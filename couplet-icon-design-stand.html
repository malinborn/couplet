couplet — иконка из токенов

Собрано из design_handoff_couplet_icon/couplet-icons.dc.html без изменений: холст 1024, сквиркл 824 с радиусом 185, Playfair Display Italic 500, курсор 114×595 (радиус 57, слева 488, сверху 114), знак поверх курсора. Каждая иконка — тот же мастер, уменьшенный трансформом, поэтому прозрачные поля по гайдлайнам macOS сохраняются на любом размере. Шрифт вшит, сеть не нужна.

Токены → иконка · 256px

Цвета — только из src/lib/theme/*.css: плитка --bg-base (у aurora-light — --bg-image), знак --color-heading, курсор — родной --color-cursor темы; светящийся градиент «акцент → второй тон» — только там, где курсор совпадает с цветом текста (light, dark, phosphor-dark). У aurora градиент курсора свой, из токенов. Геометрия и тени — из дизайна. default — иконка бандла, к теме не привязана, оставлена как в дизайне.

Реальные размеры · 128 / 64 / 32 / 16 pt

16 pt — Finder списком, «Открыть с помощью», принудительное завершение; 32 pt — Spotlight, «Свойства», уведомления; 48–128 pt — Dock, Cmd+Tab, Launchpad. На Retina 16 pt рисуется из картинки 32×32. Смотрите при масштабе 100% (Cmd+0). На 32 и 16 справа — тот же знак без свечений.
