# couplet 2.4.1

Numbers move along.

- **Enter renumbers the list.** Press Enter after `1.` in a numbered list and the new item is `2.`, but the items below kept their numbers: `1, 2, 2, 3`. Since May couplet's own Enter handler had taken the key from the editor's built-in one, which renumbered, and it only ever wrote the next number. Now the rest of the list counts on, in the same step — one ⌘Z takes back the new item and the renumbering together.
- **The list is read, not scanned.** The renumbering follows the markdown parser rather than walking lines that start with a digit: a second line of an item belongs to that item, a nested list keeps its own count, a list that starts at `5.` still starts at 5, and a list written as `1. 1. 1.` on purpose is left alone.

Upgrade: `brew update && brew upgrade --cask couplet`
