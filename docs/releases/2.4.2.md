# couplet 2.4.2

The drawer steps aside.

- **Room to drop a link.** Holding ⌥ while dragging a tab card turns the drop into a link, but the drawer stayed open over the left part of the text, so a link could not land there. Now the drawer (and the stash, if it is open) slides out of the way while ⌥ is held, and comes back with the window carousel the moment you let go. The drag goes on throughout; drop and the link is in, the drawer stays closed.
- **A hint you can see.** "⌥ — insert a link instead" under the window carousel was small grey text, easy to miss. It is larger now, in the normal text colour, with ⌥ drawn as a key.

Upgrade: `brew update && brew upgrade --cask couplet`
