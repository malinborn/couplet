# couplet 2.1.1

A one-fix patch for the drawer filters.

- **`⌥⌫` deletes a word, `⌘⌫` clears the filter.** The tab and stash drawers filter as you type, but only a plain `⌫` edited the query. `⌘⌫` fell into the branch that handles `⌘L`/`⌘R`/`⌘U`, found no sort for it and did nothing; `⌥⌫` was read as a plain `⌫` and took one character. Both now behave as in any macOS text field, in the trash view too; on an empty query they do what `⌫` always did.
- **`⌫` takes a whole emoji** instead of half of one.

Upgrade: `brew update && brew upgrade --cask couplet`
