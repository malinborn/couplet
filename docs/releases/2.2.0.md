# couplet 2.2.0

Find shows what it found.

- **Matches you can read.** A match inside a heading used to be an empty box: heading text is painted through its gradient with a transparent fill, and the match background landed on top of the glyphs. Inside inline code the code's own background covered the match, and inside a table nothing was highlighted at all. All three now show real text, and the current match, the other matches and the selection are three different colours — one shared `!important` rule used to paint them identically. A test holds every theme to a 4.5:1 contrast for match text.
- **Everything else steps back.** While the cursor is in the Find field, the page dims except for the matches, and the current one glows. Click back into the text and the dimming lifts; the highlights stay.
- **How many, and which one.** A new Find panel: `3 / 17` right in the field, toggles for case, regexp and whole word, a replace row on demand, and a red field when nothing matches or the pattern is broken.
- **`⌘G` / `⌘⇧G`.** Find Next and Find Previous are in the Edit menu and printed next to the arrows in the panel. They always worked; nothing said so. With the tab drawer open, `⌘G` is still "To a window…".
- **Stepping through tables.** Landing on a match in a table row snapped the caret out of the table, so the next step skipped every other match in it. Search steps now stay in the row, and the current match is outlined in its cell.

Upgrade: `brew update && brew upgrade --cask couplet`
