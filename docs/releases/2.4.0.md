# couplet 2.4.0

Links go somewhere, sums add up.

- **Links to files open them.** ⌘-click `[plan](docs/plan.md)` and the file opens as a tab, or couplet switches to the tab or window that already has it; `plan.md#risks` also scrolls to that heading. Until now every link went to the system's URL opener, which accepts only `http`, `mailto` and `tel`, so a path did nothing at all. Paths are read relative to the document, absolute, or from `~/`.
- **Nothing runs from a link.** A link to an image, a PDF, a folder or an `.app` is shown in Finder, never opened: a markdown file can come from anywhere. A link to a file that does not exist is drawn dashed, and clicking it offers to create the file instead of creating it behind your back.
- **`[[` and `/link`.** Type `[[` anywhere in a line, or pick `/link`, and a file picker opens: your open tabs first, then markdown files of the project, then recent files and the stash, then "Choose file…". What lands in the document is a plain markdown link with a relative path, readable by GitHub and by any other editor. The project walk never goes into Documents, Desktop or Downloads, so macOS does not pop up permission dialogs.
- **Drag to link.** Drop a stash card onto the text and it becomes a link. A tab card dragged with ⌥ held does the same (without ⌥ it still moves the tab to another window), and so does a file dropped from Finder with ⌥. A drop that would break a table, a code block or another link is refused.
- **Your agent links too.** The prompt from `AI → Teach Your AI couplet` now tells agents to write file and section links, and how a heading turns into its `#anchor`. Run it again to update your agent's skill.
- **Arithmetic after `=`.** Type `338 * 1.3 =` and a grey `439.4` appears; Tab writes it in, Esc hides it. It is a small parser of its own, not `eval`: digits, `+ − × ÷ ^ %` and brackets, decimal commas and spaced thousands included; anything it is not sure about gets no answer rather than a wrong one.
- **Computed table cells.** A cell holding `338 * 1.3 = 439.4` shows `439.4 ƒ`, with the expression in its tooltip, as long as the stored answer is exactly right. In markdown tables and CSV alike.
- **View → Lists.** Indentation lines from each item's bullet down to the end of its block, strict indentation that keeps every wrapped line under the item's text, three line styles and three densities. With both switches off lists render exactly as before.
- **Fixes.** ⌘G inside a table scrolled to the table's bottom edge rather than to the match, because table rows are zero-height lines under the widget. A link whose text is itself a URL rendered half-raw, since the URL in the text was read as the destination. And a lone `-` at the start of a line no longer turns into a bullet before you type the space.
