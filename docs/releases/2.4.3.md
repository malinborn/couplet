# couplet 2.4.3

Selection shows through code.

- **Selected code looks selected.** A selection that ran into `inline code` or a code block stopped at its edge, as if the code were not part of it. The editor draws the selection on a layer behind the text, and the code's own background, being opaque, covered it — most visibly in Live Render, where code never turns back into raw markdown. Now the selected part of the code is painted on top of that background.
- **Whole lines in a block.** A code-block line selected through its end fills across the block, empty lines included, the way lines in the middle of a selection do elsewhere; the language label and Copy stay as they are. A search match inside code still shows over the selection.
