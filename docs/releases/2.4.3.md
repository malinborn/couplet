# couplet 2.4.3 — Ticks in the table

## A checkbox in a cell is a checkbox

A status column of `[ ]`, `[x]` or `- [ ]` used to show as raw brackets, and in a narrow column it broke into one character per line. Table cells had their own small renderer that knew bold, code and links but not task boxes.

Now a cell that starts with `[ ]`, `[x]` or `[X]` — optionally after `- `, `* ` or `+ ` — draws a real box, and a click flips `[ ]` ↔ `[x]` in the file. Text after the box renders as before. A box in the middle of a cell stays text, and `[ ](url)` stays a link.

## One click, one undo

Each toggle is its own ⌘Z step, even two quick clicks on the same box. Double-click the rest of the cell and you still edit its raw text.
