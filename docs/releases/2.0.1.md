# couplet 2.0.1

A one-fix patch for tabs.

- **⌃Tab switches tabs from the keyboard again.** In 2.0.0 `View → Tabs → Show Next Tab` worked when clicked and did nothing when pressed. The cause was the kind of shortcut, not the key: a Control-only menu shortcut never reaches the menu while the window is active — the page takes it as an ordinary keypress (`⌃[` failed the same way in a trial build). `⌃Tab` / `⌃⇧Tab` are now handled by the page itself, the way `⌃1`…`⌃9` always were.
- **The menu now shows `⌘⇧]` / `⌘⇧[`** for Show Next / Previous Tab — the same keys as Safari, Chrome, Terminal and Finder. Both pairs do the same thing. A test fails the build if a Control-only shortcut ever lands in the native menu again.

Upgrade: `brew update && brew upgrade --cask couplet`
