# couplet 2.0.0

**md-mini is now couplet — and it brought tabs.**

```
brew update && brew upgrade --cask mdmini
```

That command still works and moves you onto the `couplet` cask. New installs: `brew install --cask couplet`.

---

## md-mini is now couplet

There are two apps called mdmini, and the other one has mdmini.com. Two small editors under one name meant confused searches, downloads of the wrong thing and bug reports about someone else's program, so we stepped aside rather than fight over it. The name also stopped telling the truth: this began as a minimalist markdown editor and became a page you and your AI agent work on together. A couplet is two lines that read as one.

- **Your data moves on first launch** — windows and tabs, caret positions, unsaved drafts, crash copies, theme and recent files go from md-mini's folder into couplet's, and md-mini's folder keeps a note saying where they went. If md-mini is still running, couplet asks it to quit first instead of copying data out from under it.
- **The old name keeps working** — `mdmini` is an alias for `couplet`, and `coup` is the short one, so scripts, aliases and `$EDITOR` need no edits. An MCP server registered as `mdmini` still answers with the same tools; it now introduces itself as `couplet`.
- **Restart your agent sessions** — a session opened before the upgrade still talks to md-mini's socket and will not see couplet until it restarts.
- **Your agent moves over in one step** — `AI → Teach Your AI couplet` hands over a prompt that now also cleans up the md-mini setup: it registers `couplet` instead of `mdmini`, replaces the old skill (and keeps it if you edited it by hand), rewrites the note in `CLAUDE.md`, and tells you what it changed.
- **Installed from the DMG?** Delete `/Applications/md-mini.app`. Your data is already in couplet, and the old app, opened by accident, would start empty. An MCP registration that points at a path inside `md-mini.app` stops working: re-register with `claude mcp add --scope user couplet -- couplet mcp`.
- `couplet watch` lines start with `[couplet]` instead of `[mdmini]` — worth knowing if a filter of yours matched on it.

## Tabs

- **Windows hold tabs** — `⌘T`, `⌘W` (the last tab closes the window), `⌘1`…`⌘9`, `⌃Tab` / `⌃⇧Tab`. A file lives in one tab across the whole app, so opening it again focuses it instead of making a copy.
- **Windows are numbered** — the title reads `README.md — #7`, and the notch on the left edge shows the number and how many tabs the window has. `⌘J` opens the tab drawer; the notch glints while a tab your agent opened is still unread.
- **`⌘⇧T` brings back what you closed** — the last tab, into its window, caret included. The Window menu gains Minimize (`⌘M`) and Reopen Windows from Last Session.
- **`⌘Z` stays in its own document** — after `⌘O` or a Recent file, undo could write the previous document's text into the new one: the inverse of a deletion survived the swap. The history is rebuilt on every switch now, and the last ≤300 ms of typing is saved before it happens instead of dropped.

## Six languages

English, Spanish, German, French, Russian and Simplified Chinese, taken from your system on first launch, with Language and Check for Updates… in the app menu. Changing the language restarts the app: rebuilding the native menu in place would have meant four new places for a silent mismatch.

## Two more themes, and the Dock follows them

- **Paper** — ink on paper, and the same paper at night in sepia; coral only for what you change: the caret, the checkbox, the line through a finished task. **Ink** — cream on ink with a coral caret that glows, and ink on a cool light sheet for the light half.
- **The Dock icon takes the theme's colours** — both halves of all six families, following Follow System too. The Finder icon stays the default one: the app is ad-hoc signed, and writing into the bundle would break the signature.
- **`/theme`** in the slash menu switches themes live as you arrow through the list; Enter keeps it, Esc goes back.

## Fixes

- **Zoom scales the whole window** — `⌘+`/`⌘−` set a font size that the editor overrode, so the only thing that ever grew was the slash-menu tooltip. It is page zoom now: text, tables, diagrams and toasts scale and rewrap to the window.
- **Files with Windows line endings open** — a CRLF file opened as an empty Untitled window with no error: the caret was placed past the end of a document CodeMirror had already shortened. Line endings are normalised on read and restored on save, and a failed open or reload now says so.
- **No "External Change" dialog on your own saves** — your own save was recognised by a 600 ms timer that could lose the race to the file-system event. It is recognised by content now.
- **`couplet --version` prints the version** — it used to open an empty window.
- Dragging across part of a heading in Live Render no longer flickers between the fragment and the whole line.
