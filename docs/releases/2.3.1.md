# couplet 2.3.1

Short rows reach the edge.

- **Empty cells are drawn.** A table row with fewer cells than the widest one stopped at its last cell — background, border and stripe included — so a sparse table read as a staircase. Short rows are now padded with empty cells to the full width, the way GitHub renders them. Double-click one in a data row and couplet writes the missing cells into the row and opens it for editing. The header's padding stays read-only: in GFM the header must have as many cells as the `|---|` line under it.
- **Rows without outer pipes keep their text.** GFM lets a row leave off its leading or closing `|`, but couplet's cell reader ignored whatever sat outside them: `| R-091` drew an empty row, and `a | b |` lost `a`. Both ends are read now, the same way the markdown parser reads them.

Upgrade: `brew update && brew upgrade --cask couplet`
