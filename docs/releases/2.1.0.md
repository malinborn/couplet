# couplet 2.1.0

The stash: nothing you type is untitled, and nothing you type gets lost.

- **Untitled is gone.** A new tab becomes a note the moment you type its first character — a plain `.md` file in `~/couplet/`, named by date, titled by its first line. Close it with `⌘W`, the red button or `⌘Q` and it is put away in the stash, not thrown away; a tab you never typed in just disappears. Drafts from earlier versions are imported as notes on first launch — read back and compared before the old copy moves aside.
- **The stash drawer.** `⌃S` opens it beside the tab drawer, `⌃T` puts the current tab away, and a file you tag or put away is kept as a reference — the file itself stays where it was, untouched. Drag cards between the two drawers, sort by changed, opened or kind, filter by `#tag`; a project window opens the stash already filtered to its repository. A narrow window widens itself so the drawers never overlap, and shrinks back when the stash closes.
- **Search that finds word forms.** A trigram index over titles and text, so `тайник` finds `тайнике` and `мент` finds `документ`, case-insensitive in any alphabet. Titles weigh more than text; the matched spot is highlighted and the card shows the text around it.
- **A trash that keeps things for 30 days.** Deleting a note moves its file to `~/couplet/.trash/`; *Trash* at the bottom of the stash restores it with its tags or deletes it for good. A note open in another window is released by that window first, after its last keystroke is on disk, so the next autosave cannot bring it back. Removing a file reference never touches the file.
- **Why 2.0.1 lost drafts on upgrade.** Restoring the previous session is opt-in, and a launch nobody restored rewrote the session file with only the windows it had open; the next launch saw the old drafts as unreferenced and deleted them. The session now keeps every un-restored window that holds a draft, and nothing is deleted outright: unreferenced drafts move to a trash for 30 days, and a draft that cannot become a note leaves a rescue copy when it is closed.
- **Your agent can use the stash.** `couplet stash search | list | get | add | tag` and the same five MCP tools. The default scope is the repository the agent works in; search returns short snippets and `get` one note at a time, so an agent never pulls the whole stash into its context. Run `AI → Teach Your AI couplet` again to tell it.
- **`⌘'` / `⌘⇧'` walk through AI marks** — the next or previous edit your agent highlighted, comment anchor or open question, wrapping around and unfolding whatever hides it. Menu shortcuts, so they work with focus in a comment box.
- **Quotes render what is inside them** — bold, links, code, lists, checkboxes, headings and nested `>` levels, each with its own bar, muted towards the quote grey. Tables and mermaid inside a quote stay source.
- **Crossing formatting nests instead of tearing.** In Live Render, italicising text that ran past the end of a bold word wrapped the hidden `**` with it, and the repair filter added a stray `**`. The selection is now split at hidden markers it crosses, and spans of the same kind merge.
- **Tab cards say when** a tab was last viewed or edited; `View → Tabs → Show Dates` hides it.
- **Autumn** — cinnamon and pumpkin by day, a violet sunset at night.

Upgrade: `brew update && brew upgrade --cask couplet`
