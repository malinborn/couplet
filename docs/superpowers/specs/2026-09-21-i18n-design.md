# md-mini i18n — шесть языков, язык системы по умолчанию

**Дата:** 2026-09-21
**Ветка:** `feat/i18n`
**База:** 1.3.0 (`ff585f6`)

## Контекст

Приложение целиком англоязычно: ~180 пользовательских строк, зашитых в код в виде литералов, в двух рантаймах — ~30 в нативном меню macOS (Rust) и ~120 во фронтенде (Svelte + CodeMirror), плюс встроенный welcome-документ. Механизма перевода нет вообще: ни библиотеки, ни каталога, ни `t()`.

Задача — поддержать шесть языков (английский, испанский, немецкий, французский, русский, китайский упрощённый), дать пункт **Language** в меню приложения, перевести меню и документы, открывающиеся по кнопкам, и определять язык системы при первом запуске с откатом на английский. Заодно — добавить ручную проверку обновлений в меню: автопроверка есть, ручной нет.

Ключевое ограничение, обнаруженное при разведке: **нативное меню строится в `setup` (`lib.rs:169`) примерно за 200 мс до появления вебвью**, а все существующие настройки живут в `localStorage` и Rust'у при старте недоступны. Поэтому язык нельзя хранить там, где лежат тема и движок, — нужен файл, который Rust читает сам.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Смена языка на лету | Нет. Авторестарт с восстановлением сессии | Пересборка меню требует Mutex вокруг состояния, переноса `Toggle`, пересчёта session count и повторного прогона трёх `sync_*` — четыре места для тихих ошибок. Session restore уже работает, рестарт выглядит как моргание |
| Реактивность `t()` | Не нужна | Следствие авторестарта: каталог проставляется один раз при загрузке, `t()` — обычная функция. ~30 строк в императивных CM6-виджетах перестают быть проблемой |
| Объём | Один PR | Решение владельца |
| `playbook.md` | Остаётся английским | Промпт для агента с CLI-синтаксисом |
| Вставки блок-шаблонов | Переводятся | Решение владельца |
| Ручная проверка обновлений | Тост, включая «у вас последняя» | Переиспользует существующий ToastStack |

## Архитектура

### Источник истины — один каталог на два рантайма

`locales/{en,es,de,fr,ru,zh}.json` в корне репозитория. Плоские ключи с точками (`menu.file.save`, `toast.update.available`).

- **Rust** подключает все шесть через `include_str!`, парсит **только активный** в `HashMap<String, String>` при старте.
- **TypeScript** импортирует их же (Vite умеет JSON нативно).

Один файл на язык, две точки потребления. Именно это имелось в виду под «подтягивать переводы из конфигов».

### Разрешение языка

Чистая функция, тестируемая без окружения:

```
stored preference  →  sys_locale::get_locale()  →  en
```

Сопоставление BCP-47 по префиксу: `de-AT` → `de`, `zh-Hans-CN` → `zh`, `pt-BR` → нет совпадения → `en`.

- **Rust:** `sys-locale = "0.3"` — чистый крейт, читает `NSLocale`, вебвью не требует, ACL-разрешений не требует (не плагин). Вызывается в начале `setup`, до `build_menu`.
- Зеркальная реализация на TS для браузерного дева (`npm run dev`, где Tauri нет) — через `navigator.language`.

Отклонён `@tauri-apps/plugin-os`: его `locale()` доступен только из JS, то есть **после** появления вебвью, что не решает задачу построения меню. Его Rust-сторона — обёртка над тем же `sys-locale`.

### Хранение настройки

Новый файл `preferences.json` в `paths::app_data_dir()`:

```json
{ "language": "de" }
```

Отсутствие ключа = следовать системе. Пишется Rust'ом при клике по меню, читается Rust'ом в `setup`. Фронтенд получает уже разрешённый язык — свою копию логики не держит.

> `paths::app_data_dir()` именуется по product name, поэтому dev-сборка не перетирает настройку установленного релиза — то же правило, что для `recovery/` и `session.json`.

### Загрузка фронтенда

`src/main.ts` сейчас монтирует приложение синхронно. Станет: `await` разрешённого языка → установка каталога → `mount()`. В браузерном деве `invoke` падает, ловим и откатываемся на `navigator.language`.

Это гарантирует, что ни один компонент не отрендерится до готовности каталога, — без «мигания» английским.

### Пересборки меню нет

`build_menu` по-прежнему вызывается один раз. Лейблы берутся из `t()`. Клик по языку:

1. Записать `preferences.json`
2. **Явно сохранить сессию**
3. `app.restart()`

### Ловушка рестарта — обязательно к исполнению

`AppHandle::restart()` при вызове **из главного потока пропускает `RunEvent::Exit`**: идёт сразу в `cleanup_before_exit()` + `process::restart()` (tauri 2.11.1, `app.rs:586-593`). Обработчики меню выполняются в главном потоке. Значит `save_session_on_exit`, висящий на `RunEvent::Exit`, **не сработает**, и смена языка потеряет все открытые окна.

**Сессию сохранять явным вызовом перед `restart()`.** Не полагаться на событие.

Это тот же класс бага, что уже задокументирован в `CLAUDE.md` про Cmd+Q и `ExitRequested`.

Известное ограничение, одинаковое с Cmd+Q: несохранённые буферы едут в сессию через секундный хартбит фронтенда, поэтому рестарт может потерять до секунды набора в untitled-документе.

### Множественное число

Два места: `reopen_session` (Rust) и счётчик окон в тосте (TS). Сейчас оба — бинарный тернарник, что неверно для русского.

Своя функция категорий вместо полноценного ICU: en/es/de/fr — `one`/`other`, ru — `one`/`few`/`many`, zh — только `other`. Ключи вида `menu.file.reopen_session.one` / `.few` / `.many` / `.other`.

### Меню Language и Check for Updates

Оба — в подменю приложения (крайнее левое), после About:

```
md-mini
  About md-mini              PREDEFINED
  ──────
  Check for Updates…         id=check_updates        ← новое
  ──────
  Language ▸                                          ← новое
    ✓ Follow System          id=language_system
    ──────
      English                id=language_en
      Español                id=language_es
      Deutsch                id=language_de
      Français               id=language_fr
      Русский                id=language_ru
      简体中文                id=language_zh
  ──────
  Services / Hide / Quit     PREDEFINED
```

Названия языков — на самих языках, не переводятся (общепринятая практика: немец найдёт «Deutsch» в любой локали).

Структура зеркалит меню Theme: «Follow System» чекбоксом сверху, разделитель, затем варианты. Радиогруппа, поэтому `Toggle` и суффиксы `:on`/`:off` не нужны — широковещательная рассылка идемпотентна.

**Предопределённые пункты не переводим** — macOS локализует их сам: `about`, `services`, `hide`, `hide_others`, `show_all`, `quit`, `undo`, `redo`, `cut`, `copy`, `paste`.

**Ловушка:** `"Select All"` (`menu.rs:172`) — кастомный пункт, стоящий посреди предопределённого блока. Выглядит как системный, но не локализуется. Переводим.

### Ручная проверка обновлений

Клик по `check_updates` **нельзя пускать через общий broadcast** (`lib.rs:271-273`): он уходит в каждое окно, и при пяти открытых окнах даст пять запросов к GitHub. Маршрутизируем как `ai_comment` — один `app.emit` на всё приложение.

Фронтенд выполняет проверку и всегда даёт ответ, в отличие от автопроверки, которая молчит:

| Исход | Тост |
|---|---|
| Есть новая версия | существующий `update-available`, в обход подавления dismissal |
| Уже последняя | новый `update-none` |
| Сеть недоступна | новый `update-check-failed` |

В `report_update` добавляется флаг `force`, в `UpdateState` — сброс `dismissed` при принудительном вызове.

## Что НЕ переводится — по политике, а не по недосмотру

| Что | Почему |
|---|---|
| `SELF_AUTHOR = "You"` (`comments.rs:707`, `comment-format.ts:95`) | Пишется в sidecar на диск. Перевод сломает совместимость файлов между локалями |
| Ошибки `respondToAi` (`App.svelte:1103-1151`) | Парсятся агентом |
| Сборщики промптов (`ai-bind.ts`, `buildWatchPrompt`, `buildHandoffPrompt`) | Содержат вызовы CLI, потребляются LLM |
| `ai_socket.rs`: `USAGE`, `mdmini help`, снипеты | Терминал и агенты |
| `playbook.md` | Решение владельца |
| Названия тем Classic / Aurora / Blueprint / Phosphor | Имена собственные |
| Ошибки парсинга Mermaid, имена языков из `@codemirror/language-data` | Сторонние строки |
| `brew update && brew upgrade --cask mdmini` | Команда оболочки |
| Маркеры статусов в sidecar (`open`/`answered`/`resolved`/`paused`) | Формат файла |

## Документы

| Документ | Действие |
|---|---|
| `welcome.md` | Шесть версий: `welcome.{lang}.md`. Пишется как `welcome-{version}-{lang}.md`. Маркер `onboarding-version` хранит `версия:язык` (например, `1.3.0:ru`), поэтому смена языка без смены версии тоже переоткрывает окно — см. решение #3 в `2026-09-21-i18n-open-questions.md` |
| `playbook.md` | Один, английский |
| `connect_doc()` («Teach Your AI mdmini») | Обрамляющая проза переводится, блоки промпта/скилла/конфига остаются английскими — они должны совпадать байт в байт с выводом `mdmini agent` |

**Ловушка в `connect_doc`:** внутридокументные ссылки `(#the-prompt)` и `(#skill-only-leaving-your-config-alone)` — это слаги заголовков. При переводе заголовков слаги обязаны пересчитываться из переведённого текста, иначе ссылки станут битыми. Нужен slugify на стороне Rust, согласованный с `heading-slugs.ts`.

`welcome.md` дословно называет восемь пунктов меню (`AI`, `Teach Your AI mdmini`, `Theme`, `Follow System`, `View`, `Editor Engine`, `Live Render`, `Preview`, `Raw`, `OCD Alignment`). Каждая языковая версия обязана называть **свои** переведённые лейблы.

### Новые тесты

- Разрешение локали: точное совпадение, совпадение по префиксу (`de-AT`→`de`), неподдерживаемый (`pt-BR`→`en`), локаль не читается → `en`
- Категории множественного числа по всем шести языкам, особенно `1/2-4/5+` для русского
- **Полнота каталогов**: каждая локаль содержит ровно тот же набор ключей, что `en` — в обоих рантаймах. Шесть файлов по ~180 ключей разъедутся без этого
- Круговой прогон `preferences.json`, включая битый JSON → следовать системе

Стиль тестов — домашний: `PascalCase_WithUnderscores`, «перезапуск» имитируется повторным созданием стора, проверяется сырой `localStorage`, чистая логика отделена от реактивной обёртки (образец — `theme-resolve.ts` + его тест).

## Проверка

1. `npx vitest run --dir src` — не `npm run test`: он подхватывает копии из `.claude/worktrees/` и завышает счёт
2. `cd src-tauri && cargo test`
3. `cargo clippy --manifest-path src-tauri/Cargo.toml`
4. `npm run check`
5. `npm run check:x86` — Intel-сборка
6. `npm run dev` + Playwright: тосты, слэш-команды, подсказки таблиц на разных языках
7. `npm run dev:app` — нативное меню и авторестарт при смене языка. Проверить руками, что **окна вернулись на место**, — это регрессия, которую не ловит ни один юнит-тест
8. Первый запуск при системной локали `de` → меню и welcome по-немецки. Проверяется через `defaults write -g AppleLanguages`
