# Tabs 04 — AI Contract and CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make windows first-class for agents and the CLI: every window is bound to a project, an agent's `show`/`edit`/`ask`/open is routed by the four steps of spec §5, lands in the background without ever taking the tab a human is typing in, an `ask` survives its tab going to the background, `show(transient)` asks «Закрыть / Оставить» by itself, and agents/humans get `-t/-b/-f`, `ls`, `close` and MCP `windows`/`close`.

**Architecture:** Rust decides *where*: a window's project is bound lazily from its first file (`routing::bind_missing_projects`, persisted in session v2), and a pure `routing::route` picks the window (binding → already open → project, most recently focused → new window) for every agent command in `ai_socket::dispatch`, which now also serves `open`, `close` and `windows`. The frontend decides *how it lands*: a pure `decideLanding` (live / activate / background) guarded by a typing clock, and a dependency-injected orchestrator `agent-commands.ts` that replaces `handleAiCommand` — background opens, edits applied to the cached state and written to disk, shows that place the caret and pulse on entry, asks parked in a per-tab inbox and delivered when the tab is shown. The tab controller gains the background operations and three hooks (`leave`/`enter`/`forget`) instead of cancelling asks. Quick looks are a controller flag plus a small bar, expired by a File-menu policy.

**Tech Stack:** Tauri 2 (Rust), Svelte 5 runes, TypeScript strict, CodeMirror 6, vitest (+ jsdom for DOM helpers and the one component), cargo test. No new dependencies.

**Sources of truth:** behaviour — `docs/superpowers/specs/2026-09-24-tabs-design.md` §2, §3, §4, §5, §7, §8, §13; roadmap row 04 — `docs/superpowers/plans/2026-09-24-tabs-00-roadmap.md`; open question Q4 — `docs/superpowers/plans/tabs-questions.md`. Spec wins on behaviour. **Naming:** the product rebrand is not part of this work — the CLI stays `mdmini` (`scripts/mdmini` + the binary's `ai` client); every `coup …` in the spec is implemented as `mdmini …`, and `coup` becomes an alias with the rebrand. The `show` contract change ships with the rebrand (spec §5): **no release steps, no Homebrew, nothing under `/Applications`.**

## Decisions

| # | Decision | Why |
|---|---|---|
| D1 | **A window's project is bound lazily and once:** the git toplevel of the first file tab it holds (nearest `.git` dir or file walking up — a worktree is its own project), or that file's directory outside git. Stored as an absolute path on `WindowTabs.project`, shown as the directory name. Bound by `routing::bind_missing_projects` (walk outside the registry lock) before every routing decision and on every heartbeat; persisted as `WindowSnapshot.project` (serde default, no version bump); a restored window binds its saved project. Closing the file that bound it never rebinds the window. No `git` process: `git_info.rs`'s `.git` walk already resolves worktrees; `$GIT_DIR`/`core.worktree` setups fall back to the directory (plan 03 gap, accepted). | Spec §2: the project is the toplevel of the file the window was opened with, a worktree its own project. Lazy binding covers every way a window gets its first file (⌘O, CLI, agent, restore, ⌘N then open) with one call site instead of one per path. |
| D2 | **Routing (spec §5), a pure `routing::route`:** (1) `window_binding`: a dead number is an error listing the live windows (spec §3), checked first; (2) the file is already open → its tab — **this outranks a live binding** (one file, one tab app-wide, spec §2), and the answer names the window it is really in; (3) a live window of the file's project → the most recently focused one (`FocusTracker` becomes a most-recent-first list); never-focused ties by label order; (4) a new window. | The binding/already-open conflict is not in the spec; moving a tab between windows is plan 05, and an error would make the agent's next call fail for no gain — it reuses the returned `window`. |
| D3 | **Focus defaults:** `show` → `focus: true` unless the call says otherwise (spec §5 names `true` the default; it is also what every `show` did before, so old callers keep their behaviour). An agent's open (`mdmini <file>` with `CLAUDECODE` set) → background; a human's `-t N` → focus; `-b`/`-f` override either. **`edit` and `ask` never switch tabs** (spec §5: an edit of a background tab applies there; an ask waits there). A new window created for a background command is built **without activating the app** (`focused(false)`, no `NSApp activate`, spec §4). | Spec §5 as agreed with the owner at design time (confirmed by the architect): background for opens, edits and asks, focus for `show`. The one place it is decided: `AiRequest::focus()` and the MCP schema default. |
| D4 | **"Typing" is concrete:** a key without ⌘/⌃ that is not a lone modifier, delivered to an editable element of this window, within the last **2000 ms**, while the window has keyboard focus (`typing.ts`, `TYPING_GRACE_MS`). While typing: no agent command switches the active tab — `focus: true` lands in the background and answers `focused: false`; a `show` or `ask` on the active tab does not move the caret; an agent `close` of the active tab is refused. | Mandatory: an agent never takes the tab a human types in, `focus: true` included. 2 s covers the pause between words without keeping the guard up for a reader who has stopped. |
| D5 | **Landing is one pure function** `decideLanding` → `live` (the target is the active tab), `activate` (`show`/`open` with focus, nobody typing, no other agent's live question on screen), `background` (everything else). A switch that is refused (the active tab's save has not landed) or busy falls back to **background instead of an error**; only an unreadable file is an error. | Plan 02's interim errors (`the current tab has unsaved changes`, `the window is showing another agent's question`) existed because the only way in was switching. With a background path there is always somewhere to land. |
| D6 | **An `ask` survives its tab going to the background (mandatory 1).** Asks for a background tab, and live asks of a tab being left, wait in a per-window inbox keyed by tab id (`agent-inbox.ts`); the tab is marked unviewed (plan 03's shimmer and «✦ от ИИ» label — no new visual state); the controller calls `ai.enter(tabId)` after every swap, which places each ask that is still pending and before its deadline. Leaving a tab no longer cancels anything: `cancel_ai_ask` and the controller's `ai.cancel` are removed. Closing the tab → Rust `tab close` fails the agent with `tab closed` (unchanged), a release with `tab released`, the window with `window closed`; the inbox entry is forgotten. **Timeout counts from the request** (spec §13 q.3): Rust's wait is unchanged, and a parked ask past its deadline is dropped at delivery. | Counting from the showing would let the server wait past the MCP client's own timeout and answer nobody. The unviewed flag already means "an agent put something here you have not seen". |
| D7 | **`edit` of a background tab** is applied to its cached `EditorState` (or one built from disk if it was never shown or the disk moved on) **and written to disk at once**, so a background file tab stays clean (plan 02 invariant: no autosave, no recovery, no watcher there). Undo history and the AI highlight live in the state and are there on return; the baseline becomes the written text, so returning reuses the cached state. `show: true` places the caret on the change for when the tab is shown. A failed write answers `could not save the background tab: …` and changes nothing. | Spec §5 "применяется к её закешированному состоянию, с undo и подсветкой при активации". Writing immediately is the only way to keep "background ⇒ clean" true. |
| D8 | **`show` of a background tab** resolves `line`/`find` now against the tab's text (so `target not found` is still immediate), places the caret there for the next entry (`enterAt`) and parks a pulse that plays when the tab is shown. | The agent learns about a bad target at once; the human gets the "look here" when they arrive. |
| D9 | **Unviewed:** any agent command that lands on a tab which is not the active tab of a focused window marks it unviewed (plan 03 marked only commands in an unfocused window). `markUnviewedNow` and every other agent-driven stamp (`markTransientNow`, background open/edit/caret) run **only inside `runExclusive`**: the controller tracks the exclusive slot and refuses (console error, no change) a call outside it (mandatory 3). The controller's own re-park on leave sets the flag inside the queue it already holds. | A stamp from outside the slot could interleave with a switch and mark the tab the human just activated. |
| D10 | **Response:** `AiResponse` gains `window` (filled by Rust in `ai_respond` from the registry), `focused` (frontend: the tab is its window's active tab afterwards), `windows` (the listing) and `opened` (a multi-file CLI open). The label check closes "any window can answer (or dismiss) any agent's question". |
| D11 | **Wire compatibility:** every new request field has a serde default and is skipped on serialize when unset; `v` stays `1`. An old `show`/`edit`/`ask` behaves as before (show takes the view). /// The project `path` belongs to, as the absolute path of its root — see

pub fn project_of(path: &str) -> String {

/// Bind every window that holds a file but has no project yet. The walk up
/// the directories runs outside the registry lock; a window bound (or
/// closed) meanwhile keeps what it has.
pub fn bind_missing_projects(app: &AppHandle) {
    let unbound = {
        let open_files = app.state::<crate::window::OpenFiles>();
        let reg = open_files.0.lock().unwrap();
        reg.unbound_windows()
    };
    if unbound.is_empty() {
        return;
    }
    let found: Vec<(String, String)> = unbound
        .into_iter()
        .map(|(label, path)| (label, project_of(&path)))
        .collect();

    let mut reg = open_files.0.lock().unwrap();
    for (label, project) in found {
        if reg.window(&label).is_some() {

    }

```rust
/// The windows in the order they last gained focus, most recent first.
///
/// `WebviewWindow::is_focused()` queried from the menu handler is not
/// reliable: while the menu bar is being used, the OS may report no window as
/// focused. The last `WindowEvent::Focused(true)` is — clicking the menu bar
/// or pressing an accelerator does not move key-window status. The whole
/// order is what agent routing breaks ties with (spec §5 step 3).
pub struct FocusTracker(Mutex<Vec<String>>);

impl FocusTracker {
    pub fn new() -> Self {
        Self(Mutex::new(Vec::new()))
    }

    pub fn focused(&self, label: &str) {
        let mut order = self.0.lock().unwrap();
        order.retain(|l| l != label);
        order.insert(0, label.to_string());
    }

    /// A destroyed window leaves the order; the window focused before it
    /// becomes the last one.
    pub fn forget(&self, label: &str) {
        self.0.lock().unwrap().retain(|l| l != label);
    }

    pub fn last(&self) -> Option<String> {
        self.0.lock().unwrap().first().cloned()
    }

    /// Most recently focused first.
    pub fn order(&self) -> Vec<String> {
        self.0.lock().unwrap().clone()
    }
}
```

use crate::ai_socket::{ListedTab, WindowListing};
use crate::tabs::TabRegistry;

#[derive(Debug, PartialEq, Eq)]
pub enum Route {
    /// This live window takes it.
    Existing(String),
    /// Step 4: a new window, bound to the file's project by its first file.
    NewWindow,
    /// The `window_binding` names no live window (spec §3).
    DeadNumber(u32),
}

/// Spec §5, in order: a dead `binding` is an error; the file already open →
/// its window, even when `binding` names another one (one file is one tab
/// app-wide, and the answer names the window it is really in); a live
/// `binding`; a live window of `file_project`, the most recently focused one
/// (`focus_order`, most recent first; windows never focused in label order);
/// else a new window.
pub fn route(
    reg: &TabRegistry,
    path: &str,
    binding: Option<u32>,
    file_project: &str,
    focus_order: &[String],
    is_live: impl Fn(&str) -> bool,
) -> Route {
    let bound = match binding {
        Some(number) => match reg.label_with_number(number).filter(|l| is_live(l)) {
            Some(label) => Some(label),
            None => return Route::DeadNumber(number),
        },
        None => None,
    };
    if let Some(owner) = reg.label_of(path).filter(|l| is_live(l)) {
        return Route::Existing(owner);
    }
    if let Some(label) = bound {
        return Route::Existing(label);
    }
    let rank = |label: &str| {
        (
            focus_order.iter().position(|l| l == label).unwrap_or(usize::MAX),
            crate::session::label_order(label),
        )
    };
    reg.all_windows()
        .filter(|(label, w)| w.project.as_deref() == Some(file_project) && is_live(label))
        .map(|(label, _)| label.clone())
        .min_by_key(|label| rank(label))
        .map_or(Route::NewWindow, Route::Existing)
}

}

/// The listing as text, one line per window: `#N  project  files`, columns
/// aligned. `max_files` cuts each line's files short with ` …`.
pub fn format_listing(windows: &[WindowListing], max_files: Option<usize>, indent: &str) -> String {
    let number = |w: &WindowListing| w.window.map_or_else(|| "#?".to_string(), |n| format!("#{n}"));
    let project = |w: &WindowListing| w.project.clone().unwrap_or_else(|| "—".to_string());
    let nw = windows.iter().map(|w| number(w).chars().count()).max().unwrap_or(0);
    let pw = windows.iter().map(|w| project(w).chars().count()).max().unwrap_or(0);
    windows
        .iter()
        .map(|w| {
            let names: Vec<String> = w
                .tabs
                .iter()
                .map(|t| t.path.as_deref().map_or_else(|| "Untitled".to_string(), file_name))
                .collect();
            let shown = max_files.map_or(names.len(), |m| m.min(names.len()));
            let mut files = names[..shown].join(", ");
            if shown < names.len() {
                files.push_str(" …");
            }
            format!("{indent}{:<nw$}  {:<pw$}  {files}", number(w), project(w))
                .trim_end()
                .to_string()
        })
        .collect::<Vec<_>>()
        .join("\n")
}

}

/// Create an empty editor window, cascaded, and give it its number.
pub(crate) fn build_window(app: &AppHandle, activation: Activation) -> Result<String, String> {
    let count = WINDOW_COUNTER.fetch_add(1, Ordering::SeqCst);
    let label = format!("editor-{}", count);
    let offset = (count as f64) * CASCADE_OFFSET;

    let product_name = app
        .config()
        .product_name
        .clone()
        .unwrap_or_else(|| "md-mini".to_string());
    let window_title = format!("Untitled — {}", product_name);
    let foreground = activation == Activation::Foreground;

    let window = WebviewWindowBuilder::new(app, &label, WebviewUrl::App("index.html".into()))
        .title(&window_title)
        .inner_size(DEFAULT_WIDTH, DEFAULT_HEIGHT)
        .min_inner_size(400.0, 300.0)
        .position(100.0 + offset, 100.0 + offset)
        .background_color(tauri::utils::config::Color(25, 23, 36, 255))
        .focused(foreground)
        .build()
        .map_err(|e| e.to_string())?;
    if foreground {
        // Bring app + window to foreground (macOS requires NSApp activate)
        let _ = window.set_focus();
        activate_app();
    }
    let moved = {
        let open_files = app.state::<OpenFiles>();
        let mut reg = open_files.0.lock().unwrap();
        number_window(&mut reg, &label, None, allocate_from(app))
    };
    if moved {
        save_window_counter(app);
    }
    Ok(label)
}

/// Make the app the active one — a window's focus alone does not on macOS.
fn activate_app() {
    #[cfg(target_os = "macos")]
    unsafe {
        use cocoa::appkit::{NSApplication, NSApplicationActivationPolicy};
        let ns_app = cocoa::appkit::NSApp();
        // `cocoa::base::YES`, never a `true` literal: Objective-C's BOOL
        // is `bool` on aarch64 but `i8` everywhere else, so a literal
        // type-checks on Apple Silicon and fails to compile for x86_64.
        ns_app.activateIgnoringOtherApps_(cocoa::base::YES);
    }
}

/// Give the freshly built window `label` a tab for `file_path`.
pub(crate) fn hand_over_file(app: &AppHandle, label: &str, file_path: String) {
    let tab = PendingTab {
        tab_id: crate::session::new_tab_id(),
        path: Some(file_path.clone()),
        content: None,
        cursor: 0,
        top_line: 1,
        ..Default::default()
    };
    match hand_over_tab(app, label, tab) {
        Handover::Pending => set_watcher(app, label, Some(&file_path)),
        // Mounted before the tab could be queued: its listeners
        // exist, and it opens and claims the tab itself.
        Handover::Mounted => {
            let _ = app.emit_to(label, "open-file", &file_path);
        }
        // Claimed since the check above. The file stays with its
        // holder — it must never be shown and autosaved in two
        // windows — and this window opens with one untitled tab.
        Handover::Held(owner) => {
            eprintln!("open_file_window: {file_path} is held by {owner}; {label} opens empty");
            if let Some(win) = app.get_webview_window(&owner) {
                reveal(&win);
                let _ = win.emit_to(owner.as_str(), "open-file", &file_path);
            }
        }

/// reached the app or never got an answer.
fn exchange(socket_path: &Path, request: &AiRequest) -> Result<String, (String, i32)> {
    let fail = |msg: String, code: i32| (serde_json::to_string(&AiResponse::error(msg)).unwrap(), code);
    let mut stream =
        UnixStream::connect(socket_path).map_err(|_| fail("md-mini is not running".to_string(), 2))?;
    // `ask` blocks server-side on a human clicking a button, so the CLI's own
    // read timeout must cover that wait (plus 10s of margin) instead of the
    // fixed 10s used for everything else.

        AiRequest::Ask { timeout_secs, .. } => Duration::from_secs(timeout_secs + 10),
        _ => Duration::from_secs(10),
    };
    let _ = stream.set_read_timeout(Some(read_timeout));
    let mut line = serde_json::to_string(request)
        .map_err(|e| fail(format!("failed to encode request: {e}"), 1))?;
    line.push('\n');
    stream
        .write_all(line.as_bytes())
        .map_err(|_| fail("md-mini is not running".to_string(), 2))?;
    let mut reader = BufReader::new(stream);
    let mut response_line = String::new();
    match reader.read_line(&mut response_line) {
        Ok(0) | Err(_) => Err(fail("timeout waiting for response".to_string(), 1)),
        Ok(_) => Ok(response_line.trim().to_string()),
    }
}

/// One line for several opens: `window`/`focused` of the first tab, every tab in `opened`.
fn open_summary(opened: Vec<OpenedTab>, error: Option<String>) -> AiResponse {
    AiResponse {
        ok: error.is_none(),
        error,
        window: opened.first().and_then(|t| t.window),
        focused: opened.first().map(|t| t.focused),
        opened: Some(opened),
        ..Default::default()
    }
}

/// `mdmini <files>` routed: one `open` per file, one summary line.
fn run_open(socket_path: &Path, paths: &[String], window: Option<u32>, focus: bool, agent: bool) -> i32 {
    let mut opened = Vec::new();
    let mut first_error = None;
    for path in paths {
        let abs = crate::resolve_path(path, None);
        let request = AiRequest::Open { v: 1, path: abs.clone(), window_binding: window, focus };
        let resp = match exchange(socket_path, &request) {
            Ok(line) => serde_json::from_str::<AiResponse>(&line)
                .unwrap_or_else(|e| AiResponse::error(format!("failed to parse response: {e}"))),
            Err((line, code)) => {
                println!("{line}");
                if !agent {
                    tell_human(&line);
                }
                return code;
            }
        };
        if resp.ok {
            opened.push(OpenedTab { path: abs, window: resp.window, focused: resp.focused.unwrap_or(false) });
        } else if first_error.is_none() {
            first_error = resp.error;
        }
    }
    let summary = serde_json::to_string(&open_summary(opened, first_error)).unwrap();
    println!("{summary}");
    let code = exit_code_for(&summary);
    if code != 0 && !agent {
        tell_human(&summary);
    }
    code
}

/// `mdmini ls`: the listing as text, or the JSON answer with `--json`.
fn run_ls(socket_path: &Path, json: bool) -> i32 {
    let line = match exchange(socket_path, &AiRequest::Windows { v: 1 }) {
        Ok(line) => line,
        Err((line, code)) => {
            println!("{line}");
            return code;
        }
    };
    if json {
        return print_response_and_exit_code(&line);
    }
    match serde_json::from_str::<AiResponse>(&line) {
        Ok(resp) if resp.ok => {
            let windows = resp.windows.unwrap_or_default();
            if windows.is_empty() {
                println!("No windows are open.");
            } else {
                println!("{}", crate::routing::format_listing(&windows, None, ""));
            }
            0
        }
        _ => {
            println!("{line}");
            1
        }
    }
}

# Make sure the running app's command socket is up, launching the app if it
# is not (no pending-files handoff needed — the request itself carries the
# file). Exits the script with an error line if it never comes up.
ensure_running() {
  if [ -S "$CMD_SOCK" ] && ! pgrep -f "md-mini.app/Contents/MacOS/md-mini" >/dev/null; then
    # Socket file survived a crash/kill-9 of the process that owned it — a
    # stale socket makes every command below hang until its own read times
    # out. Treat it as absent so the launch path below rebinds it.
    rm -f "$CMD_SOCK"
  fi
  if [ ! -S "$CMD_SOCK" ]; then
    open "$APP"
    waited=0
    while [ ! -S "$CMD_SOCK" ]; do
      sleep 0.1
      waited=$((waited + 1))
      if [ "$waited" -ge 50 ]; then
        echo '{"ok":false,"error":"md-mini did not start in time"}'
        exit 2
      fi
    done
  fi
}

/// The files of `paths` a live window already holds, with that window, and
/// the rest, each in the order given.
pub fn partition_held(
    reg: &TabRegistry,
    paths: &[String],
    is_live: impl Fn(&str) -> bool,
) -> (Vec<(String, String)>, Vec<String>) {
    let mut held = Vec::new();
    let mut free = Vec::new();
    for path in paths {
        match reg.label_of(path).filter(|label| is_live(label)) {
            Some(owner) => held.push((path.clone(), owner)),
            None => free.push(path.clone()),
        }
    }
    (held, free)
}

/// open already, the window holding the first comes forward on that tab.
pub fn open_files_window(app: &AppHandle, paths: &[String]) {
    let (held, free) = {
        let open_files = app.state::<OpenFiles>();
        let reg = open_files.0.lock().unwrap();
        partition_held(&reg, paths, |label| app.get_webview_window(label).is_some())

        Ok(label) => label,
        Err(e) => {
            eprintln!("Failed to create window: {e}");
            return;
        }
    };

 * "The human is typing" (spec §5: an agent never takes the active tab while
 * they type): a key that went into an editable element of this window within

export function isEditableTarget(target: EventTarget | null): boolean {
  if (target instanceof HTMLInputElement || target instanceof HTMLTextAreaElement) return true;
  return target instanceof Element && target.closest('[contenteditable]:not([contenteditable="false"])') !== null;

/**
 * Where an agent's command lands in this window (spec §5):
 * - `live` — its file is the active tab: handled in the live view;
 * - `activate` — switch to its tab first (`show`/`open` with `focus`);
 * - `background` — handled without switching; the tab shimmers.
 *
 * `edit` and `ask` never switch tabs. Nothing switches while the human is
 * typing (`typing.ts`), or while the active tab shows another agent's
 * question — an agent never takes the view away from either.
 */
export type Landing = 'live' | 'activate' | 'background';

export interface LandingInput {
  cmd: 'show' | 'edit' | 'ask' | 'open';
  /** The command's file is this window's active tab. */
  active: boolean;
  /** The command may take the view (`AiCommandPayload.focus`). */
  focus: boolean;
  typing: boolean;
  /** The active tab shows an agent's live `ask`. */
  liveAsk: boolean;
}

export function decideLanding(i: LandingInput): Landing {
  if (i.active) return 'live';
  if (i.cmd === 'edit' || i.cmd === 'ask') return 'background';
  return i.focus && !i.typing && !i.liveAsk ? 'activate' : 'background';

import type { AiCommandPayload } from '../tauri/events';

/**
 * What waits for a background tab until it is shown (spec §5): an `ask` —
 * delivered then if its agent still waits and its deadline has not passed —
 * and the pulse of a `show` that landed in the background.
 */
export type InboxItem =
  | { kind: 'ask'; payload: AiCommandPayload; deadline: number }
  | { kind: 'pulse'; payload: AiCommandPayload };

export function createAgentInbox() {
  const byTab = new Map<string, InboxItem[]>();
  return {
    /** A later pulse replaces an earlier one: only the last "look here" matters. */
    park(tabId: string, item: InboxItem): void {
      const items = (byTab.get(tabId) ?? []).filter((i) => item.kind !== 'pulse' || i.kind !== 'pulse');
      items.push(item);
      byTab.set(tabId, items);
    },
    /** Everything waiting for `tabId`, once. */
    take(tabId: string): InboxItem[] {
      const items = byTab.get(tabId) ?? [];
      byTab.delete(tabId);
      return items;
    },
    /** The tab is gone: drop what waited for it, and say what that was. */
    forget(tabId: string): InboxItem[] {
      return this.take(tabId);
    },
    has(tabId: string): boolean {
      return (byTab.get(tabId)?.length ?? 0) > 0;
    },
  };
}

export type AgentInbox = ReturnType<typeof createAgentInbox>;

/** Items still worth delivering at `now`: asks before their deadline, and every pulse. */
export function deliverable(items: readonly InboxItem[], now: number): InboxItem[] {
  return items.filter((i) => i.kind !== 'ask' || now < i.deadline);
}

/** An agent's `edit`, worked out against a state but not applied. */
export interface AiEdit {
  /** One coalescing span — keeps CM6's selection mapping and scroll intact. */
  changes: ChangeSet;
  /** Where the change starts, in the resulting document: where `show` puts the caret. */
  from: number;
  /** One highlight per changed region, in the resulting document (issue #27). */
  highlights: AiHighlightRange[];
  /** 1-based inclusive `changed_lines` for the response. */
  changedLines: LineRange[];
}

/** `null` when `newContent` is what `state` already holds. */
export function buildAiEdit(state: EditorState, newContent: string): AiEdit | null {
  const oldContent = state.doc.toString();
  const repl = computeReplacement(oldContent, newContent);
  if (!repl) return null;
  const changes = ChangeSet.of(repl, state.doc.length);
  // Positions must be post-change: the highlight field reads effect values in
  // the end state — hence the diff runs against `newContent`.
  const lineRanges = computeChangedLineRanges(oldContent, newContent);
  const highlights = docRangesForLineRanges(Text.of(newContent.split('\n')), lineRanges);
  // A pure deletion produces no new lines to report: the single span's line.
  const changedLines =
    lineRanges.length > 0 ? lineRanges : [changedLineRanges(state.update({ changes }).state, repl)];
  return { changes, from: repl.from, highlights, changedLines };
}

/**
 * `buildAiEdit` applied to a state with no view — a background tab's. An
 * ordinary undoable transaction carrying the highlight, so both are there
 * when the tab is shown; with `show` the caret moves to the change.
 */
export function applyAiEditToState(
  state: EditorState,
  newContent: string,
  show: boolean
): { state: EditorState; result: AiEdit } | null {
  const edit = buildAiEdit(state, newContent);
  if (!edit) return null;
  const next = state.update({
    changes: edit.changes,
    ...(show ? { selection: { anchor: edit.from } } : {}),
    effects: setAiHighlights.of(edit.highlights),
  }).state;
  return { state: next, result: edit };
}

  const respond = (payload: AiCommandPayload, response: AgentResponse) => deps.respond(payload.id, response);
  const deadlineOf = (payload: AiCommandPayload) => deps.now() + payload.timeoutSecs * 1000;

  function place(payload: AiCommandPayload, deadline: number): boolean {
    const shown = deps.live.placeAsk(payload, deadline, (result) => {
      placed.delete(payload.id);
      void deps.respond(payload.id, answerResponse(result));
    });
    if (shown) placed.set(payload.id, { payload, deadline });
    return shown;
  }

  /** Unviewed unless in front of the human; a quick look only if this command opened it. */
  function stamp(payload: AiCommandPayload, tabId: string, opened: boolean): void {
    deps.tabs.markUnviewedNow(tabId);
    if (payload.transient && (opened || payload.fresh)) deps.tabs.markTransientNow(tabId);
  }

  async function landLive(payload: AiCommandPayload, opened: boolean): Promise<void> {
    const tab = deps.tabs.findByPath(payload.path);
    if (tab) stamp(payload, tab.id, opened);
    if (payload.cmd === 'ask') {
      if (!place(payload, deadlineOf(payload))) {
        await respond(payload, { ok: false, error: AGENT_ERRORS.targetNotFound });
      }
      return;
    }
    const typing = deps.typing();
    const response: AgentResponse =
      payload.cmd === 'edit'
        ? deps.live.edit(payload)
        : payload.cmd === 'show'
          ? deps.live.show(payload, typing)
          : { ok: true };
    // While the human types here the window is already in front of them.
    if (response.ok && payload.focus && !typing && (payload.cmd === 'show' || payload.cmd === 'open')) {
      await deps.revealWindow();
    }
    await respond(payload, response.ok ? { ...response, focused: true } : response);
  }

  async function showInBackground(payload: AiCommandPayload, tabId: string, known: string | null): Promise<void> {
    if (payload.line === null && payload.find === null) return respond(payload, { ok: true, focused: false });
    const text = known ?? (await deps.tabs.textForAgentNow(tabId));
    if (text === null) return respond(payload, { ok: false, error: AGENT_ERRORS.unreadable });
    const doc = EditorState.create({ doc: text });
    const pos = resolveShowTarget(doc, payload);
    if (pos === null) return respond(payload, { ok: false, error: AGENT_ERRORS.targetNotFound });
    const line = doc.doc.lineAt(pos).number;
    deps.tabs.placeCaretNow(tabId, { cursor: pos, topLine: Math.max(1, line - CONTEXT_LINES) });
    inbox.park(tabId, { kind: 'pulse', payload });
    return respond(payload, { ok: true, focused: false });
  }

  async function editInBackground(payload: AiCommandPayload, tabId: string): Promise<void> {
    const result = await deps.tabs.applyToTabNow(tabId, (state) =>
      applyAiEditToState(state, payload.content ?? '', payload.show)
    );
    if (result.kind === 'failed') {
      return respond(payload, { ok: false, error: `could not save the background tab: ${result.error}` });
    }
    if (result.kind === 'unchanged') return respond(payload, { ok: true, changed_lines: [], focused: false });
    const edit = result.result;
    if (payload.show) {
      const firstLine = edit.changedLines[0]?.[0] ?? 1;
      deps.tabs.placeCaretNow(tabId, { cursor: edit.from, topLine: Math.max(1, firstLine - CONTEXT_LINES) });
    }
    return respond(payload, { ok: true, changed_lines: edit.changedLines, focused: false });
  }

  async function landBackground(payload: AiCommandPayload): Promise<void> {
    let tabId = deps.tabs.findByPath(payload.path)?.id;
    let opened = false;
    let text: string | null = null;
    if (tabId === undefined) {
      const result = await deps.tabs.openBackgroundNow(payload.path);
      if (result.kind === 'other-window') return respond(payload, { ok: false, error: AGENT_ERRORS.elsewhere });
      if (result.kind === 'failed') return respond(payload, { ok: false, error: AGENT_ERRORS.unreadable });
      tabId = result.tabId;
      if (result.kind === 'opened') {
        opened = true;
        text = result.text;
      }
    }
    stamp(payload, tabId, opened);
    switch (payload.cmd) {
      case 'open':
        return respond(payload, { ok: true, focused: false });
      case 'show':
        return showInBackground(payload, tabId, text);
      case 'edit':
        return editInBackground(payload, tabId);
      case 'ask':
        // Answered from the widget once the human opens the tab (`enter`).
        inbox.park(tabId, { kind: 'ask', payload, deadline: deadlineOf(payload) });
        return;
      case 'close':
        return;
    }
  }

  /** Switch to the command's tab (opening it first if needed): shown, or fall back. */
  async function activateFor(payload: AiCommandPayload, tabId: string | undefined): Promise<'shown' | 'background' | 'failed'> {
    if (tabId !== undefined) {
      const result = await deps.tabs.activateNow(tabId, { byAgent: true });
      if (result === 'ok' || result === 'noop') return 'shown';
      // Refused (the active tab's save has not landed) or busy: never an error.
      return result === 'failed' ? 'failed' : 'background';
    }
    await deps.tabs.openPathNow(payload.path);
    return deps.activePath() === payload.path ? 'shown' : 'background';
  }

  /** Spec §8: the ⌘W path; never while the human types in it; answered before a last tab closes its window. */
  async function closeFor(payload: AiCommandPayload): Promise<void> {
    const tab = deps.tabs.findByPath(payload.path);
    if (!tab) return respond(payload, { ok: false, error: AGENT_ERRORS.notOpen });
    if (tab.id === deps.tabs.list.activeId && deps.typing()) {
      return respond(payload, { ok: false, error: AGENT_ERRORS.typing });
    }
    let answered = false;
    const closed = await deps.tabs.closeTabNow(tab.id, async () => {
      answered = true;
      await respond(payload, { ok: true });
    });
    if (!answered) await respond(payload, closed ? { ok: true } : { ok: false, error: AGENT_ERRORS.unsaved });
  }

  return {
    async handle(payload: AiCommandPayload): Promise<void> {
      await deps.tabs.runExclusive(async () => {
        // A command can wait here behind a switch or past its own timeout;
        // its agent has been answered already, and acting now acts for nobody.
        if (!(await deps.isPending(payload.id))) return;
        if (payload.cmd === 'close') return closeFor(payload);
        const tab = deps.tabs.findByPath(payload.path);
        const landing = decideLanding({
          cmd: payload.cmd,
          active: tab !== undefined && tab.id === deps.tabs.list.activeId,
          focus: payload.focus,
          typing: deps.typing(),
          liveAsk: deps.liveAsk(),
        });
        if (landing === 'live') return landLive(payload, false);
        if (landing === 'activate') {
          const shown = await activateFor(payload, tab?.id);
          if (shown === 'shown') return landLive(payload, tab === undefined);
          if (shown === 'failed') return respond(payload, { ok: false, error: AGENT_ERRORS.unreadable });
        }
        return landBackground(payload);
      });
    },

    /** The controller is leaving `tabId`: its live questions wait in the inbox. */
    leave(tabId: string): boolean {
      let parked = false;
      for (const id of deps.live.askIds()) {
        const record = placed.get(id);
        if (!record) continue;
        placed.delete(id);
        inbox.park(tabId, { kind: 'ask', ...record });
        parked = true;
      }
      return parked;
    },

    /** `tabId` is shown: a pulse, then the questions still waited on, in order. */
    async enter(tabId: string): Promise<void> {
      for (const item of deliverable(inbox.take(tabId), deps.now())) {
        if (item.kind === 'pulse') {
          deps.live.pulse(item.payload);
          continue;
        }
        if (!(await deps.isPending(item.payload.id))) continue;
        if (!place(item.payload, item.deadline)) {
          await respond(item.payload, { ok: false, error: AGENT_ERRORS.targetNotFound });
        }
      }
    },

    /** `tabId` left the window: what waited for it goes (Rust answers its agents). */
    forget(tabId: string): void {
      for (const item of inbox.forget(tabId)) {
        if (item.kind === 'ask') placed.delete(item.payload.id);
      }
    },
  };
}

export type AgentCommands = ReturnType<typeof createAgentCommands>;

  // --- AI commands (`mdmini show`/`edit`/`ask`, routed opens, `close`) ---
  //
  // Where a command lands, and what it does to a tab in the background, is
  // `lib/tabs/agent-commands.ts`. What stays here is the live view.

  const typingTracker = createTypingTracker({ now: () => Date.now(), focused: () => document.hasFocus() });

  function noteTyping(e: KeyboardEvent): void {
    typingTracker.note(e);
  }

  function liveShow(payload: AiCommandPayload, keepCaret: boolean): AgentResponse {
    const view = editorHandle?.view;
    if (!view) return { ok: false, error: AGENT_ERRORS.editorNotReady };
    const pos = resolveShowTarget(view.state, { line: payload.line, find: payload.find });
    if (pos === null) return { ok: false, error: AGENT_ERRORS.targetNotFound };
    view.dispatch({
      // Move the caret along with the view: otherwise it stays wherever it
      // was (often position 0 in a fresh window) and the next arrow key
      // snaps the view back there — reads as "cursor jumped to the top".
      // Not while the human types: then it stays under their fingers.
      ...(keepCaret ? {} : { selection: { anchor: pos } }),
      effects: [EditorView.scrollIntoView(pos, { y: 'center' }), pulseAiLine.of(pos)],
    });
    schedulePulseCleanup();
    return { ok: true };
  }

  /** A background `show` arriving with its tab: the caret is already there. */
  function livePulse(payload: AiCommandPayload): void {
    const view = editorHandle?.view;
    if (!view) return;
    const pos = resolveShowTarget(view.state, { line: payload.line, find: payload.find });
    if (pos === null) return;
    view.dispatch({ effects: pulseAiLine.of(pos) });
    schedulePulseCleanup();
  }

  /** Invariant: synchronous between reading `view.state.doc` (in `buildAiEdit`)
   * and calling `view.dispatch` — no `await` in between. Two AI edit commands
   * delivered back-to-back would otherwise both read the same pre-edit state
   * and diff against it, and whichever dispatches second would clobber the
   * first's change instead of building on top of it. */
  function liveEdit(payload: AiCommandPayload): AgentResponse {
    const view = editorHandle?.view;
    if (!view) return { ok: false, error: AGENT_ERRORS.editorNotReady };
    const edit = buildAiEdit(view.state, payload.content ?? '');
    if (!edit) return { ok: true, changed_lines: [] };
    const scrollEffect = view.scrollSnapshot().map(edit.changes);
    view.dispatch({
      changes: edit.changes,
      // With `show` the user is being led to the change — bring the caret
      // too (post-change coordinates), so arrow keys continue from there.
      ...(payload.show ? { selection: { anchor: edit.from } } : {}),
      effects: [
        ...(scrollEffect ? [scrollEffect] : []),
        setAiHighlights.of(edit.highlights),
        ...(payload.show ? [EditorView.scrollIntoView(edit.from, { y: 'center' })] : []),
      ],
      // Unlike an external-reload or an untitled-restore transaction, an AI
      // edit must stay undoable — it's a content change the user did not
      // author, and Cmd+Z is their way to reject it.
    });
    // docChanged still fires the update listener (handleChange), which arms
    // dirty state + autosave — no separate call needed here.
    return { ok: true, changed_lines: edit.changedLines };
  }

  function livePlaceAsk(
    payload: AiCommandPayload,
    deadline: number,
    onAnswer: (result: AskResult) => void
  ): boolean {
    const view = editorHandle?.view;
    if (!view) return false;
    let pos: number;
    if (payload.line === null && payload.find === null) {
      pos = view.state.doc.length;
    } else {
      const resolved = resolveShowTarget(view.state, { line: payload.line, find: payload.find });
      if (resolved === null) return false;
      pos = resolved;
    }
    const askId = payload.id;
    // The caret follows the question's anchor for the same reason as `show` —
    // unless the human is typing: then the widget appears and nothing moves.
    const quiet = typingTracker.typing();
    view.dispatch({
      ...(quiet ? {} : { selection: { anchor: pos } }),
      effects: [
        addAiAsk.of({
          spec: {
            id: askId,
            question: payload.question ?? '',
            options: payload.options,
            multi: payload.multi,
            freeText: payload.freeText,
            onAnswer: (answerId, result) => {
              editorHandle?.view?.dispatch({ effects: removeAiAsk.of(answerId) });
              onAnswer(result);
            },
          },
          pos,
        }),
        ...(quiet ? [] : [EditorView.scrollIntoView(pos, { y: 'center' })]),
      ],
    });
    // The Rust side owns the deadline; this only drops a widget nobody waits
    // on any more. Removing an id the field no longer has is a no-op.
    setTimeout(
      () => {
        editorHandle?.view?.dispatch({ effects: removeAiAsk.of(askId) });
      },
      Math.max(0, deadline - Date.now()) + 2000
    );
    return true;
  }

  const agent = createAgentCommands({
    tabs,
    activePath: () => fileState.filePath,
    isPending: (id) =>
      invoke<boolean>('ai_is_pending', { id }).catch((err: unknown) => {
        logTabIpc('ai_is_pending')(err);
        return true;
      }),
    respond: (id, response) =>
      invoke<void>('ai_respond', { id, response }).catch((err: unknown) => {
        console.error('Failed to respond to AI command:', err);
      }),
    typing: () => typingTracker.typing(),
    liveAsk: () => {
      const view = editorHandle?.view;
      return view ? activeAskIds(view.state).length > 0 : false;
    },
    revealWindow: () => invoke<void>('reveal_window').catch(logTabIpc('reveal_window')),
    now: () => Date.now(),
    live: {
      show: liveShow,
      edit: liveEdit,
      placeAsk: livePlaceAsk,
      pulse: livePulse,
      askIds: () => {
        const view = editorHandle?.view;
        return view ? activeAskIds(view.state) : [];
      },
    },
  });

  async function handleAiCommand(payload: AiCommandPayload): Promise<void> {
    // Before any of the command's own outcomes: an agent has reached this
    // install for the first time, and this is the one moment the user is
    // certain to be looking. Raised even if the command below then fails —
    // something visibly happened either way, and the point is to explain what.
    if (payload.firstUse) {
      toasts.push({ kind: 'ai-first-use' });
    }
    await agent.handle(payload);
  }

## Known gaps and risks carried out of this plan

- **Obligation for plan 05: moving a tab — drag to another window and «В новые окна» — must carry the tab's agent inbox (`agent-inbox.ts`: parked asks, a pending pulse) and its `AiPending` entries (re-keyed to the new window's label) along with the tab. No `tab released` for a move.** Today «В новые окна» releases the tab, so its waiting agents get `tab released` and its parked questions are forgotten.
- **Quick looks are not persisted** (D17, Q8): a restart turns them into ordinary tabs.
- **Finder is unchanged and waits for Q4** (D14): it still opens a new window even when a window of the file's project is open. Not tested live (Task 15); a unit test pins the current behaviour.
- **Plan 03 D9, follow-up:** the drawer's search and card previews read background tabs from their cached state, not from disk as spec §6 says. Entering a tab still reloads from disk when the file changed, so only search/preview freshness is affected — now also after an agent's background `edit`, which updates the cache and the disk together (no divergence there).
- **`focused(false)` on a new window is tao's behaviour on macOS** — measured in Task 15 scenario 1 (`document.hasFocus()` in both windows). If a background window still takes key focus on some macOS version, the fallback is to re-focus the previously focused window right after `build_window` (the `FocusTracker` knows which).
- **An ask whose target (`line`/`find`) vanished while it waited** answers `target not found` when its tab is shown — later than an agent may expect.
- **The typing guard counts keys, not IME composition**: a Chinese IME's candidate keys (`key === 'Process'`) count as typing, which errs on the safe side.
- **`the file is open in another window`** can happen when the human opens the file elsewhere between Rust's routing and the frontend's landing; the agent re-sends and routing then finds it.
- **Old running `md-mini mcp` processes drop `window`/`focused`** until the MCP client restarts them (spec §5); acceptable only because this ships with the rebrand.
- **Paths are normalized, but not case-folded** (`path_norm::normalize_path`): APFS is case-insensitive by default, so `/x/A.md` and `/x/a.md` are one file, yet `canonicalize` keeps the case it was given — two spellings, two tabs, both autosaving. `.`/`..`, symlinks (`/tmp` → `/private/tmp`) and relative paths are handled at every entry (CLI, socket, MCP, tab commands, session restore, ⌘⇧T, window opens). Folding needs the volume's own answer (`pathconf(_PC_CASE_SENSITIVE)` or the directory's real entry name), not a lowercase.
