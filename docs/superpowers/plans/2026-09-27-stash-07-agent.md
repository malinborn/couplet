> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents can search, list, read, add to and tag the user's stash — `couplet stash search|list|get|add|tag` on the command line and `stash_search`, `stash_list`, `stash_get`, `stash_add`, `stash_tag` over MCP — through a direct connection to `stash.db` that works whether or not couplet is running, scoped by default to the repository the agent works in, and never handing an agent the whole stash.

**Architecture:** One new Rust module, `src-tauri/src/stash/cli.rs`, holds everything agent-facing: where the stash is without a Tauri context (`StashLocation`, resolved from a product name — `--product couplet-dev` for dev), how a call is scoped (`ScopeArg` → `Scope`, from `git_info::git_toplevel` of the caller's cwd), compact snake_case answer types (`StashAnswer`, `AgentEntry`, `AgentHit` — no previews, no full text except in `get`), the five operations over the stage 02/05/06 API, the CLI parser/renderer, and a best-effort `notify` that sends a new `stash-changed` request to the app's command socket after a write. `ai_socket::run_ai_cli` hands `couplet ai stash …` to it before its own parser; `scripts/couplet` routes `couplet stash …` to `ai stash …` next to the other offline verbs; `mcp_server.rs` gains five tools that call the same operations. The app side is one new request arm in `ai_socket::dispatch` that emits `stash-changed` once.

**Tech Stack:** Rust (Tauri 2 app crate `md-mini`, lib `md_mini_lib`), `rusqlite` (added in stage 02), `serde`/`serde_json`, `libc` (already a dependency — `localtime_r`/`mktime` for local times), cargo test. Bash for `scripts/couplet`. No frontend changes; no new dependencies.

**Sources of truth:** behaviour — `docs/superpowers/specs/2026-09-26-stash-design.md`, section «Агент» (spec wins on behaviour); names, paths, schema, IPC and the `stash-changed` event — `docs/superpowers/plans/2026-09-27-stash-00-roadmap.md` («Shared contracts», used exactly); format reference — `docs/superpowers/plans/2026-09-25-tabs-04-ai-cli.md`.

## Decisions

| # | Decision | Why |
|---|---|---|
| D1 | **All agent logic lives in `stash/cli.rs`**, as plain functions over a `Ctx { loc, cwd, now_ms }`. The CLI (`run`) and MCP (`mcp_server::stash_tool_call`) are thin adapters: parse → operation → render. Operations return a `StashAnswer`, never print. | One behaviour for both surfaces, testable without stdio or sockets. |
| D2 | **Direct DB access, no app required.** Every operation opens its own connection with stage 02's `stash::db::open` (WAL, `foreign_keys`, 5 s busy timeout, migrate). Reads of a stash that does not exist yet answer an empty page with the hint `the stash is empty` — they never create the file. | Roadmap: "The MCP server and CLI read and write the same database directly (WAL), so agents can search the stash even when the app is not running." |
| D3 | **The stash is named by a product, not by a socket.** Default product = `paths::RELEASE_PRODUCT_NAME`. `--product couplet-dev` sets the app dir (`<data_dir>/couplet-dev/`), the notes dir (`~/Documents/couplet-dev/`) and the socket (`/tmp/couplet_dev_cmd.sock`) together. `--socket PATH` only overrides the socket, and **`--socket` without `--product` is refused for stash verbs** with an error that names `--product`. For MCP `show`/`edit`/…, `--product P` also selects `socket_path(P)` and disables the launch unless P is the release product. | The trap in the owner's memory: a dev CLI given only `--socket` would silently read and write the **release** stash. Refusing is cheaper than a wrong write. |
| D4 | **The CLI/MCP never creates the app data directory.** A write when `<data_dir>/<product>/` does not exist answers `couplet has not run on this Mac yet — open it once, then try again`, before anything is created (no note file, no notes dir). If the directory exists, `db::open` may create `stash.db` in it. | `migration.rs`: one file in a freshly created `couplet/` before the first real launch makes the md-mini → couplet migration see `NewAlreadyPopulated` and leave md-mini's data behind for good (the same reason `scripts/mdmini` keeps its marker under `Caches`). |
| D5 | **Default scope = the git repository of the caller's cwd**, by name (`git_info::dir_name(git_toplevel(cwd))`) — the same name a window uses for its project and stage 02 stores in `entries.repo`. Outside git: the whole stash (`scope: {"all":true}`). `all: true` / `--all` widens; `repo` / `--repo` names another (a value containing `/` is a path: its toplevel's name, or its directory's name outside git). `repo` + `all` together is an error. CLI cwd = process cwd; MCP cwd = the MCP server's cwd, which is the agent's cwd at spawn. | Spec: «Область по умолчанию — репо текущей папки агента, как окно проекта само фильтрует тайник. `all: true` ищет по всему тайнику.» |
| D6 | **Every search/list answer echoes its `scope`**, and a repo-scoped default call with zero results carries `hint: "nothing in repo X; widen with --all (MCP: all: true)"`. | An agent that silently gets zero hits from a filtered scope tells the user "nothing exists". |
| D7 | **Agent JSON is snake_case and compact** (like every other AI answer: `changed_lines`, `project_path`), with its own types: `AgentEntry { id, kind, title, path, repo?, branch?, tags?, stashed_at?, modified_at }`, `AgentHit = AgentEntry + snippet`. No `preview`, `caret`, `top_line`, `score`, `ranges`, `created_at`, `opened_at`. Times are local ISO-8601 with offset (`2026-09-27T01:55:12+03:00`). The IPC `StashEntry` (camelCase, with `preview`) is never serialized to an agent. | Spec: search «без полного текста», list «только метаданные, никогда текст» — `preview` is 400 chars of text. ISO local time is both machine-parseable and readable to a model, which ms are not. |
| D8 | **Limits:** search default 10, max 50; list default 20, max 100 (clamped, never refused). Snippets are clipped to 240 chars. `get` without `lines` returns at most **500 lines / 64 KiB** (a single longer first line is returned whole), with `truncated: true`, `total_lines` and a `hint` naming the next `lines` range. `lines` is `A:B`, `A:` or `:B`, 1-based inclusive. | Spec: `stash_get(id, lines?)` — «для большой — диапазон строк»; "never dump" applies to one huge note too. |
| D9 | **`get` of a file entry returns its metadata and path, no text** (`hint: "a file reference: read <path> directly"`); `lines` on a file entry is an error. `get` of a trashed entry is an error; search/list never show trashed entries (stage 06 excludes them; this stage passes `deleted: false`). | Spec: «полный текст одной заметки … или путь файла». The trash is a human view. |
| D10 | **Agent reads touch nothing.** No operation here updates `opened_at`, `stashed_at` or `modified_at`, except `add` (which puts away: `stashed_at = now`) and `tag` (stage 02's own bookkeeping). | The human's «открытие ⌘R» sort must not be reordered by an agent looking things up. |
| D11 | **`add`:** text → `entries::create_note(text, repo_of_cwd)` then `entries::put_away([note path], tags)` (so the card reads «отложено только что»); `--path` → `put_away([abs path], tags)`, the dedup of stage 02 answering `created: false` for a path already in the stash. The path must exist and be a regular file. Empty/blank text is refused (CLI: exit 2 before any disk access). Tags are normalised: trim, strip leading `#`, lower-case, one word each, duplicates dropped. | Spec table `stash_add(text | path, tags?)`; roadmap dedup rule. |
| D12 | **Notify after a successful write, best effort.** `notify(loc, reason)` connects to `loc.socket` (500 ms read/write timeout), sends `{"v":1,"cmd":"stash-changed","reason":…}`, reads one answer line, ignores every failure, never launches the app. The app arm in `dispatch` sanitises `reason` (`[a-z0-9-]`, ≤ 32 chars, empty → `external`), calls `stash::emit_changed(app, reason)` once and answers `{"ok":true}` immediately — no window, no `AiPending`, no first-use toast. | Roadmap «Event: stash-changed … best effort, ignored when the app is not running». |
| D13 | **CLI shape:** `couplet stash <verb> …` → `scripts/couplet` → `$BIN ai stash <verb> …` → `run_ai_cli` → `stash::cli::run(&args[3..])`. `main.rs` does not change (its `ai` check already covers it). Text output by default, one JSON line with `--json` (the JSON is exactly the MCP tool result text). Exit codes: 0 ok, 1 rejected (`ok:false`), 2 usage error / empty stdin / bad location flags. Without `--json` an error goes to stderr as `couplet: <error>` and stdout stays empty. | Same dispatch as `ls`/`close`/`question` (never launches the app); same exit-code contract as the other verbs. |
| D14 | **MCP tools** `stash_search`, `stash_list`, `stash_get`, `stash_add`, `stash_tag` are served before any socket logic, from `McpConfig.stash` (a `Result<StashLocation, String>` resolved from flags at startup) and `McpConfig.cwd`. A missing required argument (`query`, `id`) or `text`+`path` together is JSON-RPC `-32602`; everything else is an `isError` tool result carrying the `StashAnswer` JSON. | The existing split between protocol errors and tool errors (`mcp_server.rs` `handle_tools_call` doc). |
| D15 | **Etiquette is taught in four places, one wording:** the tool descriptions, `AGENT_SNIPPET`, `MCP_AGENT_SNIPPET` (both embedded verbatim in «Teach your AI couplet» and `docs/ai-interface.md`), and `couplet help`. The phrase is **"Search first, get one, never dump."** | Spec: «Агенту никогда не отдаётся весь тайник». |

### Behaviour the spec leaves open, and what this plan does

| Topic | Chosen |
|---|---|
| `since` format | `today`, `yesterday` (local midnight), `12h`, `7d`, `YYYY-MM-DD` (local midnight), or unix ms |
| `since` field | `COALESCE(stashed_at, modified_at)` — a note never put away (open in a tab) still counts by its last change |
| search/list `next_cursor` on the last page | absent (skipped), documented as "no `next_cursor` = last page"; `total` is always present |
| multiple words in `couplet stash search a b` | joined with a space into one query |
| MCP `stash_add` with a relative `path` | resolved against the MCP server's cwd (like `show`) |
| `repo` of an agent-added note | the cwd's repository name, or none outside git |

/// The repository a *directory* belongs to: the nearest directory at or above
/// `dir` holding `.git` (a worktree's `.git` file counts — it is its own

    if !is_acceptable(dir) {

    }
    dir.ancestors()
        .take(MAX_DEPTH)
        .find(|d| fs::metadata(d.join(".git")).is_ok())

use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};

/// What the caller asked the scope to be.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub enum ScopeArg {
    /// The repository of the caller's cwd; the whole stash outside git.
    #[default]
    Default,
    All,
    /// A repository name, or — containing `/` — a path inside one.
    Repo(String),
}

/// The scope a call ran with, echoed in every search/list answer so the
/// agent knows its results were filtered.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Scope {
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub repo: Option<String>,
    #[serde(default, skip_serializing_if = "std::ops::Not::not")]
    pub all: bool,
}

/// A directory's repository by name — the name a window shows for its
/// project and stage 02 stores in `entries.repo`.
pub(crate) fn repo_of_dir(dir: &Path) -> Option<String> {
    crate::git_info::git_toplevel(dir).map(|top| crate::git_info::dir_name(&top))
}

pub fn resolve_scope(arg: &ScopeArg, cwd: &Path) -> Scope {
    match arg {
        ScopeArg::All => Scope { repo: None, all: true },
        ScopeArg::Repo(r) if r.contains('/') => {
            let dir = PathBuf::from(crate::resolve_path(r, cwd.to_str()));
            let name = repo_of_dir(&dir).unwrap_or_else(|| crate::git_info::dir_name(&dir));
            Scope { repo: Some(name), all: false }
        }
        ScopeArg::Repo(r) => Scope { repo: Some(r.clone()), all: false },
        ScopeArg::Default => match repo_of_dir(cwd) {
            Some(name) => Scope { repo: Some(name), all: false },
            None => Scope { repo: None, all: true },
        },
    }
}

/// Answer to a write when the app data directory does not exist yet.
pub const NOT_RUN_YET: &str = "couplet has not run on this Mac yet — open it once, then try again";

/// Where one couplet build keeps its stash, resolved without a Tauri context.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct StashLocation {
    /// `~/Library/Application Support/<product>/` — holds `stash.db`.
    pub app_dir: PathBuf,
    /// `~/Documents/<product>/` — the note files.
    pub notes_dir: PathBuf,
    /// The app's command socket, told about writes. `None`: nobody is told.
    pub socket: Option<PathBuf>,
}

impl StashLocation {
    pub fn paths(&self) -> StashPaths {
        StashPaths::new(self.app_dir.clone(), self.notes_dir.clone())
    }
}

/// The location of `product`'s stash under the given bases — pure, so tests
/// can name any base; `location_from_flags` passes the real ones.
pub fn location_for_product(product: &str, data_base: &Path, documents_base: &Path) -> StashLocation {
    let name = crate::paths::dir_name(product);
    StashLocation {
        app_dir: data_base.join(&name),
        notes_dir: documents_base.join(&name),
        socket: Some(crate::ai_socket::socket_path(product)),
    }
}

/// `--product` / `--socket` into a location. A socket alone is refused: it
/// names a non-release build, and the stash would silently be the release
/// one's (plan D3).
pub fn location_from_flags(product: Option<&str>, socket: Option<&str>) -> Result<StashLocation, String> {
    if socket.is_some() && product.is_none() {
        return Err("--socket names another couplet build: pass --product too (e.g. --product couplet-dev), so the stash is that build's and not the release one".to_string());
    }
    let product = product.unwrap_or(crate::paths::RELEASE_PRODUCT_NAME);
    let data = dirs::data_dir().ok_or("cannot determine the application data directory")?;
    let documents = dirs::document_dir().ok_or("cannot determine the Documents directory")?;
    let mut loc = location_for_product(product, &data, &documents);
    if let Some(s) = socket {
        loc.socket = Some(PathBuf::from(s));
    }
    Ok(loc)
}

/// A connection for reading, or `None` when the stash does not exist yet —
/// a read never creates it.
fn open_for_read(loc: &StashLocation) -> Result<Option<rusqlite::Connection>, String> {
    let db = loc.paths().db;
    if !db.exists() {
        return Ok(None);
    }
    crate::stash::db::open(&db).map(Some)
}

/// A connection for writing. Refused while the app data directory does not
/// exist: one file in a freshly created `couplet/` before the app's first
/// launch makes `migration.rs` skip an installed md-mini's data for good
/// (plan D4). Checked before anything else touches the disk.
fn open_for_write(loc: &StashLocation) -> Result<rusqlite::Connection, String> {
    if !loc.app_dir.is_dir() {
        return Err(NOT_RUN_YET.to_string());
    }
    crate::stash::db::open(&loc.paths().db)
}

pub const GET_MAX_LINES: usize = 500;
/// …and at most this many bytes (a single longer first line comes back whole).
pub const GET_MAX_BYTES: usize = 64 * 1024;

pub fn now_ms() -> i64 {
    SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_millis() as i64).unwrap_or(0)

/// `2026-09-27T01:55:12+03:00` in the machine's local zone — readable to a
/// model, unlike unix ms, and still unambiguous.
pub fn iso_local(ms: i64) -> String {
    let secs = ms.div_euclid(1000) as libc::time_t;
    // SAFETY: an all-zero `tm` is a valid value; localtime_r writes only into
    // it and reads only `secs`.
    let mut tm: libc::tm = unsafe { std::mem::zeroed() };
    if unsafe { libc::localtime_r(&secs, &mut tm) }.is_null() {
        return ms.to_string();
    }
    let offset = tm.tm_gmtoff;
    let sign = if offset < 0 { '-' } else { '+' };
    let offset = offset.abs();
    format!(
        "{:04}-{:02}-{:02}T{:02}:{:02}:{:02}{sign}{:02}:{:02}",
        tm.tm_year + 1900,
        tm.tm_mon + 1,
        tm.tm_mday,
        tm.tm_hour,
        tm.tm_min,
        tm.tm_sec,
        offset / 3600,
        (offset % 3600) / 60
    )
}

/// Local midnight of `now` minus `days_back` days, in unix ms.
fn local_day_start(now_ms: i64, days_back: i32) -> Option<i64> {
    let secs = now_ms.div_euclid(1000) as libc::time_t;
    // SAFETY: as in `iso_local`; mktime normalises the fields it is given
    // (a day of 0 or less rolls back into the previous month).
    let mut tm: libc::tm = unsafe { std::mem::zeroed() };
    if unsafe { libc::localtime_r(&secs, &mut tm) }.is_null() {
        return None;
    }
    tm.tm_hour = 0;
    tm.tm_min = 0;
    tm.tm_sec = 0;
    tm.tm_mday -= days_back;
    tm.tm_isdst = -1;
    let t = unsafe { libc::mktime(&mut tm) };
    (t != -1).then_some(t as i64 * 1000)
}

fn local_midnight(year: i32, month: i32, day: i32) -> Option<i64> {
    if !(1..=12).contains(&month) || !(1..=31).contains(&day) {
        return None;
    }
    // SAFETY: an all-zero `tm` is valid; mktime reads and normalises it.
    let mut tm: libc::tm = unsafe { std::mem::zeroed() };
    tm.tm_year = year - 1900;
    tm.tm_mon = month - 1;
    tm.tm_mday = day;
    tm.tm_isdst = -1;
    let t = unsafe { libc::mktime(&mut tm) };
    // mktime turns 2026-02-31 into March 3rd: accept only a date that survived.
    (t != -1 && tm.tm_mday == day && tm.tm_mon == month - 1).then_some(t as i64 * 1000)
}

/// `--since` / `since`: `today`, `yesterday`, `12h`, `7d`, `YYYY-MM-DD`, or unix ms.
pub fn parse_since(s: &str, now_ms: i64) -> Result<i64, String> {
    let bad = || format!("invalid since: {s:?} (expected today, yesterday, 12h, 7d, YYYY-MM-DD or unix ms)");
    let t = s.trim();
    let digits = |x: &str| !x.is_empty() && x.bytes().all(|b| b.is_ascii_digit());
    match t {
        "today" => return local_day_start(now_ms, 0).ok_or_else(bad),
        "yesterday" => return local_day_start(now_ms, 1).ok_or_else(bad),
        _ => {}
    }
    if let Some(n) = t.strip_suffix('h').filter(|n| digits(n)) {
        return n.parse::<i64>().map(|n| now_ms - n * 3_600_000).map_err(|_| bad());
    }
    if let Some(n) = t.strip_suffix('d').filter(|n| digits(n)) {
        return n.parse::<i64>().map(|n| now_ms - n * 86_400_000).map_err(|_| bad());
    }
    let b = t.as_bytes();
    if t.len() == 10 && b[4] == b'-' && b[7] == b'-' && digits(&t[0..4]) && digits(&t[5..7]) && digits(&t[8..10]) {
        let (y, m, d) = (t[0..4].parse().map_err(|_| bad())?, t[5..7].parse().map_err(|_| bad())?, t[8..10].parse().map_err(|_| bad())?);
        return local_midnight(y, m, d).ok_or_else(bad);
    }
    if digits(t) {
        return t.parse().map_err(|_| bad());
    }
    Err(bad())
}

/// A 1-based inclusive line range; `to: None` runs to the last line.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct LineRange {
    pub from: usize,
    pub to: Option<usize>,
}

/// `A:B`, `A:` or `:B`.
pub fn parse_lines(s: &str) -> Result<LineRange, String> {
    let bad = || format!("invalid line range: {s:?} (expected A:B, A: or :B, 1-based)");
    let (a, b) = s.split_once(':').ok_or_else(bad)?;
    let num = |t: &str| -> Result<Option<usize>, String> {
        if t.is_empty() {
            return Ok(None);
        }
        if !t.bytes().all(|c| c.is_ascii_digit()) {
            return Err(bad());
        }
        t.parse::<usize>().map(Some).map_err(|_| bad())
    };
    let from = num(a)?.unwrap_or(1);
    let to = num(b)?;
    if from == 0 || to == Some(0) || to.is_some_and(|t| t < from) {
        return Err(bad());
    }
    Ok(LineRange { from, to })
}

#[derive(Debug, PartialEq, Eq)]
pub struct Sliced {
    pub text: String,
    /// The lines actually returned; `[0, 0]` for an empty note.
    pub lines: [usize; 2],
    pub total_lines: usize,
    /// Fewer lines than asked for came back (a cap was hit).
    pub truncated: bool,
}

pub fn slice_lines(text: &str, range: Option<LineRange>) -> Result<Sliced, String> {
    let all: Vec<&str> = text.lines().collect();
    let total = all.len();
    let range = range.unwrap_or(LineRange { from: 1, to: None });
    if total == 0 && range.from == 1 {
        return Ok(Sliced { text: String::new(), lines: [0, 0], total_lines: 0, truncated: false });
    }
    if range.from > total {
        return Err(format!("line {} is past the end of the note ({total} lines)", range.from));
    }
    let wanted_to = range.to.unwrap_or(total).min(total);
    let mut out = String::new();
    let mut last = range.from - 1;
    for (i, line) in all[range.from - 1..wanted_to].iter().enumerate() {
        let over_lines = i >= GET_MAX_LINES;
        let over_bytes = !out.is_empty() && out.len() + 1 + line.len() > GET_MAX_BYTES;
        if over_lines || over_bytes {
            break;
        }
        if !out.is_empty() {
            out.push('\n');
        }
        out.push_str(line);
        last = range.from + i;
    }
    Ok(Sliced { text: out, lines: [range.from, last], total_lines: total, truncated: last < wanted_to })
}

/// Trim, strip a leading `#`, lower-case; one word each; duplicates dropped.
pub fn normalize_tags(raw: &[String]) -> Result<Vec<String>, String> {
    let mut out: Vec<String> = Vec::new();
    for t in raw {
        let tag = t.trim().trim_start_matches('#').to_lowercase();
        if tag.is_empty() {
            return Err(format!("empty tag: {t:?}"));
        }
        if tag.chars().any(char::is_whitespace) {
            return Err(format!("a tag is one word: {t:?}"));
        }
        if !out.contains(&tag) {
            out.push(tag);
        }
    }
    Ok(out)
}

/// At most `max` characters, with `…` when cut.
pub fn clip(s: &str, max: usize) -> String {
    if s.chars().count() <= max {
        return s.to_string();
    }
    let mut out: String = s.chars().take(max).collect();
    out.push('…');
    out
}

        Ok(None) => return StashAnswer::error(format!("no stash entry {id}")),
        Err(e) => return StashAnswer::error(e),
    };
    let entry = match crate::stash::entries::get(&conn, id) {
        Ok(Some(e)) => e,
        Ok(None) => return StashAnswer::error(format!("no stash entry {id}")),
        Err(e) => return StashAnswer::error(e),
    };
    if entry.deleted_at.is_some() {
        return StashAnswer::error(format!("stash entry {id} is in the trash"));
    }
    let mut answer = StashAnswer { ok: true, entry: Some(agent_entry(&entry)), ..Default::default() };
    if entry.kind == StashKind::File {
        if lines.is_some() {
            return StashAnswer::error(format!("{id} is a file reference: read {} directly", entry.path));
        }
        answer.hint = Some(format!("a file reference: read {} directly", entry.path));
        return answer;
    }
    let text = match fs::read_to_string(&entry.path) {
        Ok(t) => t,
        Err(e) => return StashAnswer::error(format!("cannot read the note file {}: {e}", entry.path)),
    };
    match slice_lines(&text, lines) {
        Ok(s) => {
            if s.truncated {
                answer.hint = Some(format!(
                    "showing lines {}–{} of {}; the rest with lines {}:",
                    s.lines[0],
                    s.lines[1],
                    s.total_lines,
                    s.lines[1] + 1
                ));
            }
            answer.text = Some(s.text);
            answer.lines = Some(s.lines);
            answer.total_lines = Some(s.total_lines);
            answer.truncated = Some(s.truncated);
            answer
        }
        Err(e) => StashAnswer::error(e),
    }
}

const NOTIFY_TIMEOUT: Duration = Duration::from_millis(500);

/// Tell a running couplet the stash changed under it, so its drawers reload
/// (plan D12). Best effort by design: the write is already on disk, and an
/// app that is not running reads the database fresh when it starts — there
/// is nobody to tell and nothing to report. Never launches the app.
pub fn notify(loc: &StashLocation, reason: &str) {
    let Some(socket) = &loc.socket else { return };
    let Ok(mut stream) = UnixStream::connect(socket) else { return };
    let _ = stream.set_write_timeout(Some(NOTIFY_TIMEOUT));
    let _ = stream.set_read_timeout(Some(NOTIFY_TIMEOUT));
    let request = crate::ai_socket::AiRequest::StashChanged { v: 1, reason: reason.to_string() };
    let Ok(mut line) = serde_json::to_string(&request) else { return };
    line.push('\n');
    if stream.write_all(line.as_bytes()).is_err() {
        return;
    }
    // Wait for the one answer line so the app's reply does not meet a closed
    // socket; what it says does not matter.
    let mut answer = String::new();
    let _ = BufReader::new(stream).read_line(&mut answer);
}

/// The first put-away result, or an error naming what was attempted.
fn first_result(results: Vec<crate::stash::entries::PutAwayResult>, what: &str) -> Result<crate::stash::entries::PutAwayResult, String> {
    results.into_iter().next().ok_or_else(|| format!("nothing was put away for {what}"))
}

/// A new note from text, put away at once — «отложено только что» (plan D11).
pub fn add_note(ctx: &Ctx, text: &str, tags: &[String]) -> StashAnswer {
    if text.trim().is_empty() {
        return StashAnswer::error("refusing to add an empty note");
    }
    let tags = match normalize_tags(tags) {
        Ok(t) => t,
        Err(e) => return StashAnswer::error(e),
    };
    let conn = match open_for_write(ctx.loc) {
        Ok(c) => c,
        Err(e) => return StashAnswer::error(e),
    };
    let paths = ctx.loc.paths();
    let repo = repo_of_dir(ctx.cwd);
    let note = match crate::stash::entries::create_note(&conn, &paths, text, repo.as_deref()) {
        Ok(n) => n,
        Err(e) => return StashAnswer::error(e),
    };
    let request = PutAwayRequest { paths: vec![note.path.clone()], tags, ..Default::default() };
    let result = crate::stash::entries::put_away(&conn, &paths, &request).and_then(|r| first_result(r, &note.path));
    match result {
        Ok(r) => {
            notify(ctx.loc, "add");
            StashAnswer { ok: true, entry: Some(agent_entry(&r.entry)), created: Some(true), ..Default::default() }
        }
        // The note exists (an open-state note, visible in the stash); say so.
        Err(e) => StashAnswer::error(format!("note {} was created but could not be put away: {e}", note.id)),
    }
}

        Err(e) => return StashAnswer::error(e),

        Ok(m) if m.is_file() => {}
        Ok(_) => return StashAnswer::error(format!("not a file: {abs}")),
        Err(_) => return StashAnswer::error(format!("file does not exist: {abs}")),
    }
    let conn = match open_for_write(ctx.loc) {
        Ok(c) => c,
        Err(e) => return StashAnswer::error(e),
    };
    let request = PutAwayRequest { paths: vec![abs.clone()], tags, ..Default::default() };
    match crate::stash::entries::put_away(&conn, &ctx.loc.paths(), &request).and_then(|r| first_result(r, &abs)) {
        Ok(r) => {
            notify(ctx.loc, "add");
            StashAnswer { ok: true, entry: Some(agent_entry(&r.entry)), created: Some(r.created), ..Default::default() }
        }
        Err(e) => StashAnswer::error(e),
    }
}

pub fn tag(ctx: &Ctx, id: &str, add: &[String], remove: &[String]) -> StashAnswer {
    if add.is_empty() && remove.is_empty() {
        return StashAnswer::error("tag needs something to add or remove");
    }
    let (add, remove) = match (normalize_tags(add), normalize_tags(remove)) {
        (Ok(a), Ok(r)) => (a, r),
        (Err(e), _) | (_, Err(e)) => return StashAnswer::error(e),
    };
    let conn = match open_for_write(ctx.loc) {
        Ok(c) => c,
        Err(e) => return StashAnswer::error(e),
    };
    match crate::stash::entries::get(&conn, id) {
        Ok(Some(e)) if e.deleted_at.is_some() => return StashAnswer::error(format!("stash entry {id} is in the trash")),
        Ok(Some(_)) => {}
        Ok(None) => return StashAnswer::error(format!("no stash entry {id}")),
        Err(e) => return StashAnswer::error(e),
    }
    match crate::stash::entries::tag(&conn, id, &add, &remove) {
        Ok(entry) => {
            notify(ctx.loc, "tag");
            StashAnswer { ok: true, entry: Some(agent_entry(&entry)), ..Default::default() }
        }
        Err(e) => StashAnswer::error(e),
    }
}

pub(crate) fn parse_kind(s: &str) -> Result<StashKind, String> {

        "file" => Ok(StashKind::File),

pub(crate) fn parse_sort(s: &str) -> Result<ListSort, String> {
    match s {
        "changed" => Ok(ListSort::Changed),

        other => Err(format!("invalid sort: {other} (changed, opened or kind)")),

fn parse_limit(s: &str) -> Result<u32, String> {
    match s.parse::<u32>() {
        Ok(n) if n >= 1 && s.bytes().all(|b| b.is_ascii_digit()) => Ok(n),
        _ => Err(format!("invalid limit: {s} (a positive number)")),

pub fn parse_stash_args(args: &[String]) -> Result<StashCli, String> {
    let mut iter = args.iter();
    let verb = iter.next().ok_or_else(|| STASH_USAGE.to_string())?.clone();
    let v = verb.as_str();
    let filtered = matches!(v, "search" | "list");

    let (mut json, mut product, mut socket) = (false, None, None);
    let mut positional: Vec<String> = Vec::new();
    let mut filter = Filter::default();
    let (mut limit, mut cursor, mut since, mut sort, mut lines, mut path) = (None, None, None, None, None, None);
    let (mut tags, mut add, mut remove) = (Vec::new(), Vec::new(), Vec::new());
    let (mut repo_given, mut all_given) = (false, false);

    while let Some(arg) = iter.next() {
        let flag = arg.as_str();
        let mut value = || iter.next().cloned().ok_or_else(|| format!("{flag} requires a value"));
        match flag {
            "--json" => json = true,
            "--product" => product = Some(value()?),
            "--socket" => socket = Some(value()?),
            "--tag" if v == "add" => tags.push(value()?),
            "--tag" if filtered => filter.tag = Some(value()?),
            "--repo" if filtered => {
                filter.scope = ScopeArg::Repo(value()?);
                repo_given = true;
            }
            "--all" if filtered => {
                filter.scope = ScopeArg::All;
                all_given = true;
            }
            "--kind" if filtered => filter.kind = Some(parse_kind(&value()?)?),
            "--limit" if filtered => limit = Some(parse_limit(&value()?)?),
            "--cursor" if filtered => cursor = Some(value()?),
            "--since" if v == "list" => since = Some(value()?),
            "--sort" if v == "list" => sort = Some(parse_sort(&value()?)?),
            "--lines" if v == "get" => lines = Some(parse_lines(&value()?)?),
            "--path" if v == "add" => path = Some(value()?),
            "--add" if v == "tag" => add.push(value()?),
            "--remove" if v == "tag" => remove.push(value()?),
            other if other.starts_with("--") => return Err(format!("unknown flag for stash {verb}: {other}")),
            _ => positional.push(arg.clone()),
        }
    }
    if repo_given && all_given {
        return Err("--repo and --all are mutually exclusive".to_string());
    }
    let no_positional = |p: &[String]| match p.first() {
        Some(extra) => Err(format!("stash {verb} takes no argument: unexpected {extra}")),
        None => Ok(()),
    };
    let one_id = |p: Vec<String>| match p.as_slice() {
        [id] => Ok(id.clone()),
        [] => Err(format!("stash {verb} needs an entry id")),
        _ => Err(format!("stash {verb} takes one entry id")),
    };
    let verb = match v {
        "search" => {
            if positional.is_empty() {
                return Err("stash search needs a query".to_string());
            }
            StashVerb::Search(SearchArgs { query: positional.join(" "), filter, limit, cursor })
        }
        "list" => {
            no_positional(&positional)?;
            StashVerb::List(ListArgs { filter, since, sort, limit, cursor })
        }
        "get" => StashVerb::Get { id: one_id(positional)?, lines },
        "add" => {
            no_positional(&positional)?;
            StashVerb::Add { tags, path }
        }
        "tag" => {
            let id = one_id(positional)?;
            if add.is_empty() && remove.is_empty() {
                return Err("stash tag needs --add or --remove".to_string());
            }
            StashVerb::Tag { id, add, remove }
        }
        other => return Err(format!("unknown stash command: {other}\n{STASH_USAGE}")),
    };
    Ok(StashCli { verb, json, product, socket })
}

fn kind_word(kind: &StashKind) -> &'static str {
    match kind {
        StashKind::Note => "note",
        StashKind::File => "file",

/// `2026-09-27T01:55:12+03:00` → `2026-09-27 01:55`.
fn short_time(iso: &str) -> String {
    iso.get(..16).map(|s| s.replacen('T', " ", 1)).unwrap_or_else(|| iso.to_string())
}

fn entry_line(e: &AgentEntry) -> String {
    let mut line = format!("{}  {}  {}", e.id, kind_word(&e.kind), e.title.as_deref().unwrap_or("(untitled)"));
    for t in &e.tags {
        line.push_str(&format!("  #{t}"));
    }
    if let Some(r) = &e.repo {
        line.push_str(&format!("  [{r}]"));
    }
    if let Some(s) = &e.stashed_at {
        line.push_str(&format!("  {}", short_time(s)));
    }
    line
}

fn render_rows(a: &StashAnswer) -> String {
    let mut out = Vec::new();
    for h in a.hits.iter().flatten() {
        out.push(entry_line(&h.entry));
        out.push(format!("    {}", h.snippet.replace('\n', " ")));
    }
    for e in a.entries.iter().flatten() {
        out.push(entry_line(e));
    }
    let shown = a.hits.as_ref().map(Vec::len).or_else(|| a.entries.as_ref().map(Vec::len)).unwrap_or(0);
    let scope = match &a.scope {
        Some(Scope { repo: Some(r), .. }) => format!(" in repo {r}"),
        _ => " in the whole stash".to_string(),
    };
    let mut footer = format!("{shown} of {}{scope}", a.total.unwrap_or(0));
    if let Some(c) = &a.next_cursor {
        footer.push_str(&format!(" · next page: --cursor {c}"));
    }
    out.push(footer);
    out.extend(a.hint.clone());
    out.join("\n")
}

/// `(stdout, stderr)` for one answer. JSON: the answer, one line, even on
/// failure. Text: rows for search/list, the raw note for get (so
/// `couplet stash get ID > file` works), one row for add/tag; an error is
/// words on stderr and nothing on stdout.
pub fn render(answer: &StashAnswer, verb: &StashVerb, json: bool) -> (String, String) {
    if json {
        let line = serde_json::to_string(answer)
            .unwrap_or_else(|_| r#"{"ok":false,"error":"failed to encode the answer"}"#.to_string());
        return (line, String::new());
    }
    if !answer.ok {
        return (String::new(), format!("couplet: {}", answer.error.as_deref().unwrap_or("failed")));
    }
    let hint_err = || answer.hint.as_ref().map(|h| format!("couplet: {h}")).unwrap_or_default();
    match verb {
        StashVerb::Search(_) | StashVerb::List(_) => (render_rows(answer), String::new()),
        StashVerb::Get { .. } => match (&answer.text, &answer.entry) {
            (Some(text), _) => (text.clone(), hint_err()),
            (None, Some(e)) => (e.path.clone(), hint_err()),
            (None, None) => (String::new(), String::new()),
        },
        StashVerb::Add { .. } | StashVerb::Tag { .. } => {
            let mut line = answer.entry.as_ref().map(entry_line).unwrap_or_default();
            if answer.created == Some(false) {
                line.push_str("  (already in the stash)");
            }
            (line, String::new())
        }
    }
}

    let all = v.get("all").and_then(Value::as_bool).unwrap_or(false);

    /// the slice after the `mcp` verb).
    fn from_flags(args: &[String]) -> Self {
        let mut socket: Option<String> = None;
        let mut product: Option<String> = None;
        let mut iter = args.iter();
        while let Some(arg) = iter.next() {
            match arg.as_str() {
                "--socket" => socket = iter.next().cloned(),
                "--product" => product = iter.next().cloned(),
                _ => {}
            }
        }
        let stash = crate::stash::cli::location_from_flags(product.as_deref(), socket.as_deref());
        let release = crate::paths::RELEASE_PRODUCT_NAME;
        let (socket_path, allow_launch) = match (socket, product.as_deref()) {
            (Some(s), _) => (PathBuf::from(s), false),
            (None, Some(p)) => (ai_socket::socket_path(p), p == release),
            (None, None) => (ai_socket::socket_path(release), true),
        };
        McpConfig { socket_path, allow_launch, stash, cwd: std::env::current_dir().unwrap_or_default() }
    }

fn stash_tool_call(id: Value, tool: &str, arguments: &Value, config: &McpConfig) -> String {
    use crate::stash::cli as stash;
    let loc = match &config.stash {
        Ok(loc) => loc,
        Err(e) => return stash_result(id, &stash::StashAnswer::error(e.clone())),
    };
    let ctx = stash::Ctx { loc, cwd: &config.cwd, now_ms: stash::now_ms() };
    let answer = match tool {
        "search" => match stash::search_args_from_json(arguments) {
            Ok(args) => stash::search(&ctx, &args),
            Err(msg) => return error_response(id, -32602, msg),
        },
        "list" => match stash::list_args_from_json(arguments) {
            Ok(args) => stash::list(&ctx, &args),
            Err(msg) => return error_response(id, -32602, msg),
        },
        "get" => {
            let Some(entry_id) = arguments.get("id").and_then(Value::as_str) else {
                return error_response(id, -32602, "stash_get requires id");
            };
            let lines = match arguments.get("lines").and_then(Value::as_str).map(stash::parse_lines).transpose() {
                Ok(l) => l,
                Err(msg) => return error_response(id, -32602, msg),
            };
            stash::get(&ctx, entry_id, lines)
        }
        "add" => {
            let tags = stash::string_array(arguments, "tags");
            match (arguments.get("text").and_then(Value::as_str), arguments.get("path").and_then(Value::as_str)) {
                (Some(text), None) => stash::add_note(&ctx, text, &tags),
                (None, Some(path)) => stash::add_path(&ctx, path, &tags),
                _ => return error_response(id, -32602, "stash_add takes exactly one of text or path"),
            }
        }
        "tag" => {
            let Some(entry_id) = arguments.get("id").and_then(Value::as_str) else {
                return error_response(id, -32602, "stash_tag requires id");
            };
            stash::tag(&ctx, entry_id, &stash::string_array(arguments, "add"), &stash::string_array(arguments, "remove"))
        }
        other => return error_response(id, -32602, format!("unknown tool: stash_{other}")),
    };
    stash_result(id, &answer)
}

    let text = serde_json::to_string(answer).unwrap_or_else(|_| "{}".to_string());

## Known gaps and risks carried out of this plan

- **Repository by name.** Scope compares the repository's directory name (the contract's `entries.repo`), so two checkouts named `api` share one scope. A path-keyed repo column would fix it; out of scope (schema v1 is fixed).
- **MCP cwd is fixed at spawn.** An agent that `cd`s elsewhere keeps the server's original scope; it can pass `repo` (a path works) or `all`.
- **`get` of a single enormous line** returns it whole (the byte cap applies from the second line on).
- **No agent access to the trash**, by design (D9).
- **Delivery of `stash-changed` is best effort:** a write while the app is busy starting may not be announced; the drawer shows it on its next reload.
