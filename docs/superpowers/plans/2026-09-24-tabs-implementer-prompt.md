## Как работать
- **Субагенты, строго по одному за раз.** Реализацию веди через `superpowers:subagent-driven-development`: свежий субагент на задачу, ревью между задачами. Никогда не запускай двух субагентов параллельно: ни несколько Agent-вызовов в одном сообщении, ни Workflow, ни agent teams. Сам пиши минимум кода: ты оркестратор и ревьюер.
- **Соблюдай план.** Задачи плана выполняются в его порядке, с его тестами. Если план расходится с кодом (строки уехали, функция называется иначе), подстрой шаг под реальный код, не меняя смысла задачи, и отметь это в ночном отчёте. Если план расходится со спекой, права спека: спроси архитектора (ниже).
- **Порядок работ:**
  1. Worktree через `EnterWorktree` (имя, например, `tabs-impl`), затем `git fetch && git merge origin/worktree-tabs-design-research`.
  2. **План 01.** Ветка `feat/tabs-foundation`. Выполнить план целиком. В конце `code-reviewer` по всему диффу, исправить найденное, запушить ветку, открыть **draft PR** в main.
  3. **Планы 02 → 03 → 04 → 05 по очереди.** Ветка `feat/tabs` от `feat/tabs-foundation`. Для каждого плана:
     1. напиши детальный план скиллом `superpowers:writing-plans` в `docs/superpowers/plans/2026-09-2X-tabs-0N-<name>.md`, по спеке, дорожной карте и макету, сверяясь с текущим кодом;
     2. отправь путь архитектору на ревью (ниже) и подожди ответа до 20 минут;
     3. исполни план;
     4. прогони `code-reviewer`, исправь найденное, закоммить, запушь.

     В конце — один draft PR `feat/tabs` в main.
  4. Перед планом 05 ручной тест про pointer-события за краем окна сделать нельзя: нет мыши. Строй механизм с запасным путём (опрос `cursor_position` во время drag), а сам тест вынеси в вопросы на утро.
- **Проверки после каждой задачи:** `npx vitest run --dir src`, `cd src-tauri && cargo test`. В конце каждого плана дополнительно `cargo clippy --manifest-path src-tauri/Cargo.toml`, `npm run check`, `npm run check:x86`. Визуал планов 03 и 05 сверяй с макетом: `npm run dev` + Playwright (`chromium.launch({ channel: 'chrome' })`) и `npm run dev:app`. Скриншоты сохраняй в `docs/superpowers/plans/night-shots/`.
