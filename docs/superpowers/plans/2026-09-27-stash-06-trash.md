# Stash 06 — Trash («Удалённые») Implementation Plan

> **⚠️ Roadmap amendments override this plan.** Read the section «Amendments after planning» in `2026-09-27-stash-00-roadmap.md` first. Most visible here: **A1 — the notes folder is `~/couplet/` (dev `~/couplet-dev/`), not `~/Documents/…`**: use `dirs::home_dir()` instead of `dirs::document_dir()`, rename every `Documents` base in tests to a home base, and drop every TCC-prompt note or step (the home root is not TCC-protected). Also A2 (offline build, `functions` feature), A3 (`repo` = directory name) and A5 (schema v2).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deleting a stash note moves its file into `~/Documents/<product>/.trash/` and marks it `deleted_at`, instead of destroying anything; the stash drawer gets an «Удалённые» view (dimmed cards, «удалится через N дн.», «вернуть» / «удалить навсегда»); a restored note comes back on top with its tags; notes older than 30 days in the trash are purged at startup and once a day; removing a file reference drops only the entry and its tags — the file is never touched.

**Architecture:** A new Rust module `stash/trash.rs` holds three filesystem-first operations over the stage 02 connection — `delete`, `restore`, `purge` (+ `purge_expired`, `reconcile`) — each of which moves a file with a no-clobber `rename` and then changes the row in one transaction, rolling the file back if the transaction fails. The row's `path` always names where the file **is** (the trash path while deleted), so every existing reader (preview, `on_file_written`, backups) stays correct without a second column. A note that is open in a tab anywhere is first dropped from that tab by **the window that holds it** — Rust asks it with a targeted `stash-drop-tab` event and waits for `stash_drop_done`; the window leaves the tab the normal controller way (flush autosave, refuse if the save did not land, `tab_release`) — and only then is the file moved, so no autosave can recreate it. The frontend adds a pure `trash-view.ts` (days left, filter, key decisions), a `trash-mode.svelte.ts` composed into stage 04's `stash-store`, `TrashBar.svelte` / `TrashCard.svelte`, a delete button on `StashCard.svelte`, and a controller method `dropPath`.

**Tech Stack:** Tauri 2 (Rust), `rusqlite` (from stage 02), `libc::renamex_np` (already a direct dependency), Svelte 5 runes, vitest, cargo test, Playwright (Google Chrome channel) for the visual check.

**Spec (behaviour wins):** `docs/superpowers/specs/2026-09-26-stash-design.md` — «Модель» (Удалить), «Жизненный цикл заметки», «Дровер тайника → Корзина». **Mockup (look wins):** `docs/investigations/2026-09-26-stash-mockup/stash-drawers.html` (`renderTrash`, `renderTrashBar`, `trCardHTML`, `trashAction`, `removeFromStash`, the keyboard handler), shot `shots/07-trash-view.png`. **Roadmap:** `docs/superpowers/plans/2026-09-27-stash-00-roadmap.md` row 06 and «Shared contracts».

**Depends on:** stages 02–05 on `feat/stash`. This plan names their functions by the roadmap's contracts; where a stage chose a different name or signature, Task 0 records the real one and every later step uses it — never add a second function that does the same thing.

The **only** code in this stage that deletes a note's bytes is `trash::purge`, and it deletes only a regular file whose canonical parent is the canonical notes trash directory.

## Design decisions this plan commits to

| # | Decision | Why |
|---|---|---|
| D1 | `entries.path` always names where the file is: the trash path while `deleted_at` is set, the notes-dir path otherwise. No `trash_path` column, no schema change. | Preview, backups, `on_file_written` and purge all read one column and are right by construction. The old path is freed at once, so a stale reference to it (Recent Files, an old ⌘⇧T entry) can never be mistaken for the trashed entry — `closed::pop_live` already skips a path whose file is gone. |
| D2 | Order of a note delete: (1) the window holding its tab (if any) drops the tab — flush, refuse if the save did not land, swap away, `tab_release`; (2) Rust re-checks nobody holds the path; (3) no-clobber rename into `.trash/`; (4) one transaction: `path`, `deleted_at`, FTS row removed. A failed (4) renames the file back. | The file moves only after the last keystroke is on disk and no autosave is bound to its path any more, so nothing can write it back to the notes folder. Rename before the DB change means a crash leaves the text in exactly one place, which `reconcile` finds (D10). |
| D3 | One path for "open in a tab", whichever window: Rust asks the owner window with `stash-drop-tab` and waits up to `DROP_REPLY_TIMEOUT` = 10 s for `stash_drop_done`, off the async runtime (`spawn_blocking` + `recv_timeout`, the `ai_socket` pattern). | The spec hides a note open in *this* window from this window's stash, so the card a human actually clicks is the one marked «открыта в #N» — the other-window case is the common one. Letting the owner window drop its own tab keeps "only the controller changes what a window shows" true. |
| D4 | Dropping the window's **only** tab opens a fresh empty tab in its place (`newTabNow`), the window stays. | The human acted inside a drawer, possibly of another window; closing a numbered, project-bound window as a side effect of a delete would surprise. An empty tab vanishes on its own when closed (stage 03). |
| D5 | A drop is a **release**, not a close: Rust `tab_release` — no ⌘⇧T entry, no stage 03 put-away, agents waiting on the tab get `tab released`. | ⌘⇧T of a trashed note would reopen an empty document at a path that no longer holds it. Putting away a note that is about to be deleted would stamp `stashed_at` for nothing. |
| D6 | Moves use `renamex_np(RENAME_EXCL)`; on `ENOTSUP` fall back to `link` + `unlink` (also no-clobber); on `EXDEV` (a `.trash` the user replaced with a symlink to another volume) copy with `create_new` → `sync_all` → re-read and compare bytes → only then remove the source. | `fs::rename` silently replaces an existing destination on macOS. Each fallback keeps "never overwrite" and "second copy before removal". |
| D7 | A name already taken — on disk (any entry, even a dangling symlink) **or** by another row's `path` — gets a suffix before the extension: `x.md` → `x-2.md` → `x-3.md`, up to `-999`, in the trash and on restore alike. A race that takes the name between the check and the rename (`EEXIST`) retries with the next free name, at most 5 times. | Note names are time + random and almost never collide; when they do (a leftover from a crash, a hand-copied file) nothing may be overwritten and `UNIQUE(path)` must not make the transaction fail after the file moved. |
| D8 | Restore: file back into the notes dir (collision → suffix), `deleted_at = NULL`, `stashed_at = now`, `opened_at` and tags untouched, FTS row re-added after the commit (best effort, logged). | Stage 04's «изменение» sort orders by the newer of edit and put-away (mockup `lastTouch`), so `stashed_at = now` is what puts it «наверху» as the toast says. The FTS index is derived and rebuildable; a failed index must not undo a restore. |
| D9 | Purge deletes a file only when `symlink_metadata` says **regular file** and `canonicalize(parent) == canonicalize(notes_trash_dir)`. Anything else — outside the trash, a symlink, a directory, a `..` path — is refused: manual purge returns `Err`, auto-purge logs and skips that row. A file already gone just removes the row. Purge applies only to `kind = 'note' AND deleted_at IS NOT NULL`. | The one irreversible operation gets the narrowest possible target. A tampered or corrupt row cannot turn purge into a delete of a real document. |
| D10 | Housekeeping thread: at startup, then every hour it checks whether ≥ 24 h of wall clock passed since its last run (or the clock went backwards) and if so runs `reconcile` then `purge_expired(now)`. Cutoff: `deleted_at <= now − 30 d`. | `thread::sleep` uses a clock that stops while the Mac sleeps; an hourly check against wall time is what "once a day" means on a laptop. Startup runs catch everything that expired while the app was closed. |
| D11 | `reconcile` finishes an interrupted move: a live note whose file is missing while `.trash/<name>` exists → mark deleted; a trashed note whose file is missing while `notes/<name>` exists (and no other row holds it) → mark restored. Anything else is left alone. | Rename-then-DB (D2) can be cut by a crash between the two. Only the exact name is looked for; a suffixed restore that was cut leaves an orphan file in the notes folder — text kept, never deleted. |
| D12 | File references have no trash: `stash_delete` on a `file` entry deletes the row (tags cascade) and its FTS row, even if the file is open in a tab (the tab is unaffected). | Spec: «удаляется только ссылка, файл на месте». |
| D13 | Trashed notes are not in the FTS index, so `stash_search` (human and agent) never returns them. The trash view filters client-side: stage 04's query parser, `#tag` prefix match on tags + repo, plain text as a case-insensitive substring of title and preview. The trash view ignores the repo chip; sorted newest deletion first; no sort row, ⌘L/⌘R/⌘U are swallowed no-ops. | Mockup `renderTrash`. The trash holds at most 30 days of deletions; a second index for it is not worth it. |
| D14 | Trash keys: typing filters; first Esc clears the query, the next returns to the stash (the drawer stays open); Backspace edits the query and does nothing on an empty one (no repo chip here); ←/→ still move focus between drawers. No keyboard ring on trash cards (mockup: `stView = []`). Closing the stash, reopening it, ⌃S, and **any put-away** (drop zone, ⌃T, «В тайник») return the drawer to the stash view with an empty query. | Mockup keyboard handler, `openStash`, `closeStash`, `stashTabs`. |
| D15 | «удалить навсегда» acts at once, no confirmation. | Approved mockup. Deliberate: it is the second step (the note already sat in the trash). Revisit only on owner feedback. |
| D16 | A comment sidecar (`.mdmini_comments_<name>`) travels with its note into the trash and back (renamed to match a suffixed name), best effort; purge removes it under the same guard as the note. | The sidecar quotes the note; leaving it behind would keep deleted text readable in the notes folder, and restoring without it would lose threads. Best effort because the note's own text matters more than a failed sidecar move. |
| D17 | `OpenFiles` and `StashState` are never held at the same time. `stash_delete` reads the owner under a short `OpenFiles` lock, drops it, and only then locks `StashState`. | Adds no edge to the lock-order graph in CLAUDE.md. The window between the check and the rename is harmless: a tab opened on the old path after the move sees a missing file (an empty new document) — nothing already written is lost. |
| D18 | Guards on trashed entries: `stash_put_away` of a trashed entry's path and `stash_tag` on a trashed entry return `Err("in the trash")`; `on_file_written` ignores trashed rows. | Otherwise opening `.trash/x.md` by hand and saving it would bump a trashed row's `modified_at`, and a put-away dedup hit would stamp `stashed_at` on a row that stays deleted. |
| D19 | Stash toasts of this stage (`stash-trash`) go by themselves after 6 s like `tabs-moved`; `stash-trash-kept` and `stash-trash-error` stand until dismissed. If stage 04 already established a stash toast kind and timing, follow stage 04 instead and note it in the commit. | Success reports would pile up; a refusal or failure must be read. |

- [ ] **Step 1: Write the failing tests**

Create `src-tauri/src/stash/trash.rs` with the module doc and the test module only:

```rust
//! The note trash (stage 06): delete moves a note's file into
//! `notes_trash_dir`, restore moves it back, purge is the one place that
//! deletes a note's bytes — and only a regular file inside that directory.
//! Every move is no-clobber; every move across volumes copies, verifies and
//! only then removes the source.

#[cfg(test)]
mod tests {
    use super::*;
    use crate::atomic_write::testkit::scratch;
    use std::fs;
    use std::os::unix::fs::symlink;

    fn never_taken(_: &Path) -> bool {
        false
    }

    #[test]
    fn unique_target_returns_the_plain_name_when_free() {
        let dir = scratch("trash-uniq-free");
        assert_eq!(unique_target(&dir, "a.md", never_taken).unwrap(), dir.join("a.md"));
    }

    #[test]
    fn unique_target_suffixes_before_the_extension() {
        let dir = scratch("trash-uniq-suffix");
        fs::write(dir.join("a.md"), "1").unwrap();
        assert_eq!(unique_target(&dir, "a.md", never_taken).unwrap(), dir.join("a-2.md"));
        fs::write(dir.join("a-2.md"), "2").unwrap();
        assert_eq!(unique_target(&dir, "a.md", never_taken).unwrap(), dir.join("a-3.md"));
    }

    #[test]
    fn unique_target_handles_names_without_extension_and_dotfiles() {
        let dir = scratch("trash-uniq-noext");
        fs::write(dir.join("notes"), "1").unwrap();
        assert_eq!(unique_target(&dir, "notes", never_taken).unwrap(), dir.join("notes-2"));
        fs::write(dir.join(".mdmini_comments_a.md"), "1").unwrap();
        assert_eq!(
            unique_target(&dir, ".mdmini_comments_a.md", never_taken).unwrap(),
            dir.join(".mdmini_comments_a-2.md")
        );
    }

    #[test]
    fn unique_target_skips_names_another_row_holds() {
        let dir = scratch("trash-uniq-db");
        let taken = dir.join("a.md");
        assert_eq!(
            unique_target(&dir, "a.md", |p| p == taken).unwrap(),
            dir.join("a-2.md")
        );
    }

    #[test]
    fn unique_target_treats_a_dangling_symlink_as_taken() {
        let dir = scratch("trash-uniq-dangling");
        symlink(dir.join("nowhere"), dir.join("a.md")).unwrap();
        assert_eq!(unique_target(&dir, "a.md", never_taken).unwrap(), dir.join("a-2.md"));
    }

    #[test]
```

```rust
use std::fs;
use std::io::{ErrorKind, Write};
use std::os::unix::fs::PermissionsExt;
use std::path::{Path, PathBuf};

const MAX_SUFFIX: u32 = 999;
/// A name taken between `unique_target` and the rename is retried this often.
const MOVE_ATTEMPTS: u32 = 5;

#[derive(Debug)]
pub(crate) enum MoveError {
    /// The destination exists. Nothing was changed.
    Exists,
    Other(String),
}

impl From<std::io::Error> for MoveError {
    fn from(e: std::io::Error) -> Self {
        if e.kind() == ErrorKind::AlreadyExists {
            MoveError::Exists
        } else {
            MoveError::Other(e.to_string())
        }
    }
}

impl std::fmt::Display for MoveError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            MoveError::Exists => write!(f, "destination exists"),
            MoveError::Other(e) => write!(f, "{e}"),
        }
    }
}

fn occupied(path: &Path) -> bool {
    // `symlink_metadata`: a dangling symlink occupies its name too.
    fs::symlink_metadata(path).is_ok()
}

fn split_name(name: &str) -> (&str, Option<&str>) {
    match name.rfind('.') {
        Some(i) if i > 0 => (&name[..i], Some(&name[i + 1..])),
        _ => (name, None),
    }
}

/// `dir/file_name`, or the first `stem-N.ext` (N = 2…999) that is free on disk
/// and not held by another row (`taken`).
pub(crate) fn unique_target(
    dir: &Path,
    file_name: &str,
    taken: impl Fn(&Path) -> bool,
) -> Result<PathBuf, String> {
    let free = |p: &Path| !occupied(p) && !taken(p);
    let first = dir.join(file_name);
    if free(&first) {
        return Ok(first);
    }
    let (stem, ext) = split_name(file_name);
    for n in 2..=MAX_SUFFIX {
        let candidate = dir.join(match ext {
            Some(e) => format!("{stem}-{n}.{e}"),
            None => format!("{stem}-{n}"),
        });
        if free(&candidate) {
            return Ok(candidate);
        }
    }
    Err(format!("no free name for {file_name} in {}", dir.display()))
}

fn rename_excl(from: &Path, to: &Path) -> std::io::Result<()> {
    let f = crate::atomic_write::c_path(from).map_err(std::io::Error::other)?;
    let t = crate::atomic_write::c_path(to).map_err(std::io::Error::other)?;
    // SAFETY: both are NUL-terminated C strings that outlive the call.
    let rc = unsafe { libc::renamex_np(f.as_ptr(), t.as_ptr(), libc::RENAME_EXCL) };
    if rc == 0 {
        Ok(())
    } else {
        Err(std::io::Error::last_os_error())
    }
}

/// Move `from` to `to` without ever replacing `to`. Same volume: an atomic
/// exclusive rename (or link + unlink where the volume lacks RENAME_EXCL).
/// Across volumes: `copy_verify_remove`.
pub(crate) fn move_no_clobber(from: &Path, to: &Path) -> Result<(), MoveError> {
    match rename_excl(from, to) {
        Ok(()) => Ok(()),
        Err(e) if e.raw_os_error() == Some(libc::ENOTSUP) => {
            match fs::hard_link(from, to) {
                Ok(()) => fs::remove_file(from).map_err(MoveError::from),
                Err(e) if e.raw_os_error() == Some(libc::EXDEV) => copy_verify_remove(from, to),
                Err(e) => Err(e.into()),
            }
        }
        Err(e) if e.raw_os_error() == Some(libc::EXDEV) => copy_verify_remove(from, to),
        Err(e) => Err(e.into()),
    }
}

/// The roadmap's cross-volume rule: a second copy exists, is on disk and
/// matches byte for byte before the first one is removed.
pub(crate) fn copy_verify_remove(from: &Path, to: &Path) -> Result<(), MoveError> {
    let bytes = fs::read(from)?;
    let mode = fs::metadata(from)?.permissions().mode() & 0o7777;
    {
        let mut out = fs::OpenOptions::new().write(true).create_new(true).open(to)?;
        out.write_all(&bytes)?;
        out.set_permissions(fs::Permissions::from_mode(mode))?;
        out.sync_all()?;
    }
    if fs::read(to)? != bytes {
        // Only the copy this call just created is removed; the source is intact.
        let _ = fs::remove_file(to);
        return Err(MoveError::Other(format!("copy to {} did not verify", to.display())));
    }
    fs::remove_file(from)?;
    Ok(())
}

/// Move `from` into `dir` under `file_name` or its first free suffix; a name
/// taken between the check and the move is retried with the next one.
pub(crate) fn move_into(
    dir: &Path,
    file_name: &str,
    from: &Path,
    taken: impl Fn(&Path) -> bool,
) -> Result<PathBuf, String> {
    for _ in 0..MOVE_ATTEMPTS {
        let target = unique_target(dir, file_name, &taken)?;
        match move_no_clobber(from, &target) {
            Ok(()) => return Ok(target),
            Err(MoveError::Exists) => continue,
            Err(e) => return Err(format!("move {} → {}: {e}", from.display(), target.display())),
        }
    }
    Err(format!("could not find a free name for {file_name} in {}", dir.display()))
}

/// The purge guard (D9). `Ok(Some(canonical))`: a regular file directly inside
/// `trash_dir`, safe to delete. `Ok(None)`: nothing there any more. `Err`:
/// anything else — never delete it.
pub(crate) fn purgeable_file(trash_dir: &Path, path: &Path) -> Result<Option<PathBuf>, String> {
    let meta = match fs::symlink_metadata(path) {
        Ok(m) => m,
        Err(e) if e.kind() == ErrorKind::NotFound => return Ok(None),
        Err(e) => return Err(format!("{}: {e}", path.display())),
    };
    if !meta.file_type().is_file() {
        return Err(format!("{} is not a regular file", path.display()));
    }
    let name = path
        .file_name()
        .ok_or_else(|| format!("{} has no file name", path.display()))?;
    let parent = path
        .parent()
        .ok_or_else(|| format!("{} has no parent", path.display()))?;
    let canon_parent = fs::canonicalize(parent).map_err(|e| format!("{}: {e}", parent.display()))?;
    let canon_trash =
        fs::canonicalize(trash_dir).map_err(|e| format!("{}: {e}", trash_dir.display()))?;
    if canon_parent != canon_trash {
        return Err(format!("{} is outside the note trash", path.display()));
    }
    Ok(Some(canon_parent.join(name)))
}
```

```rust
fn move_sidecar(from_doc: &Path, to_doc: &Path) {
    let (Some(from), Some(to)) =
        (crate::comments::sidecar_path(from_doc), crate::comments::sidecar_path(to_doc))
    else {
        return;
    };
    if !occupied(&from) {
        return;
    }
    if let Err(e) = move_no_clobber(&from, &to) {
        eprintln!("[stash::trash] sidecar {} not moved: {e}", from.display());
    }
}

fn spelled(path: &Path) -> String {
    crate::path_norm::normalize_str(&path.to_string_lossy())
}

/// Stage 06 delete. A note's file moves into the trash (no-clobber) and then
/// its row changes in one transaction; a failed transaction moves the file
/// back. A file reference loses its row and tags; the file is not touched.
/// The caller has made sure no tab holds a note's path (`delete_flow`).
pub fn delete(conn: &mut Connection, paths: &StashPaths, id: &str, now: i64) -> Result<Deleted, String> {
    let r = row(conn, id)?;
    if r.kind == "file" {
        let tx = conn.transaction().map_err(sql)?;
        crate::stash::search::unindex_entry(&tx, r.rowid)?;
        tx.execute("DELETE FROM entries WHERE id = ?1", params![id]).map_err(sql)?;
        tx.commit().map_err(sql)?;
        return Ok(Deleted::Removed);
    }
    if r.deleted_at.is_some() {
        return Ok(Deleted::Trashed);
    }

    let src = PathBuf::from(&r.path);
    let moved = if occupied(&src) {
        fs::create_dir_all(&paths.notes_trash_dir)
            .map_err(|e| format!("{}: {e}", paths.notes_trash_dir.display()))?;
        let name = file_name(&src)?;
        let dest = move_into(&paths.notes_trash_dir, &name, &src, |p| path_taken(conn, p))?;
        move_sidecar(&src, &dest);
        Some(dest)
    } else {
        None
    };
    let new_path = moved.as_deref().map(spelled).unwrap_or_else(|| r.path.clone());

    let outcome = (|| -> Result<(), String> {
        let tx = conn.transaction().map_err(sql)?;
        let n = tx
            .execute(
                "UPDATE entries SET path = ?2, deleted_at = ?3 WHERE id = ?1 AND deleted_at IS NULL",
                params![id, new_path, now],
            )
            .map_err(sql)?;
        if n != 1 {
            return Err(format!("stash entry {id} changed while it was being deleted"));
        }
        crate::stash::search::unindex_entry(&tx, r.rowid)?;
        tx.commit().map_err(sql)
    })();

    if let Err(e) = outcome {
        if let Some(dest) = &moved {
            match move_no_clobber(dest, &src) {
                Ok(()) => move_sidecar(dest, &src),
                Err(back) => eprintln!(
                    "[stash::trash] delete of {id} failed ({e}) and the file stays at {} ({back})",
                    dest.display()
                ),
            }
        }
        return Err(e);
    }
    Ok(Deleted::Trashed)
}
```

```rust
pub fn restore(

    paths: &StashPaths,
    id: &str,
    now: i64,
```

```rust
pub const TRASH_RETENTION_DAYS: i64 = 30;
pub const TRASH_RETENTION_MS: i64 = TRASH_RETENTION_DAYS * 24 * 60 * 60 * 1000;

#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct PurgeReport {
    pub purged: Vec<String>,
    /// Rows the guard refused, with the reason — left exactly as they were.
    pub skipped: Vec<(String, String)>,
}

/// «удалить навсегда» and the 30-day purge: the only code that deletes a
/// note's bytes. Only a trashed note; only a regular file directly inside the
/// note trash (`purgeable_file`). A file already gone just loses its row.
pub fn purge(conn: &mut Connection, paths: &StashPaths, id: &str) -> Result<(), String> {
    let r = row(conn, id)?;
    if r.kind != "note" || r.deleted_at.is_none() {
        return Err(format!("stash entry {id} is not in the trash"));
    }
    let doc = PathBuf::from(&r.path);
    if let Some(file) = purgeable_file(&paths.notes_trash_dir, &doc)? {
        fs::remove_file(&file).map_err(|e| format!("{}: {e}", file.display()))?;
        if let Some(side) = crate::comments::sidecar_path(&file) {
            match purgeable_file(&paths.notes_trash_dir, &side) {
                Ok(Some(s)) => {
                    if let Err(e) = fs::remove_file(&s) {
                        eprintln!("[stash::trash] sidecar {} not removed: {e}", s.display());
                    }
                }
                Ok(None) => {}
                Err(e) => eprintln!("[stash::trash] sidecar left alone: {e}"),
            }
        }
    }
    let tx = conn.transaction().map_err(sql)?;
    crate::stash::search::unindex_entry(&tx, r.rowid)?;
    tx.execute("DELETE FROM entries WHERE id = ?1 AND deleted_at IS NOT NULL", params![id])
        .map_err(sql)?;
    tx.commit().map_err(sql)
}

/// Every trashed note deleted at least `TRASH_RETENTION_MS` before `now`.
/// One refused row never stops the rest.
pub fn purge_expired(conn: &mut Connection, paths: &StashPaths, now: i64) -> PurgeReport {
    let mut report = PurgeReport::default();
    let ids: Vec<String> = match conn.prepare(
        "SELECT id FROM entries WHERE kind = 'note' AND deleted_at IS NOT NULL AND deleted_at <= ?1
         ORDER BY deleted_at",
    ) {
        Ok(mut st) => match st.query_map(params![now - TRASH_RETENTION_MS], |r| r.get(0)) {
            Ok(rows) => rows.filter_map(Result::ok).collect(),
            Err(e) => {
                eprintln!("[stash::trash] purge query failed: {e}");
                return report;
            }
        },
        Err(e) => {
            eprintln!("[stash::trash] purge query failed: {e}");
            return report;
        }
    };
    for id in ids {
        match purge(conn, paths, &id) {
            Ok(()) => report.purged.push(id),
            Err(e) => {
                eprintln!("[stash::trash] purge of {id} skipped: {e}");
                report.skipped.push((id, e));
            }
        }
    }
    report
}
```

```rust
const DAY_MS: i64 = 24 * 60 * 60 * 1000;

/// Housekeeping runs when a day of wall clock has passed since the last run,
/// or when the clock went backwards (a manual change must not stall it).
pub(crate) fn due(last: Option<i64>, now: i64) -> bool {
    match last {
        None => true,
        Some(l) => now < l || now - l >= DAY_MS,
    }
}

/// Finish a move a crash cut between the rename and the transaction (D11).
/// Looks only for the exact file name on the other side; anything else is left
/// alone. Returns the ids it changed.
pub fn reconcile(conn: &mut Connection, paths: &StashPaths, now: i64) -> Vec<String> {
    let rows: Vec<(String, i64, String, Option<i64>)> = match conn
        .prepare("SELECT id, rowid, path, deleted_at FROM entries WHERE kind = 'note'")
        .and_then(|mut st| {
            st.query_map([], |r| Ok((r.get(0)?, r.get(1)?, r.get(2)?, r.get(3)?)))
                .map(|rows| rows.filter_map(Result::ok).collect())
        }) {
        Ok(v) => v,
        Err(e) => {
            eprintln!("[stash::trash] reconcile query failed: {e}");
            return Vec::new();
        }
    };
    let mut changed = Vec::new();
    for (id, rowid, path, deleted_at) in rows {
        let here = PathBuf::from(&path);
        if occupied(&here) {
            continue;
        }
        let Ok(name) = file_name(&here) else { continue };
        let (other_dir, restoring) = match deleted_at {
            None => (&paths.notes_trash_dir, false),
            Some(_) => (&paths.notes_dir, true),
        };
        let there = other_dir.join(&name);
        let is_file = fs::symlink_metadata(&there).map(|m| m.file_type().is_file()).unwrap_or(false);
        if !is_file || path_taken(conn, &there) {
            continue;
        }
        let spelled_there = spelled(&there);
        let result = if restoring {
            conn.execute(
                "UPDATE entries SET path = ?2, deleted_at = NULL, stashed_at = ?3 WHERE id = ?1",
                params![id, spelled_there, now],
            )
        } else {
            conn.execute(
                "UPDATE entries SET path = ?2, deleted_at = ?3 WHERE id = ?1",
                params![id, spelled_there, now],
            )
        };
        match result {
            Ok(1) => {
                if restoring {
                    if let Ok(text) = fs::read_to_string(&there) {
                        let _ = crate::stash::search::index_entry(conn, rowid, &text);
                    }
                } else if let Ok(tx) = conn.transaction() {
                    let _ = crate::stash::search::unindex_entry(&tx, rowid);
                    let _ = tx.commit();
                }
                changed.push(id);
            }
            Ok(_) => {}
            Err(e) => eprintln!("[stash::trash] reconcile of {id} failed: {e}"),
        }
    }
    changed
}
```

```rust
use std::sync::{mpsc, Mutex};
use std::time::Duration;

/// How long Rust waits for a window to drop a note's tab before a delete.
pub const DROP_REPLY_TIMEOUT: Duration = Duration::from_secs(10);

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Owner {
    pub label: String,
    pub number: Option<u32>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DropReply {
    Dropped,
    /// The tab's save had not landed; the window kept it (and said so there).
    Refused,
    Timeout,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)]
#[serde(rename_all = "lowercase")]
pub enum KeptReason {
    Unsaved,
    Timeout,
    Open,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum FlowOutcome {
    Done(Deleted),
    Kept { reason: KeptReason, owner: Owner },
}

/// What `delete_flow` needs from the app. The Tauri side implements it over
/// `OpenFiles`, `StashState` and the `stash-drop-tab` round trip; tests fake it.
pub trait DeleteEnv {
    /// `(kind, deleted, path)` of the entry.
    fn entry(&self, id: &str) -> Result<(String, bool, String), String>;
    /// The window whose tab holds `path`, read under a short `OpenFiles` lock.
    fn owner(&self, path: &str) -> Option<Owner>;
    fn ask_to_drop(&self, owner: &Owner, path: &str) -> DropReply;
    /// `trash::delete` under the `StashState` lock.
    fn trash(&self, id: &str) -> Result<Deleted, String>;
}

/// D2/D3: a note held by a tab is dropped by that tab's window first; the file
/// moves only once nobody holds its path, so no autosave can write it back.
pub fn delete_flow(env: &impl DeleteEnv, id: &str) -> Result<FlowOutcome, String> {
    let (kind, deleted, path) = env.entry(id)?;
    if kind == "note" && !deleted {
        if let Some(owner) = env.owner(&path) {
            match env.ask_to_drop(&owner, &path) {
                DropReply::Dropped => {}
                DropReply::Refused => return Ok(FlowOutcome::Kept { reason: KeptReason::Unsaved, owner }),
                DropReply::Timeout => return Ok(FlowOutcome::Kept { reason: KeptReason::Timeout, owner }),
            }
            if let Some(again) = env.owner(&path) {
                return Ok(FlowOutcome::Kept { reason: KeptReason::Open, owner: again });
            }
        }
    }
    env.trash(id).map(FlowOutcome::Done)
}

/// Pending `stash-drop-tab` requests, answered by `stash_drop_done`.
#[derive(Default)]
pub struct DropRequests(Mutex<DropInner>);

#[derive(Default)]
struct DropInner {
    next: u64,
    waiting: HashMap<u64, (String, mpsc::Sender<bool>)>,
}

impl DropRequests {
    pub fn register(&self, label: &str) -> (u64, mpsc::Receiver<bool>) {
        let (tx, rx) = mpsc::channel();
        let mut inner = self.0.lock().unwrap();
        inner.next += 1;
        let id = inner.next;
        inner.waiting.insert(id, (label.to_string(), tx));
        (id, rx)
    }

    /// `false` for an unknown or already answered request, or one asked of another window.
    pub fn answer(&self, from_label: &str, request_id: u64, dropped: bool) -> bool {
        let mut inner = self.0.lock().unwrap();
        match inner.waiting.get(&request_id) {
            Some((label, _)) if label == from_label => {
                let (_, tx) = inner.waiting.remove(&request_id).unwrap();
                tx.send(dropped).is_ok()
            }
            _ => false,
        }
    }

    pub fn abandon(&self, request_id: u64) {
        self.0.lock().unwrap().waiting.remove(&request_id);
    }
}
```

```rust
impl trash::DeleteEnv for AppDeleteEnv<'_> {
    fn entry(&self, id: &str) -> Result<(String, bool, String), String> {
        let state = self.app.state::<StashState>();
        let conn = state.conn(); // guard; dropped at the end of this fn
        let (kind, deleted_at, path): (String, Option<i64>, String) = conn
            .query_row("SELECT kind, deleted_at, path FROM entries WHERE id = ?1", [id], |r| {
                Ok((r.get(0)?, r.get(1)?, r.get(2)?))
            })
            .map_err(|e| e.to_string())?;
        Ok((kind, deleted_at.is_some(), path))
    }

    fn owner(&self, path: &str) -> Option<trash::Owner> {
        // D17: OpenFiles alone, dropped before anything takes StashState.
        let open_files = self.app.state::<crate::window::OpenFiles>();
        let reg = open_files.0.lock().unwrap();
        let (label, _tab) = reg.owner_of(path)?;
        let number = reg.window(&label).and_then(|w| w.number);
        Some(trash::Owner { label, number })
    }

    fn ask_to_drop(&self, owner: &trash::Owner, path: &str) -> trash::DropReply {
        let reqs = self.app.state::<trash::DropRequests>();
        let (request_id, rx) = reqs.register(&owner.label);
        let payload = DropTab { request_id, path: path.to_string() };
        if self.app.emit_to(owner.label.as_str(), "stash-drop-tab", payload).is_err() {
            reqs.abandon(request_id);
            return trash::DropReply::Timeout;
        }
        match rx.recv_timeout(trash::DROP_REPLY_TIMEOUT) {
            Ok(true) => trash::DropReply::Dropped,
            Ok(false) => trash::DropReply::Refused,
            Err(_) => {
                reqs.abandon(request_id);
                trash::DropReply::Timeout
            }
        }
    }

    fn trash(&self, id: &str) -> Result<trash::Deleted, String> {
        let state = self.app.state::<StashState>();
        let mut conn = state.conn();
        trash::delete(&mut conn, state.paths(), id, self.now)
    }
}
```

```ts
    await deps.rust.release(tab.id);
```

```ts
/**
 * The trash view's pure rules (stage 06). What the drawer shows and what a
 * key does there; no DOM, no IPC.
 */
import { parseStashQuery } from './stash-query';
import type { StashEntry, StashView } from './types';

/** Mirrors `stash::trash::TRASH_RETENTION_DAYS`; a test reads the Rust file. */
export const TRASH_DAYS = 30;
const DAY_MS = 86_400_000;

/** «удалится через N дн.»: whole days left, rounded up, never below 1 (purge runs once a day). */
export function trashDaysLeft(deletedAt: number, now: number): number {
  return Math.max(1, Math.ceil((deletedAt + TRASH_DAYS * DAY_MS - now) / DAY_MS));
}

export function sortTrash(entries: readonly StashEntry[]): StashEntry[] {
  return [...entries].sort((a, b) => (b.deletedAt ?? 0) - (a.deletedAt ?? 0));
}

/**
 * Trashed notes are not in the search index (stage 05 indexes the stash
 * only), so the trash filters here: `#tag` by prefix over tags and repo, text
 * as a substring of title and preview. The repo chip does not apply.
 */
export function filterTrash(entries: readonly StashEntry[], query: string): StashEntry[] {
  const q = parseStashQuery(query);
  const text = q.text.trim().toLowerCase();
  return entries.filter((e) => {
    const tags = [...(e.repo ? [e.repo] : []), ...e.tags].map((t) => t.toLowerCase());
    for (const tag of q.tags) if (tag && !tags.some((t) => t.startsWith(tag.toLowerCase()))) return false;
    if (!text) return true;
    return (e.title ?? '').toLowerCase().includes(text) || e.preview.toLowerCase().includes(text);
  });
}

export type StashEscape = 'clear-query' | 'leave-trash' | 'close-stash';

export function stashEscapeAction(s: { view: StashView; query: string }): StashEscape {
  if (s.query) return 'clear-query';
  return s.view === 'trash' ? 'leave-trash' : 'close-stash';
}

export type StashBackspace = 'edit-query' | 'drop-repo-chip' | 'none';

export function stashBackspaceAction(s: { view: StashView; query: string; repoChip: string | null }): StashBackspace {
  if (s.query) return 'edit-query';
  if (s.view === 'stash' && s.repoChip !== null) return 'drop-repo-chip';
  return 'none';
}

/** ⌘L / ⌘R / ⌘U sort the stash; in the trash (no sort row) they are swallowed and do nothing. */
export function stashSortKeysActive(view: StashView): boolean {
  return view === 'stash';
}
```

```ts
/**
 * The stash drawer's trash view (stage 06): which view is shown, the trashed
 * notes, and the three actions. Composed into `stash-store`; all I/O and
 * toasts come in through `deps`.
 */
import { sortTrash } from './trash-view';
import type { DeleteOutcome, KeptReason, StashChanged, StashEntry, StashView } from './types';

export type TrashNotice =
  | { kind: 'trashed'; title: string | null }
  | { kind: 'ref-removed'; title: string | null }
  | { kind: 'restored'; title: string | null; hiddenBy: string | null }
  | { kind: 'purged'; title: string | null }
  | { kind: 'kept'; reason: KeptReason; title: string | null; label: string; number: number | null }
  | { kind: 'error'; title: string | null; message: string };

export interface TrashModeDeps {
  listTrash(): Promise<StashEntry[]>;
  deleteEntry(id: string): Promise<DeleteOutcome>;
  restore(id: string): Promise<StashEntry>;
  purge(id: string): Promise<void>;
  /** The drawer's one query box: every view switch starts empty (mockup `setStashView`). */
  resetQuery(): void;
  repoChip(): string | null;
  /** Take a card off the stash list at once (its collapse animation runs). */
  removeFromStash(id: string): void;
  refreshStash(): Promise<void>;
  notify(n: TrashNotice): void;
}

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

export function createTrashMode(deps: TrashModeDeps) {
  let view = $state<StashView>('stash');
  let entries = $state<StashEntry[]>([]);
  /** Cards with an action in flight: a second click must not send a second IPC. */
  const busy = new Set<string>();

  async function reload(): Promise<void> {
    entries = sortTrash(await deps.listTrash());
  }

  async function act(card: StashEntry, run: () => Promise<void>): Promise<void> {
    if (busy.has(card.id)) return;
    busy.add(card.id);
    try {
      await run();
    } catch (err) {
      deps.notify({ kind: 'error', title: card.title, message: message(err) });
    } finally {
      busy.delete(card.id);
    }
  }

  return {
    get view() {
      return view;
    },
    get entries() {
      return entries;
    },
    async enter(): Promise<void> {
      view = 'trash';
      deps.resetQuery();
      await reload();
    },
    leave(): void {
      if (view === 'stash') return;
      view = 'stash';
      deps.resetQuery();
    },
    async toggle(): Promise<void> {
      if (view === 'trash') this.leave();
      else await this.enter();
    },
    /** «удалить» / «убрать из тайника» on a stash card. */
    remove: (card: StashEntry) =>
      act(card, async () => {
        const out = await deps.deleteEntry(card.id);
        if (out.kind === 'kept') {
          deps.notify({ kind: 'kept', reason: out.reason, title: card.title, label: out.label, number: out.number });
          return;
        }
        deps.removeFromStash(card.id);
        deps.notify(out.kind === 'trashed' ? { kind: 'trashed', title: card.title } : { kind: 'ref-removed', title: card.title });
      }),
    restore: (card: StashEntry) =>
      act(card, async () => {
        await deps.restore(card.id);
        entries = entries.filter((x) => x.id !== card.id);
        await deps.refreshStash();
        const chip = deps.repoChip();
        deps.notify({ kind: 'restored', title: card.title, hiddenBy: chip !== null && card.repo !== chip ? chip : null });
      }),
    purge: (card: StashEntry) =>
      act(card, async () => {
        await deps.purge(card.id);
        entries = entries.filter((x) => x.id !== card.id);
        deps.notify({ kind: 'purged', title: card.title });
      }),
    async changed(_ev: StashChanged): Promise<void> {
      if (view === 'trash') await reload();
    },
  };
}
```

- [ ] **Step 2: `stash-drop.ts` — the listener body**

```ts
/**
 * Rust asks this window to drop a stash note's tab before the note moves to
 * the trash (`stash-drop-tab`). The controller leaves the tab the normal way;
 * Rust waits for the answer (`stash_drop_done`) and moves the file only after
 * `dropped: true`.
 */
export interface StashDropDeps {
  dropPath(path: string): Promise<boolean>;
  done(requestId: number, dropped: boolean): Promise<void>;
}

export async function handleStashDropTab(
  deps: StashDropDeps,
  payload: { requestId: number; path: string }
): Promise<void> {
  let dropped = false;
  try {
    dropped = await deps.dropPath(payload.path);
  } catch (err) {
    console.error('stash-drop-tab: drop failed', err);
  }
  try {
    await deps.done(payload.requestId, dropped);
  } catch (err) {
    // Rust times out on its own and reports `kept`; nothing to undo here.
    console.error('stash-drop-tab: answer failed', err);
  }
}
```

`stash-drop.test.ts`: answers `dropped: true` after `dropPath` resolves true (and only after — assert order); answers `false` when `dropPath` resolves false; answers `false` when `dropPath` throws; a rejected `done` does not throw out of the handler.

### Task 15: Docs, full verification, review

**Files:**
- Modify: `CLAUDE.md`

- [ ] **Step 1: CLAUDE.md**

Architecture list: add `stash/trash.rs` ("delete / restore / purge; the only code that deletes a note's bytes; `delete_flow` asks the tab's window to drop it first") and the frontend files (`trash-view.ts`, `trash-mode.svelte.ts`, `TrashBar.svelte`, `TrashCard.svelte`, `stash-drop.ts`).

Gotchas (short, in the file's voice):
- **A trashed note's `path` is its trash path.** `entries.path` always names where the file is; `deleted_at` says whether that is the trash. Readers need no special case; writers (`on_file_written`, put-away, tag) must skip or refuse trashed rows.
- **Purge deletes only a regular file whose canonical parent is the canonical note trash dir** (`trash::purgeable_file`). Never widen it; a refused row is logged and left as it is.
- **Deleting a note open in a tab goes through the window that holds it:** `stash-drop-tab` → `tabs.dropPath` (flush, refuse if the save did not land, `tab_release`) → `stash_drop_done` → Rust re-checks the owner and only then moves the file. Moving first would let the next autosave recreate the file at its old path. A drop is a release, never a close: a ⌘⇧T entry for a trashed note would reopen an empty document there.
- **Moves into and out of the trash are no-clobber** (`renamex_np(RENAME_EXCL)`); `fs::rename` silently replaces an existing destination on macOS.
- **`OpenFiles` and `StashState` are never held together.**
- **Trashed notes are not in the FTS index** — agents' `stash_search` never sees them; the trash view filters client-side.

## Known gaps (deliberate, documented)

- No UI entry deletes a note that is open in **this** window: the spec hides such a note from this window's stash. The Rust path handles it anyway (one flow for every window), ready for a later entry point (a menu item, `/stash`).
- A crash between a suffixed restore's rename and its transaction leaves the file in the notes folder as an orphan while the row stays in the trash (its purge then finds no file and drops the row). The text is never deleted; `reconcile` only recognises the exact name.
- An older Recent Files entry for a trashed note's old path opens an empty document there (⌘⇧T already skips it via `pop_live`). Nothing is lost.
- «удалить навсегда» has no confirmation (approved mockup).
