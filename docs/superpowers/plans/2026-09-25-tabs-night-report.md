## План 01 — фундамент (PR #94)

Что сделано (спека §8–§9):
- **Утечка undo** при ⌘O / Recent закрыта: пересборка history-compartment. ⌘Z больше не вписывает текст старого документа в новый.
- **Потеря последних ≤300 мс набора** при переключении закрыта: автосейв сбрасывается до замены.
- **`switchDocument`** — единственный путь замены документа: дедуп между окнами, несохранённый буфер не теряется, передача пауз и черновиков комментариев, `ask`/`edit`/`show` уходящего документа сразу получают ошибку, переключения идут очередью, откат при отмене, открытая ячейка таблицы сохраняется.
- **Черновики untitled** именуются по `tab_id`, а не по label окна (коллизия `untitled-main.md` между запусками).
- **Recent Files в Rust** (`recent.json`), рассылка с версиями во все окна, разовый импорт из localStorage.
- **⌘⇧T** возвращает последнее закрытое окно с курсором; в свежем запуске — сессию. В тосте сессии кнопка «Restore».

### Отступления от плана 01 и почему
1. **Тест утечки undo в плане ничего не воспроизводил** — в нём была правка-вставка, а её инверсия схлопывается при полной замене документа. Утечку дают правки-удаления (так и было в прожарке №3). Тест переписан.
2. **Правило «отказ, если файл после сохранения всё ещё несохранён»** + повторное сохранение прямо перед заменой + флаг на время переключения (иначе `ask` старого документа мог проскочить и повиснуть). По итогам ревью.
3. **Закрыты две гонки потери восстановленных черновиков untitled** (вне текста плана, в его цели): первое сообщение окна в сессию уходило до загрузки текста и стирало ссылку на черновик (потеря даже при обычном ⌘Q в первые ~5 с); уборка удаляла черновики ещё не открытых окон во время восстановления.
4. **Recent регистрируется после `paths::init`** (см. риск выше), рассылки с версиями против устаревших событий.
5. **⌘⇧T**: после первого ⌘W сессию возвращает только кнопка в тосте — см. вопрос Q1.
6. **Попутно исправлено**: «Сохранить как» не регистрировал новый путь (не работали dedup и слежение за файлом); событие `open-file` уходило во все окна; открытие из Finder перетирало чужую запись и файл оказывался в двух окнах.
7. **Коммит `7d9310d`** (агент `md-mini-dev` → Opus) — по твоей просьбе этой ночью; лежит в PR фундамента, можно вынести cherry-pick'ом.
8. **PR #94 несёт всю дизайн-документацию** (~4.8k строк: спека, исследования, макет) — реши, оставлять в нём или выносить.

### Что из плана 01 перенесено в план 02

- ⌘W пока закрывает окно из Rust без сброса последних ~300 мс (план 02, задачи 12–13).

### Известное, но не исправленное
- Пять старых мест «файл уже открыт → фокус» не разворачивают свёрнутое окно (исправлено только в новом `focus_if_open`).
- Восстановление сессии не переиспользует пустое окно main (было и раньше).
- Через ~2 с после перезапуска `session.json` перезаписывается новой сессией, прошлая остаётся только в памяти до Restore — при жёстком убийстве до Restore она теряется (было и раньше, по замыслу).
- Самый первый черновик нового untitled-окна уборка может удалить сразу после записи; через 5 с он пишется снова.
