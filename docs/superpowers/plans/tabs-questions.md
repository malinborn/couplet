# Вкладки — вопросы на утро

*Ночь 2026-09-24 → 25. Сессия «couplet tabs implementation». По каждому вопросу принято обратимое решение по умолчанию, работа не останавливалась.*

## Q1. Нужен ли отдельный пункт меню «Открыть N окон прошлой сессии», кроме ⌘⇧T?
- **Контекст:** план 01, задача 7 (`src-tauri/src/menu.rs`, `src-tauri/src/closed.rs`). По спеке §6 ⌘⇧T возвращает последнее закрытое, а сессию восстанавливает, только «пока ничего не закрыто». Значит, после первого же ⌘W прошлая сессия доступна только если по одному переоткрыть всё закрытое.
- **Что я сделал пока:** оставил один пункт с ⌘⇧T, как в спеке. В тосте о сессии вместо подсказки «нажмите ⇧⌘T» поставил кнопку «Восстановить» (команда `restore_session`): так сессию можно вернуть, пока тост на экране. Решение обратимое, правка в одном Svelte-файле.
- **Альтернативы:**
  1. Как в Safari: отдельный пункт «Открыть N окон прошлой сессии» без клавиши, включён, пока сессия не восстановлена; ⌘⇧T — только закрытое. Около 30 строк в `menu.rs` и обработчике, логика пункта упрощается.
  2. Оставить как есть: только кнопка в тосте. Закрыл тост — сессию можно вернуть только через ⌘⇧T по одному окну.
