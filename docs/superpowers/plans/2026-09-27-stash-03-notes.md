> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A ⌘T / ⌘N tab is a *pending note* while it holds nothing but whitespace; its first non-blank character turns it into a stash note — an ordinary file tab on a `.md` file in `~/Documents/couplet/` — without losing a keystroke typed while that happens. An empty tab closes without a trace; ⌘W on a note puts it away; ⌃T (and `/stash`, and File → «Отложить в тайник») puts away any document, a file becoming a reference. Note tabs show their live title with the stash glyph in the drawer card and the window title. Every existing untitled draft is imported as a note once, before the session restore builds a window.

**Architecture:** The birth of a note runs inside the tab controller's serial queue (`becomeNoteNow` in `src/lib/tabs/controller.ts`), so no switch, close or move can interleave with it: `stash_create_note` writes the note with the text as it was, `tab_claim` points the tab at it (the Save As claim flow, `decideSaveAs`), and then the live state — never replaced — is marked dirty against what Rust wrote, so the ordinary autosave flush writes whatever was typed during the two awaits. What leaving the tabs means for the stash is decided in Rust from the database, inside `tab_close` (plus the red button and quit), never from a frontend cache. A new `stash::migrate_drafts` runs at every startup between `read_session()` and `set_pending`; it is idempotent through a `draft_imports` table (schema v2) and never moves a draft until its note has been re-read and compared.

**Tech Stack:** Tauri 2 (Rust, `rusqlite` from stage 02), Svelte 5 runes, CodeMirror 6, vitest, cargo test.

**Spec (behaviour wins):** `docs/superpowers/specs/2026-09-26-stash-design.md` («Модель», «Жизненный цикл заметки», «Отметка тайника», «Клавиатура», «Что меняется в принятых решениях»).

## Design decisions this plan commits to

| # | Decision | Why |
|---|---|---|
| D1 | A note is born inside the tab controller's queue (`becomeNoteNow`), not in App. | A switch, close, move or agent command queued meanwhile waits for it; there is exactly one active tab from the first await to the last. |
| D2 | **Text typed during the async gap:** the birth never touches the editor state. `stash_create_note` writes `text` (the doc when the birth started); after `tab_claim` the controller calls `doc.setActive(notePath, dirty = live !== text, baseline = text, 'lf')` and then the ordinary `autosave.flush()` → `performSave`, which writes the live doc. Nothing awaits between reading `live` and starting the flush; a key landing during the write is handled by `doSave`'s existing "buffer still equals what was written" check. | The live state keeps its undo history and every keystroke; the save path, its baseline bookkeeping, recovery and watcher are the ones every file tab already uses. |
| D3 | Claim after create, through `decideSaveAs` — the Save As flow: `tab_claim` before any write *to the tab's path*; a `blocked` answer writes nothing into the tab. A failed create leaves the tab untitled, raises `stash-error` and backs off `NOTE_RETRY_MS` (10 s); a failed claim leaves the note in the stash (a copy of the text) and the tab untitled. | Rust stays the only authority on who holds a path. In both failure modes the text is in the tab and in the stage-01-protected draft; nothing is lost, at worst duplicated. |
| D4 | Background untitled tabs with text (restored, moved, or left behind by a failed birth) are born too: on every `settle` and on arrival, with the cached text. | "No untitled with text survives" does not depend on the human typing again. |
| D5 | The stash side of ⌘W is decided **in Rust inside `tab_close`**, from the database: a live note is put away (caret + top line), a blank note discarded; with `putAway: true` (⌃T) a file becomes a reference. | One IPC, after the frontend flushed and handed over; it lands even when closing the last tab closes the window right after; a frontend cache cannot be stale here. The task's "close + `stash_put_away([path], caret, topLine)`" is exactly this, made atomic. |
| D6 | A note whose file holds only whitespace is discarded (file removed, row deleted) **only** from `tab_close` — i.e. after the controller's flush and dirty check. The red button and quit never discard. | Spec: «пустой документ при закрытии просто исчезает». There is no text to keep a second copy of; but the red button and ⌘Q do not flush the last ≤300 ms (tabs D17), so the disk may be blank while the buffer is not. |
| D7 | ⌃T = ⌘W plus "a file becomes a reference": on a blank new tab it closes it without a trace; on an untitled tab with text it first makes the note. `e.repeat` is swallowed. | One rule; a held ⌃T would otherwise put away tab after tab. |
| D8 | The red button and quit stamp the window's notes as put away (`Leaving::WithWindow`). | Spec lifecycle: «Открыта → Отложена: закрыли окно / выход». |
| D9 | A note never binds a window's project (`TabRegistry::unbound_windows` takes a predicate). | `git_info::project_root` falls back to the file's parent dir outside git: the first note typed in a fresh window would bind it to `~/Documents/couplet`, then tag every later note with that "repo" and skew agent routing — silently. |
| D10 | A note's `repo` is the window's project as the registry stores it (absolute root), read with `window_project` just before `stash_create_note`; UI renders its basename. | Same value routing and the session already use. |
| D11 | The draft importer runs at **every** startup (not once), after `StashState` exists and before `set_pending`; idempotent through `draft_imports(source, fingerprint)`. | A draft written later by a failed birth, or by a rolled-back build, is rescued on the next launch too. Nothing to import costs one `read_dir`. |
| D12 | Importer order per run: (1) note file + `entries` row + `draft_imports` row in one transaction, (2) re-read the note and compare bytes, (3) rewrite the pending session in memory and write `session-v2.json` (same `saved_at`), (4) `rename` each verified source into `session/.trash/`. Blank, non-UTF-8 and symlinked sidecars are not touched. | A crash between any two steps leaves the text in at least two places and the next run finishing the job without a duplicate; the source goes only after the destination was read back. |
| D13 | Which tab is a note is shown from a per-window cache (`stash-marks.svelte.ts`, `stash_entry_for_path`, refreshed on `stash-changed`). It decides nothing about data. | Cards and title need it synchronously; Rust decides everything that writes. |
| D14 | The native title bar cannot draw an SVG: the window title's glyph is the text character `STASH_TITLE_GLYPH = '⊔'` (U+2294, square cup — a tray). The drawer card uses the mockup's SVG tray. | `decorations: true` — the title is a string passed to `setTitle`. The owner picks the look (memory: show Max first); one constant to change. |

**Not in this stage** (each belongs to a later stage or a follow-up, listed in the night report): Save As from a note is a copy, not the spec's «переезд» (no stage owns it yet); the window carousel and the drag ghost's grey line show a note by its file name / git line (stage 04); notes appear in Recent Files (stage 04); the editor placeholder for a blank note from the mockup (stage 04); `stash_touch_opened` on opening from the stash (stage 04); deleting the FTS row of a discarded note (stage 05 must extend `lifecycle::document_left`).

```rust
/// The entry whose `path` is exactly `path` — the `path_norm` spelling the
/// tab registry uses — trashed or not. `None`: not in the stash.
pub fn entry_for_path(conn: &Connection, path: &str) -> Result<Option<StashEntry>, String> {
    let id: Option<String> = conn
        .query_row("SELECT id FROM entries WHERE path = ?1", [path], |row| row.get(0))
        .optional()
        .map_err(|e| format!("stash lookup by path failed: {e}"))?;
    id.map(|id| get(conn, &id)).transpose()
}
```

```rust
//! What leaving the tabs means for the stash (stash plan 03). Decided here,
//! from the database, never from a frontend's cache: `tab_close` (⌘W, ⌃T,
//! `/stash`, a ⇧-selection, an agent's close, an expired quick look), a
//! window's red button and a quit all come through `documents_left`.

use std::fs;

use rusqlite::Connection;
use tauri::{AppHandle, Manager};

use super::{entries, StashKind, StashPaths, StashState};
use crate::session::{Session, WindowSnapshot};
use crate::tabs::WindowTabs;

/// How a document left the tabs.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Leaving {
    /// ⌘W and every close that goes its way. The frontend flushed first.
    Closed,
    /// ⌃T / `/stash` / File → «Отложить в тайник»: `Closed`, and a file
    /// becomes a reference.
    PutAway,
    /// The red button or a quit: nothing was flushed.
    WithWindow,
}

#[derive(Debug, PartialEq, Eq)]
pub enum Left {
    Untouched,
    PutAway,
    Discarded,
}

fn is_blank_file(path: &str) -> bool {
    fs::read_to_string(path).map(|t| t.trim().is_empty()).unwrap_or(false)
}

/// One document left the tabs at `cursor` / `top_line`.
///
/// A live note is put away — or, on a flushed close of a note whose file holds
/// only whitespace, discarded (spec: «пустой документ при закрытии просто
/// исчезает»). Discarding deletes no user text: the file was read and is
/// blank. It is guarded to the notes folder, and the file goes before the
/// row, so a file that will not go keeps its entry (and is put away instead).
/// Anything else enters the stash only on `PutAway`.
pub fn document_left(
    conn: &mut Connection,
    paths: &StashPaths,
    path: &str,
    cursor: usize,
    top_line: usize,
    leaving: Leaving,
    now: i64,
) -> Result<Left, String> {
    let entry = entries::entry_for_path(conn, path)?;
    let live_note = entry.filter(|e| e.kind == StashKind::Note && e.deleted_at.is_none());
    match (&live_note, leaving) {
        (Some(note), Leaving::Closed | Leaving::PutAway)
            if is_blank_file(path)
                && super::paths::is_note_path(&super::paths::notes_dir_spelled(paths), path) =>
        {
            if fs::remove_file(path).is_ok() {
                conn.execute("DELETE FROM entries WHERE id = ?1", [&note.id])
                    .map_err(|e| format!("stash: could not drop the empty note {path}: {e}"))?;
                return Ok(Left::Discarded);
            }
        }
        (None, Leaving::Closed | Leaving::WithWindow) => return Ok(Left::Untouched),
        _ => {}
    }
    let req = entries::PutAwayRequest {
        paths: vec![path.to_string()],
        caret: Some(cursor),
        top_line: Some(top_line),
        tags: Vec::new(),
    };
    entries::put_away(conn, &req, now)?;
    Ok(Left::PutAway)
}

/// `document_left` for each of `docs` in the live app, best effort: a stash
/// that cannot be written never fails a close. Takes the connection with no
/// other lock held (lock order). One `stash-changed` if anything changed.
pub fn documents_left(app: &AppHandle, docs: &[(String, usize, usize)], leaving: Leaving) {
    if docs.is_empty() {
        return;
    }
    let Some(state) = app.try_state::<StashState>() else { return };
    let now = super::now_ms();
    let changed = state.with_conn(|conn| {
        let mut changed = false;
        for (path, cursor, top_line) in docs {
            match document_left(conn, state.paths(), path, *cursor, *top_line, leaving, now) {
                Ok(Left::Untouched) => {}
                Ok(_) => changed = true,
                Err(e) => eprintln!("stash: {path} left the tabs: {e}"),
            }
        }
        Ok(changed)
    });
    match changed {
        Ok(true) => super::emit_changed(app, "tabs-left"),
        Ok(false) => {}
        Err(e) => eprintln!("stash: {e}"),
    }
}

/// A closing window's file tabs, with the carets its last heartbeat recorded.
pub fn left_with_window(tabs: &WindowTabs, snapshot: Option<&WindowSnapshot>) -> Vec<(String, usize, usize)> {
    tabs.tabs
        .iter()
        .filter_map(|t| {
            let path = t.path.clone()?;
            let (cursor, top_line) = snapshot
                .and_then(|s| s.tabs.iter().find(|s| s.tab_id == t.id))
                .map(|s| (s.cursor, s.top_line))
                .unwrap_or((0, 1));
            Some((path, cursor, top_line))
        })
        .collect()
}

/// Every file tab of the session being written on quit.
pub fn left_at_quit(session: &Session) -> Vec<(String, usize, usize)> {
    session
        .windows
        .iter()
        .flat_map(|w| w.tabs.iter())
        .filter_map(|t| t.path.clone().map(|p| (p, t.cursor, t.top_line)))
        .collect()
}
```

```rust
//! Untitled drafts become stash notes (stash plan 03, D11/D12).
//!
//! Runs at every startup, after `StashState` exists and before the session
//! restore plans a window — idempotent, so a draft written later (a failed
//! note birth, a rolled-back build) is rescued on the next launch. Per run:
//! import (note file + row + `draft_imports` row, one transaction) → read the
//! note back and compare → rewrite the pending session and write it → only
//! then `rename` each source into `session/.trash/`. A crash between any two
//! steps leaves the text in two places and the next run finishing the job.

use std::collections::HashMap;
use std::fs;
use std::path::{Path, PathBuf};
use std::time::UNIX_EPOCH;

use rusqlite::{params, Connection, OptionalExtension};

use super::{entries, StashEntry, StashPaths};
use crate::session::{is_untitled_sidecar, Session};

/// Where drafts are read from, where a moved one goes, where the rewritten
/// `session-v2.json` is written.
pub struct DraftDirs<'a> {
    pub session_dir: &'a Path,
    pub trash_dir: &'a Path,
    pub data_dir: &'a Path,
}

#[derive(Debug, Default, PartialEq)]
pub struct ImportReport {
    pub imported: usize,
    pub reused: usize,
    pub trashed: usize,
    pub rewritten_tabs: usize,
    pub errors: Vec<String>,
}

struct Draft {
    name: String,
    path: PathBuf,
    text: String,
    mtime_ms: i64,
    fingerprint: String,
}

/// FNV-1a 64 of `bytes`, and their length — tells two contents of one
/// sidecar name apart. No new dependency; stable across Rust releases,
/// unlike `DefaultHasher`.
pub fn fingerprint(bytes: &[u8]) -> String {
    let mut hash: u64 = 0xcbf2_9ce4_8422_2325;
    for b in bytes {
        hash ^= u64::from(*b);
        hash = hash.wrapping_mul(0x0000_0100_0000_01b3);
    }
    format!("{hash:016x}-{}", bytes.len())
}

fn mtime_ms(path: &Path, fallback: i64) -> i64 {
    fs::metadata(path)
        .and_then(|m| m.modified())
        .ok()
        .and_then(|t| t.duration_since(UNIX_EPOCH).ok())
        .map(|d| d.as_millis() as i64)
        .unwrap_or(fallback)
}

/// The drafts directly in `dir` worth importing: a regular file (never
/// through a symlink) named like a sidecar, UTF-8, not blank. By name.
fn scan(dir: &Path, now: i64, report: &mut ImportReport) -> Vec<Draft> {
    let Ok(read) = fs::read_dir(dir) else { return Vec::new() };
    let mut drafts = Vec::new();
    for entry in read.flatten() {
        let Some(name) = entry.file_name().to_str().map(str::to_string) else { continue };
        if !is_untitled_sidecar(&name) {
            continue;
        }
        // `DirEntry::file_type` does not follow a symlink.
        if !entry.file_type().map(|t| t.is_file()).unwrap_or(false) {
            continue;
        }
        let path = entry.path();
        let bytes = match fs::read(&path) {
            Ok(b) => b,
            Err(e) => {
                report.errors.push(format!("{name}: {e}"));
                continue;
            }
        };
        let Ok(text) = String::from_utf8(bytes) else {
            report.errors.push(format!("{name}: not UTF-8 — left in place"));
            continue;
        };
        if text.trim().is_empty() {
            continue;
        }
        let fingerprint = fingerprint(text.as_bytes());
        drafts.push(Draft { mtime_ms: mtime_ms(&path, now), name, path, text, fingerprint });
    }
    drafts.sort_by(|a, b| a.name.cmp(&b.name));
    drafts
}

/// The project of the window whose tab holds draft `name`.
fn project_of_draft(session: Option<&Session>, name: &str) -> Option<String> {
    session?
        .windows
        .iter()
        .find(|w| w.tabs.iter().any(|t| t.untitled.as_deref() == Some(name)))
        .and_then(|w| w.project.clone())
}

/// The note this very content of `draft` became on an earlier run, or a new
/// one — created at the draft's mtime, stashed then, recorded in
/// `draft_imports` in the same transaction. `true`: created now.
fn import_one(
    conn: &mut Connection,
    paths: &StashPaths,
    draft: &Draft,
    repo: Option<&str>,
    now: i64,
) -> Result<(StashEntry, bool), String> {
    let previous: Option<String> = conn
        .query_row(
            "SELECT entry_id FROM draft_imports WHERE source = ?1 AND fingerprint = ?2",
            params![draft.name, draft.fingerprint],
            |r| r.get(0),
        )
        .optional()
        .map_err(|e| e.to_string())?;
    if let Some(id) = previous {
        if let Ok(entry) = entries::get(conn, &id) {
            return Ok((entry, false));
        }
    }
    let tx = conn.transaction().map_err(|e| e.to_string())?;
    let entry = entries::create_note_at(&tx, paths, &draft.text, repo, draft.mtime_ms)?;
    tx.execute(
        "UPDATE entries SET stashed_at = ?1 WHERE id = ?2",
        params![draft.mtime_ms, entry.id],
    )
    .map_err(|e| e.to_string())?;
    tx.execute(
        "INSERT OR REPLACE INTO draft_imports (source, fingerprint, entry_id, imported_at) VALUES (?1, ?2, ?3, ?4)",
        params![draft.name, draft.fingerprint, entry.id, now],
    )
    .map_err(|e| e.to_string())?;
    tx.commit().map_err(|e| e.to_string())?;
    Ok((entries::get(conn, &entry.id)?, true))
}

/// The note a draft `name` became on an earlier run, when that draft is gone
/// from `session/` — for a session that still names it.
fn note_from_history(conn: &Connection, name: &str) -> Option<String> {
    let id: String = conn
        .query_row(
            "SELECT entry_id FROM draft_imports WHERE source = ?1 ORDER BY imported_at DESC LIMIT 1",
            [name],
            |r| r.get(0),
        )
        .optional()
        .ok()??;
    let entry = entries::get(conn, &id).ok()?;
    (entry.deleted_at.is_none() && Path::new(&entry.path).exists()).then_some(entry.path)
}

fn reads_back(path: &str, text: &str) -> bool {
    fs::read(path).map(|b| b == text.as_bytes()).unwrap_or(false)
}

/// Point every tab naming a draft in `notes` at its note. Returns how many.
fn rewrite(session: &mut Session, notes: &HashMap<String, String>) -> usize {
    let mut n = 0;
    for tab in session.windows.iter_mut().flat_map(|w| w.tabs.iter_mut()) {
        let Some(note) = tab.untitled.as_ref().and_then(|name| notes.get(name)) else { continue };
        tab.path = Some(note.clone());
        tab.untitled = None;
        n += 1;
    }
    n
}

/// `rename` `src` into `trash_dir` (same volume: both live under the app data
/// dir), never over an existing file: `name.md`, `name.1.md`, `name.2.md`, …
pub fn move_into_trash(src: &Path, trash_dir: &Path) -> Result<PathBuf, String> {
    fs::create_dir_all(trash_dir).map_err(|e| format!("cannot create {}: {e}", trash_dir.display()))?;
    let name = src
        .file_name()
        .and_then(|n| n.to_str())
        .ok_or_else(|| format!("no file name: {}", src.display()))?;
    let (stem, ext) = name.rsplit_once('.').unwrap_or((name, ""));
    let mut target = trash_dir.join(name);
    let mut n = 1;
    while target.exists() {
        target = trash_dir.join(if ext.is_empty() { format!("{stem}.{n}") } else { format!("{stem}.{n}.{ext}") });
        n += 1;
    }
    fs::rename(src, &target).map_err(|e| format!("cannot move {} to {}: {e}", src.display(), target.display()))?;
    Ok(target)
}

/// The importer's core, on injected directories — see the module comment.
pub fn import_drafts(
    conn: &mut Connection,
    paths: &StashPaths,
    dirs: &DraftDirs<'_>,
    session: Option<Session>,
    now: i64,
) -> (Option<Session>, ImportReport) {
    let mut report = ImportReport::default();
    let drafts = scan(dirs.session_dir, now, &mut report);
    // Draft name → note path, for drafts whose note reads back byte for byte.
    let mut notes: HashMap<String, String> = HashMap::new();
    let mut movable: Vec<&Draft> = Vec::new();
    for draft in &drafts {
        let repo = project_of_draft(session.as_ref(), &draft.name);
        match import_one(conn, paths, draft, repo.as_deref(), now) {
            Ok((entry, created)) => {
                if !reads_back(&entry.path, &draft.text) {
                    report.errors.push(format!(
                        "{}: note {} does not read back as the draft — draft kept",
                        draft.name, entry.path
                    ));
                    continue;
                }
                if created {
                    report.imported += 1;
                } else {
                    report.reused += 1;
                }
                notes.insert(draft.name.clone(), entry.path.clone());
                movable.push(draft);
            }
            Err(e) => report.errors.push(format!("{}: {e}", draft.name)),
        }
    }
    let mut session = session;
    if let Some(s) = session.as_mut() {
        // Tabs naming a draft that is no longer in `session/`: an earlier run
        // moved it; its note is in `draft_imports`.
        for tab in s.windows.iter().flat_map(|w| w.tabs.iter()) {
            let Some(name) = tab.untitled.as_deref() else { continue };
            if notes.contains_key(name) || dirs.session_dir.join(name).exists() {
                continue;
            }
            if let Some(note) = note_from_history(conn, name) {
                notes.insert(name.to_string(), note);
            }
        }
        report.rewritten_tabs = rewrite(s, &notes);
        if report.rewritten_tabs > 0 {
            if let Err(e) = crate::session::write_session_in(dirs.data_dir, s) {
                // The file on disk still names the drafts: they stay, so the
                // next launch finds them (and reuses their notes).
                report.errors.push(format!("session not rewritten, drafts kept: {e}"));
                return (session, report);
            }
        }
    }
    for draft in movable {
        match move_into_trash(&draft.path, dirs.trash_dir) {
            Ok(_) => report.trashed += 1,
            Err(e) => report.errors.push(e),
        }
    }
    (session, report)
}
```

```rust
/// `import_drafts` for the live app, in `setup`: after `StashState` is
/// managed, before `set_pending`. Never blocks startup: without a stash, or

pub fn run_at_startup(app: &tauri::AppHandle, loaded: Option<Session>) -> Option<Session> {
```

```ts
/**
 * A note's title, exactly as Rust's `stash::notes::title_of` makes it: the
 * stash shows Rust's, the tab card and window title this one, live. Both
 * test suites read `src-tauri/tests/fixtures/note-titles.json`.
 */
export const NOTE_TITLE_MAX = 120;

/** Nothing but whitespace: such a tab is still a blank new note. */
export function isBlankText(text: string): boolean {
  return text.trim() === '';
}

/**
 * `[start, end)` of the first non-blank line. Walks line by line and never
 * splits the whole text: this runs on every keystroke.
 */
function firstLineSpan(text: string): [number, number] | null {
  let start = 0;
  for (;;) {
    const nl = text.indexOf('\n', start);
    const end = nl === -1 ? text.length : nl;
    if (text.slice(start, end).trim() !== '') return [start, end];
    if (nl === -1) return null;
    start = nl + 1;
  }
}

export function noteTitle(text: string): string | null {
  const span = firstLineSpan(text);
  if (span === null) return null;
  const line = text.slice(span[0], span[1]).trim();
  const heading = /^#{1,6}(?:[ \t]+(.*?))?(?:[ \t]+#+)?[ \t]*$/.exec(line);
  const title = (heading ? (heading[1] ?? '') : line)
    .replace(/^(?:>[ \t]?)+/, '')
    .replace(/^[-*+][ \t]+\[[ xX]\][ \t]+/, '')
    .replace(/^[-*+][ \t]+/, '')
    .replace(/\*\*/g, '')
    .replace(/\*/g, '')
    .replace(/`/g, '')
    .trim();
  if (title === '') return null;
  // Characters, not UTF-16 units: Rust counts `char`s.
  const chars = Array.from(title);
  return chars.length > NOTE_TITLE_MAX ? chars.slice(0, NOTE_TITLE_MAX).join('') : title;
}

/** What follows the first non-blank line — a note's body under its title. */
export function afterFirstLine(text: string): string {
  const span = firstLineSpan(text);
  return span === null ? '' : text.slice(span[1] + 1);
}
```

```ts
    if (!deps.notes || !tab || tab.path !== null || birthing.has(tabId)) return false;
    const failedAt = birthFailedAt.get(tabId);
    if (failedAt !== undefined && deps.now() - failedAt < NOTE_RETRY_MS) return false;
    const text = heldText(tabId);
    return text !== null && !isBlankText(text);

  /**
   * Queue a birth for each of `ids` that wants one. Never awaited: this is
   * called from inside queued operations, and the birth waits for that slot.
   */
  function scheduleBirths(ids: readonly string[]): void {
    for (const id of ids) {
      if (!wantsNote(id)) continue;

      void queue.run(() => becomeNoteNow(id)).catch((err: unknown) => {
        birthing.delete(id);
        console.error('Failed to make a note of the tab:', err);

    }

    birthFailedAt.set(tabId, deps.now());
    deps.notes?.failed(error);
    return { kind: 'failed', error };

  /**
   * Stash plan 03, D1–D3: untitled `tabId` with text becomes a note. Runs in
   * the queue, so the active tab cannot change underneath it. The editor
   * state is never replaced: Rust writes the text as it was, the tab claims
   * the note (the Save As flow — a refusal writes nothing to the tab), and a
   * live document that moved on during the awaits is dirty against it and
   * written by the ordinary flush.
   */
  async function becomeNoteNow(tabId: string): Promise<NoteBirth> {
    const notes = deps.notes;
    birthing.add(tabId);
    try {
      const tab = findById(list, tabId);
      if (!notes || !tab || tab.path !== null) return { kind: 'skipped' };
      const text = heldText(tabId);
      if (text === null || isBlankText(text)) return { kind: 'skipped' };
      let created: string;
      try {
        created = (await notes.create(text)).path;
      } catch (err) {
        return failBirth(tabId, message(err));
      }
      // The note holds `text` from here on, whatever happens to the tab.
      const step = decideSaveAs(await notes.claim(tabId, created), created);
      if (step.kind === 'blocked') return failBirth(tabId, `the tab could not take ${created}`);
      birthFailedAt.delete(tabId);
      if (!findById(list, tabId)) return { kind: 'skipped' };
      if (tabId === list.activeId) {
        // Read and flagged with no await in between, then flushed: what was
        // typed during the two awaits is written by the ordinary save path.
        const live = deps.editor.current()?.doc.toString() ?? text;
        const dirty = live !== text;
        deps.doc.setActive(step.path, dirty, text, 'lf');
        publish(updateTab(list, tabId, { path: step.path, dirty }));
        await flushWithRetries();
        // As Save As: Rust marks the tab active on its new file (and the watcher follows).
        await deps.rust.activate(tabId);
      } else {
        const cached = cache.get(tabId);
        cache.set(tabId, {
          state: cached?.state ?? null,
          content: null,
          cursor: cached?.cursor ?? 0,
          topLine: cached?.topLine ?? 1,
          scroll: cached?.scroll ?? null,
          // What Rust wrote: returning to the tab reuses its cached state.
          baseline: text,
          enterAt: cached?.enterAt ?? null,
          lineEnding: 'lf',
        });
        publish(updateTab(list, tabId, { path: step.path, dirty: false }));
      }
      deps.settled();
      return { kind: 'born', path: step.path };
    } finally {
      birthing.delete(tabId);
    }
  }
```

```ts
/**
 * ⌃T: put the active document away (stash spec «Клавиатура»), as a webview
 * key. A Ctrl-only menu accelerator never fires from the keyboard — the
 * WKWebView takes the chord before NSMenu (CLAUDE.md, measured 2026-09-25) —
 * so it is caught here, like ⌃Tab, and File → «Отложить в тайник» has no
 * key. Takes CodeMirror's (and Cocoa's) `transposeChars` on purpose. ⌃S
 * (open the stash) joins this handler in stage 04.
 */

/** ⌃T by the physical key (any layout), ⌃ alone. */
export function isCtrlT(e: KeyboardEvent): boolean {
  return e.ctrlKey && !e.metaKey && !e.altKey && !e.shiftKey && e.code === 'KeyT';
}

/**
 * The listener. Installed in the capture phase on the window right after
 * `ctrlTabHandler` (App's `onMount`), before the drawer's own listener, so
 * neither the drawer nor CodeMirror sees the key.
 */
export function stashKeysHandler(actions: { putAway(): void }): (e: KeyboardEvent) => void {
  return (e) => {
    if (!isCtrlT(e)) return;
    e.preventDefault();
    e.stopImmediatePropagation();
    // A held ⌃T would put away tab after tab; an IME composing owns the key.
    if (e.repeat || e.isComposing) return;
    actions.putAway();
  };
}
```

`src/lib/stash/stash-marks.svelte.ts`:

```ts
import type { StashEntry } from './types';
import { markOf, type StashMark } from './marks';

/**
 * Per window: which open documents are notes or stashed files, for the tab
 * cards and the window title. A cache over `stash_entry_for_path`, refreshed
 * on `stash-changed`; it decides nothing that writes (D13).
 */
export function createStashMarks(lookup: (path: string) => Promise<StashEntry | null>) {
  let marks = $state<Record<string, StashMark | null>>({});
  /** Path → the request whose answer may land. */
  const asked = new Map<string, number>();
  let seq = 0;

  async function fetchOne(path: string): Promise<void> {
    const mine = ++seq;
    asked.set(path, mine);
    let entry: StashEntry | null;
    try {
      entry = await lookup(path);
    } catch {
      // Unknown, not "not in the stash": asked again next time.
      if (asked.get(path) === mine) asked.delete(path);
      return;
    }
    if (asked.get(path) !== mine) return;
    marks = { ...marks, [path]: markOf(entry) };
  }

  return {
    get(path: string | null): StashMark | null {
      return path === null ? null : (marks[path] ?? null);
    },
    /** Ask for every path not known or asked yet. */
    ensure(paths: readonly (string | null)[]): void {
      for (const p of new Set(paths)) {
        if (p !== null && !(p in marks) && !asked.has(p)) void fetchOne(p);
      }
    },
    refresh(paths: readonly string[]): Promise<void> {
      return Promise.all(paths.map(fetchOne)).then(() => {});
    },
    /** An entry this window just made (a note birth): known at once, over any answer in flight. */
    learn(entry: StashEntry): void {
      asked.set(entry.path, ++seq);
      marks = { ...marks, [entry.path]: markOf(entry) };
    },
  };
}

export type StashMarks = ReturnType<typeof createStashMarks>;
```

```ts
/** What a tab card shows about the stash (mockup `cardHTML`). */
export type CardStash = { kind: 'note'; repo: string | null } | { kind: 'in-stash' } | { kind: 'blank' };

export interface Caption {
  name: string;
  stash: CardStash | null;
}

export interface CaptionInput {
  path: string | null;
  /** `noteTitle` of the text the tab holds; `undefined` when the text is not known. */
  title: string | null | undefined;
  /** The tab holds nothing but whitespace. */
  blank: boolean;
  mark: StashMark | null;
}

/**
 * A tab's caption (stash spec «Отметка тайника»): a blank untitled tab is a
 * new note; a note shows its live title (its stored one while the text is
 * unknown) with the stash glyph; a file keeps its name, with the small glyph
 * when it is in the stash. No «в тайнике» text anywhere.
 */
export function tabCaption({ path, title, blank, mark }: CaptionInput): Caption {
  if (path === null) {
    return blank ? { name: t('stash.new_note'), stash: { kind: 'blank' } } : { name: title ?? t('stash.new_note'), stash: null };
  }
  if (mark?.kind === 'note') {
    const name = title === undefined ? (mark.title ?? t('stash.untitled_note')) : (title ?? t('stash.untitled_note'));
    return { name, stash: { kind: 'note', repo: mark.repo } };
  }
  return { name: path.split('/').pop() || path, stash: mark?.kind === 'file' ? { kind: 'in-stash' } : null };
}

/** A repo (the project's absolute root) as the card shows it: its last component. */
export function repoLabel(repo: string | null): string {
  if (!repo) return '';
  return repo.split('/').filter(Boolean).pop() ?? repo;
}
```

- [ ] **Step 3: CLAUDE.md — gotchas** (append to «Gotchas»):

```markdown
- **An untitled tab is a pending note; its first non-blank character makes it a note** (stash plan 03). `becomeNoteNow` runs in the tab queue: `stash_create_note(text)` → `tab_claim` (the Save As flow, `decideSaveAs`) → `doc.setActive(notePath, dirty = live !== text, baseline = text)` → the ordinary flush. The editor state is never swapped, so undo and every key typed during the awaits survive; nothing awaits between reading the live doc and starting the flush. Births also run for background untitled tabs with text on every `settle` and arrival. A failed create backs off `NOTE_RETRY_MS` with a `stash-error` toast; the text stays in the tab and its session draft, and the startup importer rescues the draft next launch.
- **What a close does to the stash is decided in Rust, in `tab_close`** (`stash::lifecycle`), never from the frontend's marks cache: a live note is put away with the caret; a note whose file is blank is discarded (only here — after the frontend flushed; the red button and quit never discard, the last ≤300 ms may not be on disk); `putAway: true` (⌃T) makes a file a reference. The red button and quit stamp notes put away. `StashState`'s connection is taken with no other lock held.
- **A note never binds a window's project.** Outside git a file's project is its folder, so the first note in a fresh window would bind it to `~/Documents/couplet` and tag every later note with it. `TabRegistry::unbound_windows` takes a predicate; `bind_missing_projects` passes `!stash::paths::is_note_path`.
- **The draft importer runs at every startup, between `read_session()` and `set_pending`.** Order: note + row + `draft_imports(source, fingerprint)` in one transaction → read the note back and compare bytes → rewrite the pending session and write `session-v2.json` (same `saved_at`) → only then `rename` the source into `session/.trash/`. Blank, non-UTF-8 and symlinked sidecars are left alone. A crash anywhere leaves the text in two places and the next run finishing without a duplicate.
- **The native title bar cannot draw SVG:** a note's window title carries the text glyph `STASH_TITLE_GLYPH` (`window-title.ts`); the drawer card uses the SVG tray (`StashGlyph.svelte`).
- **⌃T is a page key** (`stash-keys.ts`, capture phase, registered right after `ctrlTabHandler`, `e.code === 'KeyT'`, ⌃ alone, `e.repeat` swallowed). File → «Отложить в тайник» has no accelerator; `stash-keys.test.ts` fails if `menu.rs` ever declares `Ctrl+T` or `Ctrl+S`.
```
