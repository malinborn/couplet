# Тайник (stash) в couplet — исследование и решения

> **Итоговая версия, 2026-09-26.** Дизайн согласован с Max. Эталон интерфейса — макет `docs/investigations/2026-09-26-stash-mockup/stash-drawers.html` (v6, git-тег `stash-mockup-approved`). Споры о виде решает макет, о поведении — этот отчёт.
>
> Повод: после `brew upgrade` (2.0.0 → 2.0.1) пропал untitled с планами. Задача: couplet сам хранит документы без имени, их нельзя потерять, и человеку не нужно думать, куда и под каким именем сохранять.
>
> Как шли к решению: v1 — исследование и «полка»; v2 — блокнот Max, теги, «стэш»; v3 — SQLite и два дровера; v4 — перенос между дроверами, без перекрытий; v5 — «тайник», корзина, один список; итог — фокус ободком, макет утверждён.

## Коротко

**Зачем.** Эту боль уже лечили BBEdit (Notes в версии 14 — прямой ответ на «у меня висит 300+ untitled»), Drafts, Apple Notes и iA Writer. У VS Code и Zed были такие же потери untitled на «перезапуске для обновления». Это не выдумка.

**Название.** По-русски — **тайник**, по-английски — **stash**.

**Модель (раздел 4.1–4.4):**
- Все документы по умолчанию лежат в тайнике: хрупкого untitled больше нет. Пустой untitled при закрытии просто исчезает.
- Жест **«отложить»** (`⌃T` — кандидат) убирает документ с глаз, но оставляет его в тайнике под рукой; время, когда документ отложили, видно на карточке.
- Тайник хранит **заметки** (их текст ведёт couplet) и **ссылки на файлы** (файл остаётся где был и не меняется). Тег на файле = отложить его в тайник.
- **Теги**, несколько на документ; **тег репо** ставится сам, окно проекта открывает тайник уже отфильтрованным по своему репо. Быстрые теги по клавише — потом.
- **Дедупликация:** один документ — одна запись, откуда бы его ни откладывали.
- **Корзина своя, не macOS:** удалённая заметка 30 дней лежит в «Удалённых» и возвращается вместе с тегами. У ссылки на файл корзины нет — удаляется только ссылка.

**Хранение (4.3):** SQLite — источник правды (записи, теги, ссылки); текст заметок — `.md`-файлы, путь в БД. Транзакции, ежедневные бэкапы, плоский экспорт рядом с заметками. База не в iCloud.

**Интерфейс (4.5), по утверждённому макету:**
- Внизу дровера вкладок — кнопка «Тайник» со сводкой; во время перетаскивания вкладок эта область становится зоной сброса «Отложить в тайник».
- Кнопка открывает справа **второй дровер** — тайник, своего цвета. Открыты оба сразу, фон размыт так же сильно, как при карусели окон.
- **Дроверы — это перенос:** открытое вкладкой в этом окне в тайнике не показывается; перетащил — документ ушёл с одной стороны и появился на другой. Открытое в других окнах видно с пометкой «открыта в #N».
- **Никогда не перекрываются:** в узком окне оба компактны и стоят рядом; слишком узкое окно само раздвигается и потом возвращается к прежнему размеру.
- **Фокус** переключается `←`/`→` и виден только по светящемуся ободку; дровер без фокуса не приглушается.
- Один список без секций; сортировка «изменение ⌘L · открытие ⌘R · тип ⌘U»; внизу тайника — «Удалённые · N».

**Агент (4.6):** методы `stash_list`, `stash_get`, `stash_add`, `stash_tag`; заметки — обычные файлы, так что `show`/`edit` работают с ними по пути.

**Открыто (раздел 8):** папка заметок, клавиши, фаза 0 — срочный патч 2.0.2, чтобы текущие untitled больше не пропадали, пока тайник строится.

## 2. Что сломалось и почему это типовая ошибка

Untitled в couplet — это вкладка с `path: null`, чей текст лежит в `session/draft-<tab_id>.md`. Раз в секунду couplet сохраняет сессию и **удаляет все черновики, на которые она больше не ссылается** (`prune_untitled_files`, `lib.rs:417`). Если при обновлении, миграции или падении хоть одна ссылка потерялась, сборщик мусора превращает это в удаление данных. Копии нет.

Так же падали и другие:

| Приложение | Где держало untitled | Что случилось |
|---|---|---|
| VS Code [#69972](https://github.com/microsoft/vscode/issues/69972), [#70247](https://github.com/microsoft/vscode/issues/70247) | бэкапы, найденные через метаданные сессии | после «Restart to Update» вкладки Untitled вернулись пустыми |
| Zed [#30665](https://github.com/zed-industries/zed/discussions/30665) | SQLite, привязка к воркспейсу | «lost many months of unsaved buffers». Данные остались в базе, пропала только ссылка на них |
| Sublime Text | прямо внутри файла сессии | файл сессии сломался — буферы пропали вместе с ним |

Общее у всех: **пользовательский текст живёт как часть состояния сессии.** Надёжное хранилище так не устроено.

## 4. Модель тайника

### 4.1 Две сущности: заметки и ссылки на файлы

| | Заметка | Файл |
|---|---|---|
| Где лежит текст | в папке тайника, им владеет couplet | там, где был; couplet его не трогает |
| Как попадает в тайник | сама, с первого символа | явно: «отложить» или поставить тег |
| Что хранит тайник | файл + метаданные | только ссылку: путь, теги, каретку, дату |
| Удалить из тайника | текст уходит в корзину на 30 дней | удаляется только ссылка, файл остаётся на месте |
| Тег репозитория | запоминается при создании (проект окна) | вычисляется сам из git toplevel пути |

Правила:
- **Тег = отложено.** Тегу нужно где-то жить: поставил тег файлу — файл появился в тайнике. Отдельного решения «спрятать файл в тайник» нет.
- **Открытый файл сам в тайник не попадает**, иначе тайник станет копией Recent Files. Автоматически в тайнике только заметки, файлы попадают туда по жесту человека.
- **Теги не пишутся внутрь файлов**, никакого frontmatter. Файл пользователя остаётся байт-в-байт тем же, иначе git покажет diff от couplet. Метаданные лежат в базе тайника (4.3).
- **Дедупликация (Max).** У файла ключ — нормализованный путь (`path_norm`), то же правило «один файл — одна запись», что у вкладок; в базе это уникальный индекс. У заметки дубль невозможен в принципе: она уже в тайнике, и «отложить» ставит отметку, а не создаёт копию. Повторно отложить уже лежащий документ — ничего не добавить: поднимает его наверх, сливает теги, обновляет каретку. Известная дыра: `path_norm` не сворачивает регистр, а APFS к регистру нечувствителен, так что `A.md` и `a.md` пока две записи.
- **Виды различаются иконкой**, а «удалить» у файла подписано «убрать из тайника». Так никто не испугается, что удалит настоящий файл.
- **Битая ссылка** (файл переместили или удалили вне couplet) показывается как «файл не найден» с вариантами «найти» и «убрать». Позже можно хранить macOS bookmark data: такая ссылка переживает перемещение файла на том же томе. Первой версии это не нужно.

Отвергнуто:
- **Класть в тайник только заметки.** Ломает единую модель: тег репо не поставишь на README, который обсуждаешь с агентом.
- **Копировать файл внутрь тайника.** Две копии разъедутся, и непонятно, какая настоящая.

### 4.2 Жизненный цикл заметки

```mermaid
stateDiagram-v2
    [*] --> Пустая: ⌘T / ⌘N
    Пустая --> [*]: закрыли, ничего не набрав (#1)
    Пустая --> Открыта: первый символ → файл создан
    Открыта --> Отложена: ⌃T «отложить» / ⌘W / закрыли окно / выход
    Отложена --> Открыта: выбрали в тайнике
    Открыта --> Файл: «Сохранить как…» — переезд в выбранную папку
    Отложена --> Корзина: удалить
    Открыта --> Корзина: удалить
    Корзина --> Отложена: восстановить (30 дней)
    Корзина --> [*]: 30 дней прошло
```

**«Отложить» — явный жест (Max).** Заметка и так в тайнике, но иногда документ хочется убрать, чтобы не мозолил глаза, и при этом легко до него дотянуться. «Отложить» закрывает вкладку, а в тайнике ставит документу отметку «отложено» — наверх списка. Для файла тот же жест создаёт ссылку в тайнике.

**Клавиша: `⌃T` (кандидат).** Две оговорки:
1. Только обработчик на странице, как `⌃Tab` и `⌃1…9`. Хоткей только с Ctrl, назначенный пункту меню, с клавиатуры не срабатывает (выяснено 2026-09-25, см. CLAUDE.md). В меню пункт можно показать без клавиши.
2. Это транспозиция символов в CodeMirror (`Ctrl-t: transposeChars`) и в текстовых полях macOS. Ею почти никто не пользуется, а Ctrl-сочетания у нас уже отданы навигации, так что `⌃T` хорошо встаёт в этот ряд.

### 4.3 Хранение

**Решено (Max): SQLite — источник правды для тайника, текст заметок — `.md`-файлы, путь к ним в БД.** Аналогия с `.mdmini_comments` здесь не работает. Комментарии лежат файлами, чтобы ИИ работал с любыми файлами в любых обстоятельствах и не терял их. У тайника файла может не быть вовсе, как у untitled, а тегам нужен один источник правды.

| Что | Где | Роль |
|---|---|---|
| Записи тайника, теги, отметка «отложено», ссылки на файлы, тег репо, ключи дедупликации | SQLite, `Application Support/couplet/stash.db` | **источник правды** |
| Текст заметок | `.md`-файлы в папке тайника, по одному на заметку, запись через `atomic_write::save`; путь записан в БД | данные; агенты открывают их существующими `show`/`edit` по пути |
| Поиск по тексту (FTS5), позже векторы для RAG (`sqlite-vec`) | та же SQLite | производное, пересобирается из текста |

Раз база — правда, защищаем её так же, как текст:
- **Транзакции.** «Отложить» несколько вкладок сразу — одна транзакция: либо все в тайнике, либо ни одна.
- **Бэкапы.** Раз в день онлайн-бэкап SQLite в `backups/`, хранить последние 7. Плюс снимок в плоский `.stash-export.json` рядом с заметками: его переживёт и `brew uninstall --zap`, и его можно прочитать без couplet.
- **База не в iCloud.** Синхронизация iCloud портит SQLite, особенно в режиме WAL, поэтому база лежит в `Application Support`. Заметки могут лежать где угодно.
- **Ни одного удаления без корзины** — ни для записи, ни для текста.
- **Сессия ссылается на заметки, но не владеет ими.** Сборщик мусора сессии к тайнику не прикасается ни при каких условиях.
- **Зависимость:** `rusqlite` с `bundled`. Сейчас в проекте никакой БД нет, так что дублирования нет. Бинарь вырастет примерно на 1–2 МБ.

**Папка заметок** (открыто, вопрос 1):

| | `~/Documents/couplet/` ✅ | `~/Library/Application Support/couplet/stash/` |
|---|---|---|
| Видна в Finder | да | нет |
| Spotlight ищет по тексту | да | нет, `~/Library` не индексируется |
| Переживает `brew uninstall --zap` | **да** | **нет, zap сносит всю папку** |
| Риски | при синхронизации «Документы в iCloud» неиспользуемые файлы могут выгружаться из iCloud; с этим надо научиться работать | — |

**Имена.** Файл получает стабильное имя, которое не меняется: `2026-09-26-0215-a3f9.md`. Заголовок для показа берётся из первого `#`-заголовка или первой строки. При правке заголовка файл не переименовываем: на путь в couplet завязано всё — dedup, комментарии, маршрутизация агентов.

### 4.4 Теги

- У заметки или файла может быть несколько тегов (#7).
- **Тег репо ставится автоматически (#2, #6).** У заметки это проект окна, в котором её создали. У файла — git toplevel его пути, вычисляется, не хранится.
- **Окно проекта само фильтрует тайник по тегу своего репо.** Фильтр снимается одним жестом: чип тега можно закрыть. В окне без проекта видно всё.
- **Быстрые теги (#8) — отложены (Max).** Идея «тег N по клавише с цифрой» остаётся на потом; `⌘⇧T` для неё в любом случае занят (возврат закрытой вкладки).
- Фильтр по тегам — в той же строке поиска, что и по тексту: `#tag` в запросе.

### 4.5 Где тайник живёт в UI

**Решено (Max): два дровера.** Тайник общий для приложения и живёт отдельно от вкладок: вкладки — это то, что сейчас открыто, тайник — то, что хранится. Смешать их — снова размыть разницу между «на виду» и «сохранено», из-за которой всё и случилось.

**Нижняя область дровера вкладок.** Сейчас там подсказка «⇧ click / drag — select · ⌘ click — close».
- **В покое:** кнопка «Тайник» и короткая сводка, например «Тайник · 24 · отложено сегодня 3», с клавишей.
- **Пока тащишь вкладки:** область превращается в зону сброса «Отложить в тайник». Бросил — вкладки ушли из дровера и оказались в тайнике, одной транзакцией.
- С каруселью это не конфликтует: карточка, вытащенная на страницу, по-прежнему открывает карусель окон, а брошенная вниз дровера уходит в тайник. Цели разные и видны в разных местах.

**Второй дровер справа.** Кнопка открывает дровер тайника у правого края — зеркальный левому, своего цвета. Открыты оба сразу, фон за ними размыт, как сейчас.
- **Тайник → вкладки** — открыть документ вкладкой в этом окне. **Вкладки → тайник** — отложить.
- Перетаскивание в couplet своё, на указателе, а не HTML5 — его и переиспользуем между дроверами.
- **Дроверы — это перенос (Max, по макету v2).** Документ, открытый вкладкой в этом окне, в тайнике этого окна **не показывается**: один документ не виден с двух сторон. Тайник → вкладки — карточка уходит из тайника и появляется во вкладках; закрыть или отложить вкладку — карточка уходит из вкладок и появляется в тайнике. Документы, открытые в *других* окнах, в тайнике видны с пометкой «открыта в #N»; открыть такой отсюда — он переезжает из того окна. В заголовке тайника полный размер («Тайник · 16»), в строке фильтра — видимые плюс открытые вкладками («4 из 16 · 2 во вкладках»).
- **Ширина — дроверы никогда не перекрываются (Max, по макету v2).**
  - Окно шире 960px: дроверы в обычной ширине (вкладки 420px, тайник 400px), между ними видна страница.
  - Уже 960px: оба стоят рядом с зазором 40px под хлястик, каждый `(100% − 40px) / 2`, но не меньше 320px, и оба переходят на компактные карточки, как View → Tabs → Compact. Карусель окон здесь не появляется — между дроверами нет места; зона сброса и перетаскивание между дроверами работают.
  - Уже 680px (2 × 320 + 40): при открытии тайника **окно само раздвигается** до 680px (упирается в правый край экрана — ещё и сдвигается влево) и возвращается к прежним размеру и месту, когда тайник закрывается. Тост: «Окно раздвинулось, чтобы тайник встал рядом · вернётся, когда тайник закроется». В приложении это `setSize`/`setPosition` в пределах рабочей области монитора, разрешение `core:window:allow-set-size`; окно в полноэкранном режиме или Split View не трогаем — там места и так хватает.
- **Цвет.** Свой цвет у дровера тайника — ответ на «stash modes with different colouring» из блокнота. Цвет берём из токена темы, чтобы во всех семействах он выглядел своим.

**Клавиатура (согласовано).** Открытый дровер забирает клавиши (правило Q5). При двух открытых фокус переключается `←`/`→`, а набор текста фильтрует тот дровер, где фокус. Первый Esc сбрасывает поиск, следующий закрывает дровер в фокусе; закрытие дровера вкладок закрывает оба.

**Фокус — светящимся ободком, без приглушения (Max, итог).** Оба дровера всегда в полной яркости. Дровер в фокусе обведён светящимся ободком своего цвета — у вкладок фиолетовый акцент вкладок, у тайника его цвет; у дровера без фокуса ободка нет.

**Фон.** Когда открыты оба дровера, страница размыта и затемнена так же сильно, как при перетаскивании вкладки на карусель окон; когда открыт только дровер вкладок — как раньше, слабее.

**Один список, время «отложено» на каждой карточке (Max, v5).** Секций «Отложено» и «Остальное» нет: после правила «дроверы — это перенос» всё справа и так убрано с глаз, а различие держалось бы на том, каким жестом документ закрыли. Список идёт по выбранной сортировке («изменение» по умолчанию — недавно отложенное сверху). На каждой карточке яркая строка цветом тайника: «отложено только что / сегодня 01:55 / вчера …». Сводка внизу дровера вкладок «отложено сегодня N» остаётся. Сортировка: «изменение ⌘L · открытие ⌘R · тип ⌘U».

**Корзина — своя, не macOS (Max, v5).** Зеркало нижней области дровера вкладок: внизу дровера тайника кнопка «Удалённые · N». Она переключает дровер в режим корзины — карточки приглушены, на каждой «удалится через N дн.», действия «вернуть» (в тайник вместе с тегами) и «удалить навсегда»; назад — кнопкой или Esc. Корзина только у заметок: у ссылки на файл «убрать из тайника» удаляет лишь ссылку. Почему не корзина macOS: она вернёт только файл без записи в базе (теги, «отложено», репо), её можно очистить в любой момент, а автоочистка через 30 дней там необязательна.

**Отметка «stashed» (#4):** в карточке вкладки и в заголовке окна у заметки — значок тайника вместо «Untitled».

**`/command`:** `/stash` в slash-меню — отложить текущий документ и поставить теги, не отрывая рук от клавиатуры.

**Карусель (#10) — итог.** Тайник как ещё одно «окно» в карусели не нужен: в утверждённом макете в тайник кладут через зону сброса внизу дровера вкладок или перетаскиванием на дровер тайника. Карусель остаётся для переноса вкладок между окнами; в широком окне она появляется в промежутке между дроверами, в узком — не появляется. Вопрос из блокнота «нужно ли открывать тайник вместе с дровером» закрыт: да, два дровера рядом.

### 4.6 Агент

Методы для MCP и CLI (#3), в духе couplet — у ИИ те же глаголы, что у человека:

| Метод | Что делает |
|---|---|
| `stash_list` | список: вид (заметка/файл), заголовок, теги, дата, отметка «отложено»; фильтр по тегу и тексту |
| `stash_get` | текст заметки или путь файла |
| `stash_add` | положить текст как новую заметку (аналог `bbedit --note`, через stdin в CLI) или ссылку на файл; с тегами |
| `stash_tag` | поставить или снять теги |

Заметки — это файлы, поэтому существующие `show`/`edit` работают с ними по пути без переделок.

### 4.7 Embeddings (#9)

Семантический поиск по тайнику — отдельная фаза, расширение или плагин. База к этому готова: векторы ложатся в ту же SQLite через `sqlite-vec` рядом с FTS5, а эмбеддинги считает локальная модель (например, LM Studio). В первую версию не берём.

## 5. Фаза 0 — страховка, которую стоит сделать сразу

**Что это такое.** Тайник — большая фича, это недели работы. Всё это время untitled в couplet 2.0.1 остаются такими же хрупкими, как тот, что пропал: следующее обновление или перезапуск может стереть любой из них. «Фаза 0» — маленький отдельный фикс, который выходит **до тайника** патчем 2.0.2 и закрывает эту дыру сразу, не дожидаясь тайника. К самому тайнику он не относится и ничего в его дизайне не решает.

Одним маленьким PR:

1. **Сборщик мусора больше не удаляет, а переносит.** `prune_untitled_files` перемещает черновик в `session/.trash/` с датой, чистка через 30 дней. План лежал бы там.
2. **Rescue-снимок при `⌘W` на untitled** (как в BBEdit), пока тайника нет.
3. **Найти и починить причину** потери ссылок при обновлении. Кандидаты: выход через AppleEvent `quit` от cask записал сессию без черновиков, или окно «что нового» при смене версии перебило восстановление сессии.
4. Правило в CLAUDE.md: **текст пользователя никогда не удаляется без второй копии.**

## 6. Что это меняет в принятых решениях

- Спека вкладок §8: «⌘W на untitled теряет текст — это фича» заменяется на «⌘W откладывает в тайник».
- `closed.rs`: стек `⌘⇧T` по-прежнему для файлов; у заметок есть путь, так что они попадут туда сами.
- Пункт «Открыть окна прошлой сессии» остаётся, но перестаёт быть единственным способом спасти untitled.

## 7. Что пока не делаем

Синхронизация, папки внутри тайника, отдельное окно заметок, версии каждой правки, embeddings (фаза после). Теги из этого списка убраны: они в центре идеи (раздел 4.4).
