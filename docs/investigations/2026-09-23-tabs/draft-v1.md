# Вкладки в couplet — черновик v1 (до прожарки)

## Страхи владельца (цели)
- F1 взрыв количества (Chrome/Sublime)
- F2 страшно закрыть (потеряю / понадобится)
- F3 невозможно держать в порядке
- F4 вкладки забивают окно визуально
- F5 ИИ должен хорошо с ними работать (агент открывает файлы сам, может спамить `show`)
- F6 компоновка: какие вкладки в каком окне

## Ключевые наблюдения
1. Страх закрыть = вкладка единственная ручка к чему-то. В couplet каждый сохранённый документ — файл на диске + автосейв каждые 300мс. Закрытие сохранённого файла без потерь. Единственный реальный риск — untitled.
   → Если закрытие всегда безопасно и переоткрытие тривиально, авто-закрытие дешёвое.
2. Разрастание: открывать дёшево, закрывать вручную. Инвертировать: вкладка по умолчанию эфемерна, «оставить» требует намерения (правка / pin).
3. ИИ — главный генератор открытий. `show` без намерения пользователя не должен плодить постоянные вкладки.
4. Адресация ИИ по пути (не по окну) уже есть — вкладки её не ломают ни в одном варианте.

## Архитектурные варианты
A. Нативные вкладки macOS: вкладка = NSWindow + WKWebView. Архитектура «один документ на окно» сохраняется целиком. Нужен tabbing_identifier + tabbingMode/addTabbedWindow, Window-меню. Бесплатно: системная полоса, Cmd+Shift+\ обзор, перетаскивание вкладки в окно, Merge All Windows. Цена: память на вкладку (WebContent), вид полосы не кастомизируется, italic preview нельзя (только через title), меньше контроля порядка.
B. Вкладки внутри приложения: одно окно, один EditorView, EditorState на документ (setState). Своя тонкая полоса. Цена: большой рефакторинг — все per-window синглтоны App.svelte → per-document; watchers, recovery, session v2, AI-очередь, comments, Cmd+W семантика; вынос вкладки в окно сложен.
C. Без полосы вкладок: буферы + свитчер (Cmd+P / ⌃Tab MRU), на экране ничего. Бэкенд как B. Самое минималистичное, но скрытое накопление.
0. Не делать вкладки: улучшить окна (Window-меню, свитчер по окнам+recent, переиспользование «окна агента»).

## Политика против разрастания (независима от A/B/C)
P1 полоса скрыта при 1 вкладке
P2 preview-слот: «лёгкие» открытия (AI show, клик в recent) идут в один слот, следующий лёгкий заменяет; правка/pin/двойной клик → постоянная
P3 мягкий лимит (напр. 7–8): при превышении LRU-закрытие чистой, незакреплённой → в «недавно закрытые»
P4 протухание (как Arc): не открывавшиеся N часов незакреплённые — закрыть (опционально)
P5 pin — единственный сигнал «держать»
P6 закрытие всегда безопасно: dirty/untitled не вытесняются; Cmd+Shift+T возвращает с кареткой/скроллом; сессия-восстановление вливается в тот же Cmd+Shift+T (как Chrome)
P7 компоновка: окно = проект (git root / каталог); файл из проекта X открывается во вкладку окна X

## ИИ
