F5 регресс: queued:true = агент врёт «показал». F6 не решён. F2 закрыт (лучшая часть, от вкладок не зависит).

- Альтернативы: (a) один AI-стол на всех агентов + единая лента + правило «не угонять» (N сек активности/dirty/ask → тост «Открыть» + запись в ленту); (b) агенты только стучатся — хорош как режим (a) с N=∞; (c) LRU-автозакрытие — агентские show выселяют мою заметку → возврат к двум видам; (d) только окна + свитчер — мусор сейчас от агентов, после (a) вкладки могут быть не нужны; (e) лента как md-файл с `- [ ]` ссылками (агенты без MCP дописывают, принцип сайдкаров).
- Рекомендация R2: v1 = фундамент 0′ + одно AI-окно (переиспользуемое) + правило «не угонять» с честным ответом delivered:"screen"|"inbox" + лента = панель Recent (агентские жирные до открытия, подпись проект/ветка) + ask вне экрана = тост «Ответить». Без вкладок. Через неделю — (e) или B-lite без полос (вкладка = файл, AI-стол — одна закреплённая вкладка). Отклонить v3-полосы и (c).
