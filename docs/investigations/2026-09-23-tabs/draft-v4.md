# Вкладки в couplet — черновик v4 (после прожарок №1, №1b, №2)

## Принцип
**Агент не владеет местом в интерфейсе.** Вкладки появляются только от намерения человека. У ИИ ровно одно место на всех — «AI-стол». Одно правило «не угонять» решает, может ли ИИ поменять то, что на экране.

Почему: полосы на агента (v3) порождали ~20 компенсирующих механизмов и переносили страх F1 (8 живых сессий = 8 вечных полос), а не закрывали его (прожарка №2). Прецедент ровно того, чего боится владелец: Claude Code в VS Code — diff-вкладка на каждый Edit. Противоядие в индустрии: Zed Agent Panel (одно представление вместо N вкладок), Little Arc (внешнее — во временную поверхность).

## Слои (каждый полезен сам по себе, можно остановиться после любого)

### L0. Фундамент — чинит баги, которые есть СЕГОДНЯ
- `switchDocument()` — единственный путь смены документа в окне: flush автосейва; dedup (файл уже открыт → туда); untitled с текстом → drafts; свежий EditorState (закрывает утечку undo: сейчас Cmd+Z после Cmd+O/Recent вписывает куски старого документа в новый и автосейвит); коммит пауз комментариев; перенос/отмена `ask` и AiPending по (окно, путь); сброс оверлеев (hover-menu, cell-edit); режим по типу файла; нельзя уйти с документа с упавшим сохранением.
- Untitled никогда не теряется (сейчас Cmd+W → prune удаляет; коллизия `untitled-main.md` между запусками).
- «Недавно закрытые» + Recent — в Rust (сейчас localStorage last-writer-wins между окнами); ⌘⇧T = вернуть закрытое, а в свежем запуске — прошлую сессию.
- Identity в AI-запросе (обратносовместимое поле): `CLAUDECODE=1` → агент, `CLAUDE_PROJECT_DIR` + ветка → подпись. Честный статус доставки в ответе: `delivered: "screen" | "inbox"`.
- ~8–10 файлов, ~1–1.5k строк (оценка R1).

### L1. AI-стол (вкладок ещё нет)
- `show`/`edit` агента по файлу, который нигде не открыт, НЕ создают новое окно — идут в одно переиспользуемое AI-окно (создаётся по требованию). Файл открыт у меня → dedup, как сейчас.
- **Правило «не угонять»** (одно на всё приложение): если там, куда ИИ хочет переключить экран, человек занят — был ввод/скролл последние 60 с, dirty, открыт `ask`, черновик комментария — экран не трогаем: тост «infra · report.md — Открыть» + запись в ленту, агенту `delivered:"inbox"`. Иначе переключаем, `delivered:"screen"`.
- **Лента** = эволюция панели Recent: всё, что показывали агенты, хронологически, непрочитанное жирным, подпись «проект/ветка», хоткей. Замещённый на столе документ не пропадает — он в ленте. «Оставить» (⌘↩) = открыть у себя (отдельное окно в L1, вкладка в L2).
- `ask` по документу не на экране → тост «Ответить» (+ опционально Dock bounce). Дедлайн `ask` абсолютный, в payload.
- Вид: хрома нет вовсе. Заголовок AI-окна «документ · проект/ветка».

### L2. Вкладки = файлы (B-lite без полос)
- Вкладки внутри окна для документов, открытых человеком (⌘T, ⌘O, Finder, CLI человека, drop, «Оставить» из ленты). Живая только активная вкладка (синглтоны App.svelte остаются синглтонами); неактивная = `{path, pos, очищенный EditorState}`; при возврате сверка mtime+хеш.
- ИИ и фоновые вкладки — то же правило «не угонять»: `show` файла из моей фоновой вкладки → переключит, если я не занят, иначе тост; `edit` → сразу на диск (atomic_write), подсветка при активации; `ask` → тост «Ответить».
- AI-стол в L2 — либо отдельное окно (как в L1), либо особая вкладка «AI» в главном окне (решает владелец).
- Полоса вкладок скрыта при 1 вкладке; текстовые вкладки; новая — справа от текущей; «Закрыть остальные» безопасно (всё в «недавно закрытых»). Лимита нет: вкладки растут только от моего намерения; вернуться к TextMate-LRU, если всё же разрастутся.
- «Переместить в новое окно» — командой. Session v2 (`session-v2.json`, старый не трогаем; миграция v1→v2).
- ~1.2–1.6k строк + тесты поверх L0 (B-lite минус полосы).

### L3. Потом / опционально
- Лента как обычный md-файл (`- [ ] 10:14 проект — [doc](path)`) — агенты без MCP могут дописывать, принцип сайдкаров. Проверить кликабельность ссылок.
- Нативные вкладки (A) — не рекомендуем: ~58MB на вкладку, objc на main thread (тихая смерть процесса в спайке), игнор системной «Prefer tabs», нет своих маркеров.

## Страхи → чем закрываем
- F1 взрыв: агенты вкладок не создают; вкладки = только мои намерения.
- F2 страшно закрыть: закрытие без потерь (автосейв, drafts, ⌘⇧T, лента).
- F3 порядок: вкладки в порядке открытия; всё агентское — одна хронологическая лента с подписями.
- F4 экран: в L1 хрома нет; в L2 полоса видна только при ≥2 моих вкладках.
- F5 ИИ: одно место, честная доставка, «не угонять», ask — тост.
- F6 компоновка: мои вкладки — во фронтальном окне; ИИ — на столе.

## Жертвуем
- Два агентских документа рядом — только через «Оставить».
- Нативные жесты вкладок (drag между окнами, ⌘⇧\), системный вид полосы.
- Автономия агента: он не может показать поверх моей работы (фича).
- Undo фоновой вкладки теряется, если файл изменился снаружи.
- Фоновые вкладки не живые: ответ агента на комментарий в фоновом документе виден при переключении (или лёгкий watcher ради точки).
- В L1 вкладок для своих документов нет вообще.
