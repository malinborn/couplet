# Прожарка №1b (архитектор) — B-lite
Вердикт: убийственного изъяна нет; 0′ → B-lite поддержан. B-lite ~1.5–2k строк + ~1k тестов поверх 0′ (≈вдвое больше A по строкам), но риск в контролируемом коде, проверяемом в npm run dev + Playwright; у A риск в objc (тихая смерть процесса), проверяемо только на бандле.
Протечки через переключение (лечит switchDocument как «выгрузку»):
- паузы комментариев уходящего документа коммитить при переключении (как blur, App.svelte:1295); CloseRequested коммитит только один документ.
- черновики комментариев сейчас обнуляются (:295) — для вкладок потеря; писать как paused-тред или хранить per-tab.
- УПАВШЕЕ СОХРАНЕНИЕ: dirty текст уезжает в фон без recovery и ретраев, тост save-error гасится успешным сохранением ДРУГОГО документа → тихая потеря. Запретить переключение с документа с упавшим сохранением (или держать живым).
- AiPending по label: закрытие вкладки ничего не отменяет (таймаут до 3600с) → ключ (label,path), cancel_for_tab.
- heartbeat сессии — открытие/закрытие вкладок слать сразу.
- фоновые документы без watcher'а: answer агента пишет файл мимо сокета — точку не поставить без лёгкого watcher'а.
- hover-menu/cell-edit оверлеи держат старую позицию → blur + закрыть оверлеи до setState.
Кеш EditorState — ДА, но очищенный: при уходе снять ask-виджеты, карточки комментариев, scrollSnapshot; при возврате сверить mtime+хеш (расхождение → выбросить кеш), переприменить applyPreviewConfig/lineGlow/setDocumentPath, reloadComments, заново вставить ask из Rust. Тема/mermaid-кеш/ai-highlight/pan-zoom безопасны. Одна фабрика состояний в Editor.svelte. ~80–120 строк.
AiQueue: pull только в onMount по label целиком → ключ (label,path), pull в switchDocument. Таймаут show/edit 8с (MCP 10с) → show в фоновую lane = немедленный ack queued:true + двигает историю + точка. edit в фоновую = писать на диск atomic_write::save сразу, changed-диапазоны для подсветки при активации (если фоновая dirty — ошибка). ask из очереди: абсолютный дедлайн в payload. Продуктовая ловушка: 8 агентов с ask в фоне и только точки = новая «чёрная дыра» → ask нужен сигнал сильнее точки. Реестр WindowTabs (label → вкладки+история) для dedup вместе с OpenFiles.
Session v2: {version:2, windows:[{geom, active, tabs:[{id uuid, kind mine|lane, lane?{session,child}, path?, draft?, cursor, topLine, history?, historyIndex?}]}]}; черновик по uuid вкладки (убирает коллизию); parse_session принимает 1 и 2; писать в session-v2.json, старый не трогать (откат версии).
Минусы B-lite vs A: нет drag вкладки между окнами жестом, нет системного ⌘⇧\.
