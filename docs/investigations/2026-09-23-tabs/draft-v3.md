# Вкладки в couplet — черновик v3 (после прожарки №1)

Контекст — см. draft-v2.md (страхи F1–F6, факты из кода). Изменения после технической прожарки (roast1-architect.md) — ниже.

## Что изменилось
1. «Замена документа в окне» — не готовый фундамент, а сломанная вещь (undo подмешивает старый документ, ask висит/переезжает, нет dedup, untitled выбрасывается). Починка = обязательный фундамент для ЛЮБОГО варианта: один `switchDocument()`.
2. Ключ полосы агента — не git-root, а identity агента из env (`CLAUDE_CODE_SESSION_ID`, `CLAUDECODE=1` = агент; без него = человек → «мои вкладки»).
3. «Закрывать полосу по смерти агента» — не работает (сессии живут днями, смерть не видна). Вместо: «прочитано и простаивает → сворачивается/закрывается», всё обратимо.
4. ⌘[ ⌘] заняты (indent) — история полосы через другой хоткей или через список-поповер на вкладке.
5. Recent/«недавно закрытые» — в Rust, не в localStorage; агентские `show` не вымывают Recent человека (отдельный список или не пишутся).

## Фундамент (шаг 0′, нужен всем вариантам)
- `switchDocument(path, pos)` — единственный путь смены документа в окне: flush отложенного автосейва → dedup (файл открыт в другом окне/вкладке → фокус туда) → untitled с текстом уходит в drafts, не теряется → сброс undo (новый EditorState или reconfigure history) → отмена/перенос pending `ask` и AiQueue по (окно, путь) → сброс черновиков комментариев, перечитать сайдкар, режим по типу файла.
- Untitled никогда не теряется: при закрытии/замене → drafts (app data) + «недавно закрытые»; убрать коллизию имён `untitled-<label>`.
- Стек «недавно закрытые» в Rust; ⌘⇧T = вернуть последнее закрытое; в новом запуске, пока ничего не закрыто — восстановить прошлую сессию (сливаем с Reopen Session).
- Identity агента в запросе (`agent: {session, child, project_dir}`) — обратносовместимое поле, ~30 строк.

## Варианты представления

### A. Нативные вкладки macOS (вкладка = окно + WKWebView)
+ Системный вид, drag/merge/«Move Tab to New Window», ⌘⇧\ обзор, AX бесплатно. Прецедент: iA Writer, MarkEdit.
− ~58MB на вкладку (замер, пустой документ); у владельца 8 живых агентских сессий → ~0.75GB.
− objc на main thread везде (спайк: не-main тихо убивает процесс), session v2 с группами и порядком через objc, геометрия по label бессмысленна, нет события «вкладку вынесли», «+» через class_addMethod, игнорируем системную «Prefer tabs», баг #6548 fullscreen. Маркер «непрочитано» — только префикс заголовка (конфликт с ●) или accessoryView через objc.
~ +6–8 файлов, ~1k строк поверх фундамента, риск objc/сессия.

### B. Полноценные вкладки внутри окна (все документы живые)
+ Полный контроль вида, память ≈ текст.
− Нужен headless DocumentSession для фоновых документов (AI edit, внешние изменения, автосейв без view) поверх самой хрупкой подсистемы (комментарии ~700 строк, #18/#23/#36/#54/#61/#62). ViewPlugins пересоздаются, модульные синглтоны, compartments.
~ 20–25 файлов, 3–5k строк.

### B-lite (НОВОЕ). Вкладки внутри окна, но живая только активная
Идея: вкладка = закладка `{path, pos, cachedState?}`. Живёт (watcher, автосейв, комменты, AI) только активный документ окна — ровно как сейчас. Переключение = `switchDocument()` из фундамента (его всё равно пишем).
- Команда ИИ в фоновую вкладку не переключает её (не угоняет экран): `show`/`edit`/`ask` кладутся в очередь вкладки (AiQueue уже умеет «очередь до mount» — переиспользуем), на вкладке точка; применяются при активации. `ask` агента ждёт ответа (он и так ждёт до 5 мин).
- Внешние изменения фоновых файлов — проверка при активации (mtime/содержимое); кешированный EditorState отбрасывается, если файл изменился. Опционально лёгкий Rust-watcher только ради точки.
- Сохраняются синглтоны App.svelte — никакого headless-рефакторинга комментариев.
+ Память ≈ 0, свой минималистичный вид (полоса скрыта при 1 вкладке; можно в titlebar), маркеры (непрочитано, агент) любые.
− Своя полоса вкладок + AX (role=tablist, клавиатура); drag вкладки в другое окно — командой «В новое окно», не жестом; undo фоновой вкладки живёт в кешированном state (теряется, если файл изменился снаружи); `ask` в фоновой вкладке ждёт, пока я на неё не переключусь.
~ оценка — нужна прожарка.

### C. Без полосы (свитчер ⌘P/⌃Tab MRU)
Поверх B-lite без видимой полосы. Минимум на экране, максимум «чёрной дыры». Держим как режим/настройку, не как дефолт.

## Концепция (без изменений по сути)
- Мои вкладки — от моего намерения. Полоса агента — одна вкладка на агентскую сессию, `show` заменяет документ, история назад/вперёд, непрочитанное — точка/счётчик. Правлю документ полосы руками / pin → он становится «моей» вкладкой (синхронно на первом keydown).
- Новые вкладки — во фронтальное окно; полоса живёт в своём окне. Окон-на-проект нет.
- Фокус: первый `show` новой полосы — активирует окно? последующие — только точка (решить).
