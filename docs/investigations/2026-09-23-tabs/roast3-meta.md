# Прожарка №3 (мета) — ключевое

**Проверено:**
- (a) утечка undo ПОДТВЕРЖДЕНА с оговоркой — события «только удаление» схлопываются (Cmd+Z ничего не делает), события со вставкой (удалял/перепечатывал, вырезал, снимал bold, правка агента) переживают замену и вписывают кусок старого документа в новый; автосейв пишет.
- (b) ask при замене ПОДТВЕРЖДЕНО (ai-ask.ts:216-222; Rust ждёт timeout_secs, 300 с по умолчанию).
- (c) untitled по Cmd+W ПОДТВЕРЖДЕНО (lib.rs:307-311, 272-277; session.rs:79-81).
- (d) таймауты 8 с / 10 с ПОДТВЕРЖДЕНО.
- (e) тосты ЧАСТИЧНО — кнопки прописаны под свой kind, общего API действий нет, push заменяет тост того же kind (анти-спам), стор на окно.
- (f) Recent last-writer-wins ПОДТВЕРЖДЕНО + localStorage привязан к identifier, который меняет ребрендинг.
- (g) env `md-mini mcp`: CLAUDE_CODE_SESSION_ID, CLAUDECODE, CLAUDE_PROJECT_DIR, CLAUDE_CODE_ENTRYPOINT, CLAUDE_JOB_DIR, CLAUDE_CODE_AGENT — есть; CLAUDE_CODE_CHILD_SESSION на 3 PID не найден.
- Попутно: Cmd+O не сбрасывает черновики комментариев и режим; ни один путь не flush'ит отложенный автосейв — последние ≤300 мс набора теряются.

**Ошибки прожарок:**
- Память A сравнили с нулём, а надо со статус-кво (каждый `show` уже = окно со своим WebContent).
- A отброшен по доводам эпохи полос. В v4 вкладок мало; A даёт живые фоновые вкладки бесплатно (снимает кеш/сверку/edit-на-диск); AI-путь уже на run_on_main_thread (ai_socket.rs:608-609).
- R2 «v1 без вкладок» = уклонение от запроса владельца.
- B-lite не так мрачен: edit в фон можно применить к кешированному EditorState (state.update без view); aiHighlight/aiAsk — StateField.

**Стресс-тест v4:**
- ~21 механизм, ~8 компенсаторов.
- Предикат «60 с» неверен → «непрочитанное не вытесняется»: стол переключается, только если его окно не активно И текущий документ просмотрен И нет висящего ask; иначе стук. «Только стук» — настройкой.
- Контракт: mcp_server.rs:467 пересериализует AiResponse → старые MCP-процессы выбросят `delivered`; до перезапуска сессий агенты будут говорить «показал». Обновить описание show («inbox — успех, не повторяй, скажи где»), MCP_AGENT_SNIPPET, agent_text, скилл.
- Скилл владельца открывает `mdmini file.md` (путь человека) → агенты создадут вкладки, пока скилл не переведут на show или скрипт не проверит CLAUDECODE.
- Лента: Rust JSON в app data, дедуп по пути (повтор поднимает и делает жирным), лимит ~50, отдельная секция в Recent. md-лента → L3 (гонки записи).
- Стол = отдельное окно (стол-вкладка ломает F4). ⌘W на столе → следующий show пересоздаёт окно с set_focus+activate (крадёт фокус) → нужно orderFront без активации.
- edit с подсветкой: демо не ломается; для не-экранного — считать changed_lines на отсоединённом EditorState во фронтенде стола + atomic_write.

**Пропущено всеми:**
- Cmd+W закрывается из Rust по is_focused() (ненадёжно) → во фронтенд.
- ⌘T, ⌘1..9 свободны; ⌘⇧\ занят CM6 (не проверено); новые клавиши → menu.rs + native-menu-accelerators.ts.
- Лента — пункт меню, welcome.md, «что нового».
- Ребрендинг: Recent в Rust до/вместе с ребрендингом; не выпускать session v2 и миграцию каталога в одном релизе; смену контракта show — вместе с ребрендингом (MCP всё равно перерегистрируют).
- Тесты: vitest (фабрика состояний, предикат, редьюсер ленты), cargo (стек закрытых, v2), Playwright (полоса с моком invoke), dev:app + мост (стол и фокус), A — только бандл. AX: role=tablist.
