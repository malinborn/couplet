# Прожарка №1 (архитектор) — ключевое
- Замена документа in-place сломана СЕГОДНЯ: replaceContent (Editor.svelte:60-71) addToHistory(false), undo не сбрасывается → Cmd+Z после Cmd+O/Recent подмешивает куски старого документа в новый, автосейв пишет в файл (проверено скриптом на CM6).
- Два разных пути замены: handleOpen (Cmd+O) не сбрасывает черновики комментариев/не перечитывает сайдкар; handleOpenFilePath (Recent) — делает. Общие дыры: нет dedup (два окна автосейвят один файл), Cmd+O в untitled с текстом молча выбрасывает, нет flush отложенного автосейва.
- ask при полной замене: в середине — молча исчезает, агент висит до таймаута 5 мин; без line — переживает замену и висит в чужом документе.
- Untitled: Cmd+W → SessionState::remove → prune_untitled_files удаляет сайдкар (подтверждено по коду). Плюс коллизия: untitled-main.md прошлой сессии перезаписывается, если начать печатать в main до Reopen Session.
- Identity агента: CLAUDE_CODE_SESSION_ID есть и в Bash, и в env `md-mini mcp`; CLAUDECODE=1 отличает агента от человека; CLAUDE_PROJECT_DIR. Сабагенты: тот же SESSION_ID + CLAUDE_CODE_CHILD_SESSION=1, свой MCP-процесс. MCP открывает UnixStream на каждый вызов — «смерть агента» не видна; сессии живут днями → «закрывать по смерти» ≈ никогда. Добавить поле agent в AiRequest — ~30 строк, обратносовместимо.
- ⌘[ / ⌘] заняты indentLess/indentMore (defaultKeymap).
- A реальная цена: main thread (open_file_window_cmd, restore_session, single-instance — вне main; activateIgnoringOtherApps уже сейчас вне main), session v2 с миграцией (иначе parse_session → None, сессия теряется на апгрейде), порядок вкладок только через objc на main, геометрия по label бессмысленна, нет события «вкладку вынесли», «+» требует class_addMethod, заголовок «● name — md-mini» дёргается/съедает ширину, addTabbedWindow игнорирует системную «Prefer tabs». Память: у владельца 8 живых MCP-сессий → 8 lanes + 5 своих ≈ 0.75GB.
- Recent Files как архив сломан при многих окнах (last writer wins localStorage; агентский show вымывает 10 слотов за минуты) → хранить в Rust.
- B реальная цена: скрытая — headless DocumentSession для фоновых документов (AI edit, external change, автосейв без view) поверх ~700 строк хрупкой синхронизации комментариев. ViewPlugins пересоздаются на setState (livePreview, folding, aiCommentAttention, selection toolbar, inspector, formatCaret…); модульные синглтоны cell-edit-session/hover-menu/inspector/selection-toolbar. Mermaid LRU (50) и StateField pan/zoom переживают. Compartments переприменять.
- Фокус: show уже открытого не активирует app; новое окно крадёт фокус.
- ⌘⇧T restore_pending поднимает все окна сразу; слияние со стеком «закрытое» — новый стек в Rust.
- Оценка: шаг 0′ 8–10 файлов ~1–1.5k строк; A поверх +6–8 файлов ~1k (риск objc/сессия); B 20–25 файлов 3–5k (риск App.svelte/комменты).
- Вердикт R1: шаг 0′ (switchDocument() с flush/dedup/drafts/сброс undo/отмена ask; фикс untitled; identity агента; Recent/закрытые в Rust) → lane = окно с историей → A как слой. B отложить.
