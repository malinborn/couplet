# Иконка couplet

Амперсанд («ты *и* твой агент») с кареткой за ним. Силуэт один на все темы,
меняются только палитра и свечения.

`variants/` — тринадцать растров 1024×1024 с прозрачными полями по гайдлайнам
macOS: `default` плюс по одному на каждую половину каждого семейства тем
(classic, aurora, blueprint, phosphor, paper, ink). Из `default` собран весь
комплект приложения в `src-tauri/icons/` (`npx tauri icon`).

## Источник — утверждённый стенд, а не handoff

Растры сняты со стенда `couplet-icon-design-stand.html` из тега
**`couplet-icon-final`** (коммит `aac8460`, ветка `worktree-rebrand-couplet-preview`),
функцией `main(1024, <вариант>)`.

Handoff из claude.ai/design (`design_handoff_couplet_icon/couplet-icons.dc.html`) —
только отправная точка, **пересобирать из него нельзя**: стенд ушёл от него сознательно.

| | handoff | стенд (финал) |
|---|---|---|
| Знак | Playfair Display Italic 500 | Playfair Display Italic **800** |
| Масштаб | как нарисовано | знак и каретка вместе **×1.25** от центра плитки |
| Каретка | 114×595, сверху 114 | ширина 114, верх **на 20 ниже**, длина **555** — укорочена снизу |
| Группа | по центру | сдвинута на **12 вправо**, чтобы знак не срезался скруглением |
| Цвета тем | подобраны вручную | из **токенов тем**: плитка `--bg-base`, знак `--color-heading`, каретка `--color-cursor` |
| Backlog-палитры | три штуки | paper и ink стали семьями тем (см. ниже), coral — кандидат в `theme-lab/` |

Где цвет каретки совпадает с цветом текста (classic, phosphor-dark), каретка —
градиент «акцент → второй тон»; у aurora — родной `--color-caret-top/bottom`.
Свечения обязательны там, где они были в дизайне.

**Paper и Ink** выросли из backlog-иконок, и у них одно исключение: знак —
`--text-primary`, как на тех иконках, а не `--color-heading` (у `ink-dark`
заголовок коралловый, а знак на утверждённой иконке кремовый). Кольцо берётся
из `T['backlog-paper' | 'backlog-ink']` (поле `t`), каретка ink — три stop'а
`#ff8a6a → #e8563f → #c13e7b` (поле `m`) с коралловым свечением (`glowA`).
Paper — сплошная коралловая каретка без свечения, как blueprint.

## Что при рендере убирается

Стенд рисует плитку с внешней тенью `0 20px 50px` — она только для превью. В растр
она **не запекается**: macOS сама кладёт тень под иконку в Dock, и запечённая даёт
двойную. Остаётся только внутреннее кольцо `inset 0 0 0 4px`.

## Как пересобрать

1. Собрать стенд из тега: `scripts/build-icon-design-stand.sh` (шрифты вшиваются
   data-URI, сеть не нужна; Playfair лежит в `scripts/icon-fonts/`, OFL).
2. В браузере для каждого варианта отрисовать `main(1024, k)`, срезать у `.sq`
   все тени, кроме `inset`, снять элемент с прозрачным фоном. Остальную
   страницу стенда при этом спрятать (`visibility: hidden`) — прозрачные углы
   иначе впускают в растр её текст и соседние плитки.
3. Привести к 1024×1024 (`sips --resampleHeightWidth 1024 1024`) — Retina-скриншот
   выходит 2048.
4. `npx tauri icon design/couplet-icon/variants/default.png`.

## Смена иконки по теме

Не реализована. Возможна только для иконки в **Dock** — через
`NSApplication setApplicationIconImage:`. Иконку в Finder менять нельзя:
приложение подписано ad-hoc, и запись в бандл ломает подпись.
