# md-mini 现在叫 couplet

**Powerful for you and your AI, yet minimalistic.**

同一个应用，同样的 AI 功能，换了个名字。你原有的一切都已自动迁移：打开的窗口、光标位置、未保存的草稿、崩溃恢复副本、主题和最近打开的文件。

## 需要做的事——只需一次，几分钟

1. **重启 AI 智能体的会话。** 更新前打开的会话仍然连着旧的 md-mini，重启之前看不到 couplet。
2. **重新教一遍你的智能体。** 打开 **AI → 教你的 AI 使用 couplet**，复制提示词交给智能体。它会注册 MCP 服务器 `couplet` 来取代 `mdmini`，把技能 `mdmini` 换成 `couplet`，更新 `CLAUDE.md`（或智能体配置）里的说明，并在最后告诉你改了哪些东西。
3. **如果你是用 DMG 而不是 Homebrew 安装的，** 请删除 `/Applications/md-mini.app`。你的数据已经在 couplet 里了，旧应用如果被误打开，会以空白状态启动。

## 为什么改名

**有两个应用都叫 mdmini。** 另一个拥有 mdmini.com。两个小编辑器共用一个名字，意味着搜索结果混乱、偶尔下载错应用，还会收到关于别人应用的错误报告。我们不想让这些变成你的麻烦，所以选择让开，而不是去争这个名字。

**而且旧名字已经名不副实。** md-mini 最初是一个极简的 markdown 编辑器，如今它变成了你和你的 AI 智能体共同工作的一页纸：智能体带你跳到某一行，在你眼前改写正在打开的文档，用真正的按钮向你提问，并回复你留在页边的批注。couplet 是“对句”——两行读起来像一行，这正是现在的理念。极简依然保留：它是我们做东西的方式，只是不再是全部意义。

## 即使不做这些也照常可用

| | |
|---|---|
| **终端** | `mdmini` 作为 `couplet` 的第二个名字继续可用，旁边还有简短的 `coup`。脚本、别名和 `$EDITOR` 都无需修改。 |
| **AI 智能体** | 以 `mdmini` 为名的 MCP 注册，在重启智能体后仍然可用，前提是它调用的是 `mdmini` 命令——“Teach Your AI”当初就是这样配置的。使用 `md-mini.app` 完整路径的注册将会失效：第 2 步会修复它。 |
| **Homebrew** | `brew upgrade --cask mdmini` 会把你切换到 couplet，之后也照常可用。 |
| **你的数据** | 首次启动时已从 md-mini 的文件夹迁移到 couplet 的文件夹。md-mini 的文件夹里留有一张便条，写明数据去了哪里。 |

## 在哪里找到我们

网站现在是 **couplet.pro**，旧地址 md-mini.com 也会指向那里。代码仍在原处，在 GitHub 上。

感谢你从一开始就在这里。本子还是那个本子，只是现在有了一个更贴合它用途的名字。
