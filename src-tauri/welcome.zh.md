# 欢迎使用 couplet

一款打字时就实时渲染的 markdown 编辑器——而且能让你的 AI 智能体直接操作。

## 从这里开始：交给你的智能体

1. 打开 **AI → 教你的 AI 使用 couplet**。
2. 复制文档里的提示词，交给你的智能体。
3. 设置就这么简单。智能体会把 couplet 注册成 MCP 服务器，给自己写一份用好它的技能，再在自己的配置里加一句提醒，告诉自己什么时候该用它。

之后它就能做到：

| | |
|---|---|
| **show** | 跳到指定的行或文字，并轻轻闪一下提示你。 |
| **edit** | 直接重写正在打开的文档；改动的部分保持高亮，直到你按下 **Esc**。 |
| **ask** | 在文档里放上真正的按钮——单选、多选，或一个文本框——然后等你的回答。 |
| **question** / **answer** | 读取你在某段内容上留的评论（**⇧⌘M**），并在同一条讨论里回复。 |

没有暗箱操作：**⌘Z** 撤销 AI 的修改，跟撤销自己打的字一样；评论讨论区保存在文档旁边一个独立的 markdown 文件里，不在文档本身里面。

## 按自己的喜好调整

**主题** — **主题** 菜单。六个系列，分别是 Classic、Aurora、Blueprint、Phosphor、Paper、Ink，每个都有浅色和深色两个版本。系列和明暗分开选，改一个不会动另一个。勾选 **跟随系统**，明暗就会跟着 Mac 的昼夜自动切换，系列本身不受影响。

**编辑器引擎** — **视图 → 编辑器引擎**。*实时渲染* 完全隐藏 markdown 语法；*预览* 给文字加样式，但保留原来的标记；*原始* 就是文件本来的样子。**⌘E** 在源码和你选的渲染方式之间切换，从不会把一种渲染方式换成另一种。

**强迫症对齐** — **视图 → 强迫症对齐**。勾选框里的对勾会偏离中心一丝。这不是粗心：`✓` 本来就不是对称的字形，不管怎么调都不会真正居中。如果这一丝偏差会让你耿耿于怀一整天，打开这个开关就能把它换成一个十字——两条线绕同一个点旋转而成，天生对称，没什么能歪的。我们喜欢 ✓ 本来的样子。但我们也懂那种强迫症。

## 值得了解

- 窗口、光标位置和未保存的草稿，重启后都会原样恢复。
- **⇧⌘M** 评论所选内容，**⌘=** 和 **⌘−** 缩放，**⌘E** 显示源码。
- `couplet` 在终端里也能用——`couplet help` 会列出它能做的一切。
